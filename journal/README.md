# journal 使用说明

情景记忆层。落盘纪律比内容漂亮重要。

## 每日简报模板(`daily/YYYY-MM-DD.md`)

```markdown
# Dexter 每日简报 · YYYY-MM-DD

- 触发:自动化定时点/手动/试跑
- 本轮选择与理由:(从议程选的优先级,一行)

## ⚡ 需要委托人注意
(仅重大事项;没有就写"无")

## 📄 论文雷达
(每条:标题 | 作者/机构 | arXiv ID+链接 | 一句话内容(忠于摘要) |
 相关性:高/中/低+理由 | 置信度。高相关 ≤3 条,总数 ≤8 条,宁缺毋滥)

## 💻 开源雷达
(每条:仓库/数据集 | 链接 | 干什么 | 活跃度(star/最近提交) |
 相关性+理由。≤3 条)

## 🏭 产业哨(副)
(≤3 条,只记与操作方向相关的)

## ⏳ 待核区
(拿不准但可能重要的:卡在哪、需要什么才能核实)

## 📝 交接班
(本轮干了什么;下一步是什么;给下一个实例的话。≤5 行)
```

## 周报模板(`weekly/YYYY-Www.md`)

本周要点 / 未决事项 / 风险与分歧 / 下周建议 / 继续教育(无交付阅读笔记)。

## 规则

- `latest.md`:滚动覆盖,≤5 行要点 + 指向最新文件。**常驻循环下每个任务
  结束的检查点必写**(预算随时可能断,这是存活机制)。
- `toollog.md`:PostToolUse 钩子自动追加,人工只读。
- 归档:四周前的 daily 移入 `archive/YYYY-MM/`,只 mv 不删。
