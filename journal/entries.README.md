# entries.tsv · K1 记账口（口径说明）

> **本档管什么**：**逐条**记录"报出的条目"，供 `CONTRACT.md` §3 的 **K1 有用率**计算。
> **不归本档**：轮次判决 → `rounds.tsv`；我犯的错 → `ledger.md`；产物 → `reports/` `designs/`。
> **生长纪律**：**append-only，一条一行，`entry_id` 永不复用**（承 G 编号纪律）。

**建立日**：2026-10-18。**建立理由**：`CONTRACT.md:45` 要求 K1 分母"**须逐条记，含被拒的**"，而建账前全库**只有计数、没有清单**（`residue.md` §二 只有"报出 21 / 拒绝未记录"）。**11-17 首次评估，算不出即契约失败。**

## 口径（三条写死，防漂移）

1. **分母 = `status != 被拒` 的行数**（即契约原文的"报出条数"）。**被拒的仍须逐条入账，但不入分母**——它是"判断力"的唯一度量。
2. **分子 = `used_in` 非空的行数**。30 天窗口**不在填表时判断**，在评估时按 `date` 回算。
3. **自引不计入分子。** `used_in` 若指向**报出该条目的同一件产物**（同一份规格 / 同一篇稿件），**不计**；须指向**另一件**产物。
   依据：建立本档当天，7 条全部被本件自己"引用"了一次，按朴素口径算出 **K1 = 7/7 = 100%**——**这正是本所最该防的自证**。
   **一个能被自己刷满的指标，不是指标，是自我表扬。** 故首日实际记 **K1 = 0/7 = 0.0%**（正常：被用需要另一件产物承接）。

## 计算命令（一条，不得改写）

```bash
awk -F'\t' 'NR>1 && $5!="被拒"{d++} NR>1 && $6!=""{n++} END{printf "K1 = %d/%d = %.1f%%\n", n, d, (d?100*n/d:0)}' journal/entries.tsv
```

## 列

| 列 | 取值 | 约束 |
|---|---|---|
| `entry_id` | `E-YYYYMMDD-nn` | 永不复用 |
| `date` | `YYYY-MM-DD` | 报出日 |
| `source` | `雷达` / `精读` / `主张卡` / `争点表` / `规格` / `稿件` / `外部委托` | **封闭集**，新增须走提案 |
| `one_line` | 一句话 | **必须是一句话主张或一个问题**，不是标题 |
| `status` | `报出` / `被拒` / `已用于立项` / `已用于稿件` / `已用于规格` | **封闭集** |
| `used_in` | 空，或 `立项:<位置>` / `稿件:<篇号>` / `规格:<位置>` | **分子唯一依据** |
| `ref` | 文件路径或 DOI | 可回查 |
