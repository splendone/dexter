### 透镜③ 语言条件长程操作(本轮最厚,已并入 G1 透镜③分图)

1. ★ **DexAgent**(arXiv:2609.35318)——**agentic Human2Sim2Robot**:单条自中心
   人类视频 + 任务提示 → 物理接地的机器人轨迹。四阶段(语义理解 / 按属性重建仿真 /
   轨迹优化 / 数据生成);每阶段**从工具库选技能或现造新技能**,**属性专用验证器**
   检查阶段产出并提供精修反馈以防误差传播;**新技能与验证器留在库中 → 自演化**。
   可处理铰接与可变形物体。
2. ★ **ReCAT**(arXiv:2609.35200)——**结构化循环记忆的语言条件策略**。指令条件编码器
   + Mamba-2 循环记忆 + 一层因果注意力 + flow-matching 解码器(每块双 cross-attention
   读当前与历史)。**LIBERO 95.3% / RMBench 62.4%**(九任务中六项最佳或并列最佳);
   三个真机记忆任务(空间回忆 / 事件计数 / 间隔计时)最佳变体 **66.7% vs 最强短历史
   基线 8.3%**。**关键发现:记忆更新规则任务依赖**——additive 在计数与计时最好,
   delta-rule 在空间回忆最好。
3. ★ **Recursive Harness Distillation**(arXiv:2609.33378,09-27,经 HF 推荐位发现)
   ——强 agent 把干预经验蒸馏成 playbook 交给轻 agent,**用轻 agent 的执行反馈递归
   精修**;新任务实例上复用经验**而不更新模型参数**。真机成功率 **37.3% → 64.0%**。
4. ★ **MAIL-Bench / MINT**(arXiv:2609.35003)——**视觉中断下的 VLA**。MAIL-Bench
   在**每条策略成功参考轨迹的多个阶段**切断不同相机,量化"能力保留";MINT 先在缺失
   输入下训练,推理期用**光流外推或动作条件世界模型**补观测、不可靠时**撤回预测**。
   π0.5 与 GR00T N1.5 上显著提升;AgiBot G2 真机验证。
5. **AdaHVLA**(2609.29204)/ **ADM-Planner**(2609.29212)/ **Coding Agents for TAMP**
   (2609.30233)/ **RACaP**(2609.29394)——账本一已有条目,本批**重开 abs 页复核
   一致**(见 G1 透镜③分图「复核记录」)。

### 透镜① 泛化与数据效率

6. ★ **DexRoam**(arXiv:2609.35761)——**移动双臂灵巧操作**从自中心整身人类演示学习。
   **tracker-free 采集**:仅用消费级 VR 头显 + 头戴立体相机,**无需外置相机或动捕**;
   三阶段显式对齐(embodiment / action-semantic / temporal)保留细粒度整身耦合运动。
   真机:平均成功率 **GR00T N1.7 29%→56%、π0.5 32%→57%**;**用一半机器人演示即可
   匹配纯机器人训练**。**同日开源**(CoRL 2026)。
7. ★ **DexWeave**(arXiv:2609.34724)——人演示 → 灵巧人形 loco-manipulation。两阶段
   重定向(专用求解器初始化 + 上半身交互链耦合精修,保留下肢支撑)+ **解剖感知
   Transformer**(解剖区域作结构化 token、有向掩码注意力,物体信息选择性条件化
   上半身通路);**纯 RL 直接训练**,不用预训练跟踪策略 / 师生蒸馏 / 残差精修。
8. ★ **P2P-T**(arXiv:2609.35375)——从人类演示学**工具操作**。物体中心世界模型提
   稳定位姿先验 → 位姿感知低层策略;**完全绕开人-机器人配对数据**;复杂真机工具
   操作任务上较前一 SOTA **执行性能 +73%**。
9. **Agent Priors-guided Policy Learning**(arXiv:2609.35690)——用**策略的结构先验**
   作为"组合"与"技能"之间的接口(先验声明行为依赖什么,如"抓取只依赖夹爪相对物体的
   位姿"),缓解组合泛化与技能泛化之间的信息丢失。
10. **ECHO**(arXiv:2609.34893)——**仅腕部**事件相机 + 潜世界动作模型;hindsight
    模块把过去事件流作可寻址的离屏上下文,outlook 模块用可学习事件预见查询预测未来
    事件窗。腕部 RLBench:常规光照下较 RGB / RGB+事件基线 **+20.6 / +12.0 分**,
    严重曝光下降下 **+14.6 / +11.3 分**。

### 透镜② 触觉与多模态传感

11. ★ **Uni-VLaT**(arXiv:2609.35450)——**全身触觉适配 VLA**。触觉通路潜状态
    **不仅生成动作,还预测未来触觉 / 本体 / 视觉表征**(与透镜②"把触觉做成预测目标"
    的范式一致)。五个真机任务平均 **75%**,较无触觉基线 **+43 分**、较无预测监督的
    触觉基线 **+7 分**;两个 VLA 骨干上 Table Sweeping **+30 分**、Back-Tap Walking
    **+85~90 分**。

### 通用 / 方法(跨透镜)

12. **MM-ABC**(arXiv:2609.35652)——通用移动操作基础模型。**5000+ 小时、400K+ 回合、
    12 数据集、17 构型**预训练;消融:clean-action x-prediction 换成 velocity prediction,
    RoboCasa365 composite-seen 上 **32.8% → 29.2%**。
13. **Action Upcycling**(arXiv:2609.34911)——**免训练**复用策略本会丢弃的动作:
    在动作速度开始波动处延长执行视界。策略调用降 **1.2–1.7×** 且成功率不降,
    适用于多种 VLA 乃至 WAM;与少步采样 / 流式解码正交。
14. **Adjoint Guidance Flow**(arXiv:2609.34944)——把 critic 引导**摊销**进轻量引导
    网络(把 critic 引导流生成建模为确定性最优控制,costate 回归),**VLA 与 critic
    全程冻结**。
15. ⚠️ **VLA 内部表征的诊断警示**(arXiv:2609.34684)——**自然轨迹上解码准确率高,
    可与"受控目标态响应弱"并存**。作者用物理验证过的观测(交叉目标坐标与机器人
    上下文)把**预测准确率 / 目标态响应性 / 上下文稳定性**三者分开评估。**这条对
    我们读一切"VLA 会理解状态"的结论都是方法论警告**,建议入账本一。
