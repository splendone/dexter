**批 2(R1 部分 + R2 全部)四个硬发现**:
1. **「context」在领域里指三件不同的事且无人分开**:C1 训练序列长度(RoboTTT 8K)/ C2 提示内演示条数(MT3 K≡1、Skild 1 条)/ C3 检索候选规模(STRAP K=100~4000、ReCAP 池 11→35)。→ **领先点① 必须改写**:把上下文预算分解为 N(池)/K(取回)/L(每条长度)/B=K·L,做**固定 B 下的等预算 (K,L) 等值线**,RoboTTT 的 8K 显式排除在族外。这是本批最重要的智力产出。
2. **RoboTTT 的 compute-matched 争议有答案了**:论文只对**基线**声明 matched compute(§4 原句),**上下文扫描这一组没做**;batch 由 ≤4K 的 global 64 降到 >4K 的 global 16,步数同为 30K → 8K 组多看约 2× 数据(推算),且注意力每步算力随序列超线性。→ 「context 是新 scaling 轴」目前是**相关性证据**(论文自己用 "suggesting")。→ **对我们利好**:第一个等算力等数据的上下文预算曲线仍空着。
3. **RoboTTT 一处自陈反例,对我们是直接威胁**:Pup Go Car 上 1 帧历史版 39.5% **低于**无历史版 57% —— 更多上下文存在负向区间,我们的 K 扫描必须能解释非单调性。
4. **Skild 380 解剖完毕**:是**插值**(原文 "estimated by interpolating"),交叉点落在 100→500 之间(跨度 5×,**区间内无测点**);log-x 插值 378.8、线性-x 插值 431,**差 14%**;指标是 "cumulative per-step success rate" 且允许人工接管,**不是 episode SR**;无 trial 数/无 CI/无任务清单。→ 只能当动机引用,**不能当数值基线**;我们的协议须规定插值规则 + 相邻测点间距 + 交叉点 CI。

**批 3(R3 + R4)三个硬发现**:
5. **失败归因可以做成统计模型**(本批最大方法学增量):RoboArena 的 `θ_p+τ_t+ν_t+ψ_{p,t}`(BT + 潜在任务桶 + policy×task 偏移,EM+clipped Newton,平局 Davidson)可直接**加阶段项 σ_{p,t,s}**,把"某策略在某阶段更差"变成带 CI 的估计。领先点③由此从"协议"升级为"模型"。
6. **领域最好的两个评测协议都没报失败归因**(RoboArena 只有 LLM 定性 failure modes + 11% 偏好/progress 背离;COLOSSEUM 只有 14 轴降幅)。且 COLOSSEUM 自陈 *"we do not fix the object pose variations across our test episodes"* → **轴级降幅混了位姿方差**,连最好的扰动基准都在归因混杂上失手 —— 这是我们最有力的反面教材。

## 第五轮(同日续):批 5 机制层——两条会改实验设计的结论

**执行**:两路子代理 + 主会话复核。落盘 `knowledge/papers/方向线精读-批5-机制层-2026-10-27.md`。

**① 视觉编码器选择几乎不重要(推翻一个默认假设)**:
STRAP 原文 *"DINOv2 separated from CLIP by only +0.7% across all 10 tasks"*(主会话 curl 逐字复核)。DINOv2 在**图像实例检索**上碾压 CLIP(mAP 52.3/82.6 vs 19.7/60.2),但该优势**未迁移到动作片段检索**。
→ **E2 不做编码器消融**(已知零效应),研究重心从"换更好的编码器"推到"**换正确的相似度**"。

**② 检索度量会随库规模 N 退化 —— 对我们的 N 扫描是致命混淆**:
三条机制:hubness/距离集中(KoLeo 消融反证:仅把特征铺开即 +8% 检索)、极值偏置(DTW/Chamfer/OT 都是 min 型统计量,S-DTW 自由端点让长参考占优)、度量容量上限。
→ 度量退化与预算效应**同向**(N 大→度量坏→看起来"加库没用"),**会把等值线系统性压平,且无法区分"库没用"与"度量坏了"**。
→ **E2 加设计:主扫描固定一个与 N 无关的度量(S-DTW 或 OT),余弦作独立对照臂单跑一条 N 曲线,专量退化斜率。**

**③ 归因:三类错误不能直接分开,只能靠 oracle 替换阶梯**:
分割错会**伪装成位姿错**(mask 混入桌面→深度初值偏移→refinement 自信收敛到错位姿);对称翻转伪装成分割错;检索到相似物伪装成位姿错(对错物体估得很准);XMem 漂移伪装成检索错。
→ **唯一证据**:对 10% episode 跑 **oracle mask / oracle pose** 两支反事实。**MT3 的"检索 22.3%"若是端到端单标签归类,不可信。**
→ 指标陷阱:**只报 ADD 是错的**(对称物体上会把正确位姿记成错误),必须同报 ADD-S。

**④ 假设 H1 修订为 H1'**:最优 K 是"**该 N 下的检索精度**"的函数,不是 N 的函数;因度量随 N 退化,**最优 K 可能随 N 增大而左移或提前饱和**(与朴素直觉方向相反)→ 可证伪,测法 = 每个 N 上测 top-1 精度,画"最优 K vs 精度"散点。
