**核到的事实**：**R²SI = Manifold AI（流形空间）WorldScape R²SI（Recursive Robot Self-Improvement），登顶 RoboDojo Agent Track 总榜第一，超过 GPT-6-Astra 与 NVIDIA GR00T-N1.7**。前提是 **ICL：不后训练，一次人类示范**（WorldScape Policy 2.0/2.5）；结构 = **内层 Robot Agent**（多视角 RGB + 本体 + 任务描述 + 回合记忆；按任务加载 Skill；**WSP 本身是一个 Skill**，执行一个动作块后交还控制权）+ **外层 Recursion Agent**（跨轮次复盘 → 修订 Skill → **测试通过才发布 + 版本管理**；对 WSP 任务还把执行记录做成训练数据去更新模型）。案例 push_T（600 步预算）：723 步超预算 → 改三处（夹持方向 / 平移与转向解耦 / 分阶段释放）→ **596 步首次在预算内满分 → 389 步（−35%）**。RoboDojo 口径补充：**须在原生动作步数预算内取得进展，效果与效率同受检验**。

**核心结构判断（本件最有价值的一条）**：**R²SI 与 MT3 是同前提（免微调、一次示范）下的两种"改进对象"**——R²SI 改 **Skill/Harness**，MT3 **什么都不改**（从固定库检索回放）。故"谁在榜上高"**类型上不成立**；但**R²SI 的"递归"正好长在 MT3 的"不能插值"上**（MT3 逐字 "fundamentally could not interpolate"；项目页逐字 "even when failing… motions stay loyal to the demonstrated behaviour"）→ **检索给可信运动先验，递归给先验之外的修正，二者正交可组合**。

**MT3 在 RoboDojo 五维（双臂/长程/记忆/泛化/精细）逐维对照**：**只稳拿"泛化（物体实例级）"一维**，其余四维结构性缺失；**外加最硬一条——步数预算失配**（回放定长，演示 400 步就 400 步，与任务预算无关）。→ 总分必然落后，**且落后不携带方法学信息**。
