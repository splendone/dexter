**② 检索方法**：Crossref REST API 按 ISSN 检索（`api.crossref.org/journals/<ISSN>/works`），取 DOI / 发表日期 / 出版商登记摘要；Nature 系论文再逐篇开 `nature.com` abs 页核摘要原文。

## 高相关（3 条详写）

### 1. Learning contact representations in real-world clutter for universal robotic grasping
- **刊/期**：Nature Machine Intelligence，**2026-08-12** 在线发表｜DOI `10.1038/s42256-026-01292-y`｜作者姓氏：Wang, Tam, Xu 等
- **链接**：https://www.nature.com/articles/s42256-026-01292-y
- **摘要要点**（逐句忠于原文）：
  - 问题：深度学习策略数据高效但**绑定特定硬件**；解析式规划器硬件无关但**在感知不确定性下失效**。
  - 方法 **SpaHybGen**：先训一个网络从**含噪深度图**直接推断"空间接触特征"（硬件无关的潜在抓取点表示），再用这些特征引导**可微分优化器**为**铰接手模型**计算稳定抓取。
  - 结果：训练一次，**无需任何硬件特定重训**即驱动 **7 种不同的机器人手（2 指到 5 指）**；**半杂乱场景成功率 94.3%–98.0%**；**密集杂乱中 20 Hz 动态抓取**；并支持多手协同。
  - 代码与模型**已开源**。
- **相关性：高**（这是判断）——它把"跨本体"从"换一个本体再训一遍"变成"**训练一次、接触表示共用**"，正好压在透镜①（跨本体）与 G4（评测协议：跨本体零样本怎么算达标）上。**它给的是可测数字（7 种手 / 94.3–98.0% / 20 Hz），不是概念**。
- **置信度：高**（读过 nature.com abs 页原文摘要；Crossref 元数据日期与页面 `time datetime` 一致）。

### 2. Performant robotic manipulation with real-world reinforcement learning（RL-100）
- **刊/期**：Science Robotics，**2026-07-22** 在线发表｜Vol 11, Issue 116｜DOI `10.1126/scirobotics.aed6267`｜作者：Kun Lei, Huanyu Li, Dongjie Yu 等（9 人）
- **链接**：https://www.science.org/doi/10.1126/scirobotics.aed6267
- **摘要要点**（逐句忠于原文）：
  - RL-100：把**模仿学习与 RL 统一到单一 clipped PPO 替代目标**，作用在**扩散去噪过程**上，使离线与在线两阶段都得到"保守、稳定"的提升。
  - 部署延迟：用**轻量一致性蒸馏**把多步扩散压成**一步控制器**做高频控制。
  - 结果：**8 个真机任务**（推动、保龄球、倒水、折布、拧螺丝、多阶段榨汁、长程折箱）；在预设协议下 **100% 成功（1000/1000 回合）**，含单任务**连续 250/250**；完成时间**持平或优于专家遥操作**。
  - 不重训即得：环境与动力学偏移下 **~90% 零样本**；少样本适配大幅任务变化 **86.7%**；抗人扰 **~96%**；**榨汁机器人在商场零样本连续服务约 7 小时无故障**。
- **相关性：高**（这是判断）——这是"**真机数据 + RL 能把成功率推到 100%**"目前最强的一份公开证据，直接冲击 G2 的核心议题（真机采集 vs 仿真的配比）。**注意它 100% 的口径是"预设协议下的 1000 回合"**，不是任意场景泛化——引用时必须带这个限定。
- **置信度：高**（Crossref 出版商登记摘要全文；未读正文，实验细节未核）。

### 3. Visual-tactile pretraining and online multitask learning for humanlike manipulation dexterity
- **刊/期**：Science Robotics，**2026-01-28** 在线发表｜Vol 11, Issue 110｜DOI `10.1126/scirobotics.ady2869`｜作者：Qi Ye, Qingtao Liu, Siyun Wang 等（10 人）
- **链接**：https://www.science.org/doi/10.1126/scirobotics.ady2869
- **摘要要点**（逐句忠于原文）：
  - 两阶段框架：先用**自监督**从人类演示中学**视触融合表示**；再用 **RL + 在线模仿学习**训一个**统一多任务策略**。
  - 关键点：只用**单目图像 + 简单的二值触觉信号**就获得可泛化操作技能。
  - 结果：**5 个复杂任务 / 25 个物体上 85% 成功率**；并泛化到 **3 个未见过但共享"手-物协同模式"的任务**。
- **相关性：高**（这是判断）——它正面回答透镜②的老问题"**触觉的边际价值到底值多少**"，而且答案很扎人：**二值触觉**（不是高分辨率视触传感器）就够用。这与本期 npj 的"主动掌 + 高分辨率视触"路线形成**同一问题的两条对立路线**，是本季最值得跟的一组张力。
- **置信度：高**（Crossref 出版商登记摘要全文；未读正文）。

## 两条值得展开的补充（本期唯一给了摘要细节的两条 npj）

**A. Tactile-reactive gripper with an active palm（npj Robotics, 2026-02-10, Zhou / Lee / Gu / She）**
摘要要点：以往视触工作**集中在指尖，掌部功能被长期忽略**，掌部"既提供支撑又提供驱动"的潜力未被开发。本工作做**主动触觉掌**（同时具备驱动与高分辨率视触感知）+ 可重构柔顺手指（指尖触觉阵列），靠掌-指协同做自适应抓取与富接触操作；**仅 7 个自由度**即完成 YCB 基准、多种 in-hand 操作、水果采摘与工业案例。

**B. FibTac（npj Robotics, 2026-08-31, Athar / Sheeraz / Zhang / Prince / Duffy / She）**
摘要要点：仿"触须式"同时感知与交互；碳纤维嵌入硅胶弹性体，**气动驱动使弹性体变形以扩张/收缩纤维完成抓取**，内部相机拍**纤维尖端运动**给出分布式触觉。**空气与水下均可用**，载荷达 **186 g**，可抓娇嫩生物样本、软材料、亚毫米颗粒；液液分类/棋子识别/颗粒介质分类/水下流估计/水下物体识别等任务准确率**约 90%**。
