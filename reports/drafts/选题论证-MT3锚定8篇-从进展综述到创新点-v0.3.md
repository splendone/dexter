## 0. 一句话结论

**MT3 的四条自陈缺口，只有一条还是干净的；另有一条被我们自己的裁决判过"降级"却仍留在 v0.2 的清单里。**

所以本轮不是"在 MT3 上加四个补丁写八篇"，而是：
**先按证据把 MT3 周边的研究切成五簇 → 从"两方对不上"的地方取争点 → 争点过三硬门 → 八篇由争点反推。**
八篇的分布是 **1 地基 + 3 机制 + 2 范式 + 1 测量 + 1 综合**，不是四条改造线各两篇。

**三条硬结论**：

1. **触觉线与跨本体线本月不做，且不是"晚点做"**——触觉被 `PHASE`（IROS 2026）占了方法位且本所触觉传感器 = 0；
   跨本体被 `Retrieve, Don't Retrain`（2026-06）占了方法位且本所只有 1 台 Realman。**硬写 = 编造。**
2. **v0.2 的 P5（视觉闭环）与 2026-10-13 裁决冲突**：那次裁决逐字写「2A 单纯"闭环化"被 BPC/RTCF 占、**降级（不建议单独做）**」。
   P5 必须重框为「**误差归因 × 干预匹配**」才成立——这是本件对 v0.2 最重要的一处修订，**提请裁决**。
3. **八篇里只有 3 篇能在 10-24 前交**（P1/P7/P8），前提是 10-19 判定 MT3 harness 存在。**这个前提本件无法替代。**

## 2. 研究方向地图：MT3 周边的五个簇

不是按"主题词"分，是按**它反驳谁**分——只有这样分出来的簇才长得出争点（架构 v3 §4.1 硬门①）。

| 簇 | 它在回答什么 | 代表（逐字核过） | 簇内已收敛的共识 | 簇内仍对不上的地方 |
|---|---|---|---|---|
| **A 检索度量** | 拿什么算"相似" | STRAP（子轨迹+DTW）、FlowRetrieval（光流）、IWR（密度比）、DARP（kNN 结构）、MT3（几何最近邻） | "检索比 BC 省数据"已被反复确认 | **相似性该定义在什么空间**：像素/几何/运动/分布。**四家各给一个标量，没人比较过它们是否可叠加** |
| **B 分解结构** | 轨迹该不该切、切几段 | MT3（两段：alignment + interaction）、PHASE（触觉驱动变长相位）、ManiLong-Shot（事件式，本地语料） | "切两段通常更好" | **MT3 自己逐字承认"decomposition prevented this beneficial representation sharing"**——即**切分有代价，且代价何时超过收益没人测** |
| **C 执行闭环** | 开环回放要不要纠错 | BPC（新控制律，75 Hz）、RTCF（冻结 VLA 的测试时纠错）、POIL（本地） | "开环必错、闭环必好" | **纠错施加在哪一段、收益是否可加——无人分解过**。BPC 换的是整个策略，RTCF 修的是 VLA，**都不是"分解式检索管线内部"的归因** |
| **D 库与本体** | 演示库是什么资产、能不能跨本体 | Retrieve-Don't-Retrain（池=资产，新任务=索引）、MT3（1,000 任务库） | "库可以替代微调" | **库的规模/覆盖率与"检索何时不如训练"的关系没有定量模型**；跨本体已被占（见 §4 否决项） |
| **E 测量** | 凭什么说 A 比 B 好 | MT3（1,000 任务 × 2 trials）、PHASE（+13 pp）、RTCF（2,000 episodes/条件）、RoboDojo（口径 7 倍分裂，本地语料） | "报成功率" | **同一领域里 trial 预算差 3 个数量级（2 vs 2,000），没人算过"多少才够判定"** |

## 3. 研究进展综述：检索式操作的三次转向（2024-08 → 2026-09）

**这是 P8 的骨架，也是本件对"综述研究进展"这一要求的正面回答。**

### 3.1 第一次转向：检索对象从「整条轨迹」到「子轨迹 / 相位」

- **2024-08** FlowRetrieval 把相似性从"场景/语言"移到**运动**（光流）——检索单位仍是演示级。
- **2024-12** STRAP 明确论证"**子**轨迹粒度"才能利用跨任务共享的低层行为，并用 DTW 对齐——检索单位下移到片段。
- **2025-11** MT3 把片段**结构化**为 alignment / interaction 两段，检索在段内做——单位从"片段"变成"**有语义的段**"。
- **2026-09** PHASE 用触觉信号做**变长**相位分段——单位从"固定两段"变成"由接触事件定义的可变段"。

> **趋势判读（判断，非事实）**：检索粒度的下移不是精度游戏，是**为了让"库"可复用**。
> 粒度越细，同一份演示能被越多任务借用；代价是**段边界必须被定义**——而定义段边界需要信号（MT3 用解析位姿、PHASE 用触觉）。

### 3.2 第二次转向：检索的角色从「训练时增强」到「部署时控制」

- STRAP / FlowRetrieval / IWR / DARP：检索的产物是**训练数据**，最终仍训一个策略（DARP 甚至只是重参数化 BC）。
- **2025-11 MT3**：**不训练策略网络**，检索结果直接回放——检索从"数据管道"变成"**控制器**"。
- **2026-06 Retrieve-Don't-Retrain**：连"新任务要微调"都取消，新任务 = 往池里加演示。
- **2026-08/09 RTCF / BPC**：检索进一步变成"**运行时的修正信号**"——BPC 用检索窗口做闭式残差修正，RTCF 用检索记忆做低频残差转移。

> **趋势判读**：这条线的终点是"**策略 = 库 + 一个检索规则**"。一旦如此，**"拟合"这件事从训练期移到部署期**，
> 于是"训练成本"这个指标失效，取而代之的是**库的覆盖度**与**检索规则的鲁棒性**。MT3 的 17 小时教 1,000 个任务，
> 本质是**把成本从"每任务训练"摊到"每任务一条演示"**，而不是把模型变强。

### 3.3 第三次转向：评价对象从「策略」到「库」（**这是空档**）

- Retrieve-Don't-Retrain 之后，"库"是一等公民：新能力靠**索引**获得，不靠参数。
- 但**领域还没有"库级"的评价指标**：现有论文报的都是"策略在任务集上的成功率"，
  没有一篇报"**这个库的覆盖率是多少、它值多少钱、它还能撑多少个新任务**"。
- MT3 自己给的是"1,000 任务 / 17 小时"这种**吞吐量**指标，不是**资产质量**指标。

> **这是 P3 的立论基础，也是本件认为最有价值的一条判断**：
> 当范式把库变成资产，**评价资产的指标就成了下一个必争之地**——而这正是本所"可信测量"主线能接上的地方。

### 3.4 三条反向证据（不能只讲顺风）

1. **分解不一定赢**：MT3 逐字承认分解切断了表征共享。PHASE 的相位是触觉定义的，**视觉定义不了**——所以"相位"这个概念在无触觉平台上**没有独立验证**。
2. **闭环不一定赢**：RTCF 的增益是 86.4→88.4（**+2.0 pp**，聚合），LIBERO-Long 才 +7.0 pp。**在已接近饱和的基线上，闭环的边际收益很小**——这与"开环必错"的直觉相反。
3. **检索不一定赢**：MT3 的优势区间被自己限定在 **<10 demos/任务**。超过这个区间，BC 的反超没有系统研究（→ P3）。

## 5. 八篇：问句 → 主张 → 机制 → 决定性实验 → 六段骨架

**选篇逻辑（为什么是这八篇）**：每篇必须同时满足三条——①**反驳一个已发表的具体主张**（否则是能力报告）；
②**在本所硬件下可支付**；③**能压成一句可判真假的 claim**。八篇按层分布：**1 地基 + 3 机制 + 2 范式 + 1 测量 + 1 综合**。

### P1 ·（地基）MT3 的独立复现与阶段级失败解剖
- **问句**：MT3 报称的"1 demo/任务 + 分解 + 检索"效率，在**独立任务集、独立实验室**上能否复现？失败集中在哪里？
- **主张**：MT3 的成功率在任务族上**不均匀**，且**分解把误差从 alignment 段转移到 interaction 段**——总分复现得了，**阶段结构复现不了**。
- **机制**：alignment 是解析位姿映射（误差有界、可诊断）；interaction 是开环回放（误差无界、累积）。分解把"一个混合误差"拆成"一个有界 + 一个无界"，总分掩盖了这个结构。
- **独立自变量**：无（基准测量）；因变量 = 二值成功 + **阶段级成功** + 7 类失败归因。
- **决定性实验**：M0 的 20 任务 × 10 试次 × 2 臂；报"总分 vs 阶段分"的差异；若阶段分与总分同构（即失败均匀分布），主张被推翻。
- **六段骨架**：①共识"检索式免训练可省数据" → ②反常"总分可复现但失败结构不可复现" → ③原因"分解把有界误差与无界误差分开，总分把它们加回去" → ④主张"评价必须阶段级" → ⑤实验=上面的阶段级复现 → ⑥边界"20 任务、单平台、未含形变物体"。
- **邻居与划界**：MT3（自陈 limitation，但无独立复现）；BPC（在自己的设定里重跑，不是复现）。**未检索到 MT3 的独立复现。**
- **数据/刊/风险**：只用 M0 ／《机器人》／**风险 = harness（10-19 判定）**；无 harness 则降为"协议级复现"。

### P2 ·（机制）位姿-几何解耦检索：把"fundamental tension"变成可扫的二维族
- **问句**：MT3 自陈的"similar object pose vs similar object geometry"张力，是**单标量度量的内禀缺陷**，还是可以被一个**双通道加权族**显式支配？
- **主张**：存在二维族 (w_pose, w_geom)，其 **Pareto 前沿严格支配**任何单标量度量；且**最优权重随任务族系统性移动**（alignment 主导任务偏位姿，interaction 主导任务偏几何）。
- **机制**：位姿项决定"**去哪**"，几何项决定"**怎么抓**"。单标量把两者折叠成一个数，于是"外形相似但姿态不同"与"姿态相同但外形不同"两类任务**必有一类被牺牲**——这正是 MT3 报的 22.3% 检索失败主因的结构解释。
- **独立自变量**：w ∈ {0, .25, .5, .75, 1} × top-k ∈ {1, 3, 5}；对照 = MT3 原版单通道。
- **决定性实验**：同库、同试次、同评分；画 Pareto 前沿 + 按任务族分组回归 w*。**若 w* 处处相同（前沿退化为一维），主张被推翻。**
- **六段骨架**：①共识"检索胜 BC" → ②反常"同一检索规则在两类任务上交替失手" → ③原因"单标量折叠了两个正交自由度" → ④主张"解耦 + 可扫权重" → ⑤实验=Pareto 扫描 → ⑥边界"权重需标定、库需同分布、未含可形变物体"。
- **邻居与划界**：IWR（改**分布加权**，不改度量结构）、FlowRetrieval（**运动**相似，不做位姿/几何分离）、DARP（kNN **重参数化**）、MT3（单通道）。**差异句**：三家都在换标量，本篇论证"**不该只有一个标量**"。
- **数据/刊/风险**：M0 + treatment A ／RA-L／需实现双通道特征（工作量中等）。

### P3 ·（范式）检索库还是训练集：同预算下的交叉点与覆盖率模型
- **问句**：在**同一份数据预算**（同 demo 数、同 GPU 小时）下，检索与 BC 的优劣是否存在**可预测的交叉点**？交叉点由什么决定？
- **主张**：交叉点存在，且由**库覆盖率**（库中与目标任务子轨迹距离 < ε 的比例）预测，而**不由 demo 数直接决定**——demo 数只是覆盖率的代理。
- **机制**：检索**只复用不外推**；BC **压缩并外推**。故检索优势 = 覆盖率高时的"零拟合成本"，劣势 = 覆盖率低时的"无外推"。
- **独立自变量**：方法（检索 / BC / 混合）× demo 数 × 库规模。
- **决定性实验**：仿真（LIBERO 系）+ 公开数据（DROID/OXE 子集）扫网格，拟合交叉曲线；**用覆盖率做样本外预测，若预测误差 > 10 pp 则机制错**。
- **六段骨架**：①共识"检索省数据" → ②反常"同一方法在库大/库小两种设定下结论相反" → ③原因"复用 vs 外推" → ④主张"交叉点由覆盖率决定" → ⑤实验=预算配平扫描 + 覆盖率预测 → ⑥边界"仿真为主、库同分布假设"。
- **邻居与划界**：MT3（比过 BC，但**只在自己 1,000 任务库、单平台、无预算配平、无交叉点建模**）；STRAP（子轨迹 vs 多任务学习，不比 BC 同预算）。
- **数据/刊/风险**：**公开 + 仿真，不用 M0**／RA-L／算力（4090 可）。

### P4 ·（范式）分解的边界：什么时候"切两段"有害
- **问句**："分解为 alignment + interaction"是普遍有效的结构先验，还是**有条件的**？条件是什么？
- **主张**：分解收益是"**相位可分性**"的函数；当两相位在观测上不可分（按压、推、擦拭——接触即对齐），分解切断表征共享，**收益转负**。
- **机制**：分解 = 在两个子策略间切断共享，换来每段更简单的分布。**净收益 = 分布简化收益 − 共享损失**；两项都随可分性单调变化，方向相反。
- **独立自变量**：无（元分析）；调节变量 = 人工编码的"相位可分性"等级。
- **决定性实验**：汇总已发表"分解 vs 单体"的**成对**数字（MT3 的多任务族 × 多组合 + 其他分解工作），按可分性分层做效应量汇总与异质性检验；**若效应量与可分性无关，主张被推翻**。
- **六段骨架**：①共识"分解更好" → ②反常"MT3 自己承认分解阻断共享" → ③原因"简化收益 vs 共享损失" → ④主张"可分性是边界条件" → ⑤实验=分层元分析 → ⑥边界"二次分析、编码主观性、发表偏倚"。
- **邻居与划界**：MT3（只报总体一个数量级，**未按可分性分层**）；PHASE（证明相位存在，但用触觉定义、不检验"何时有害"）。
- **数据/刊/风险**：**纯文献，零硬件，可立即启动**／《机器人》或方法学短文／**最大风险 = 成对数字不够**（若 <6 对则降为"研究通讯"）。

### P5 ·（机制）闭环该修哪一段：误差归因 × 干预匹配
- **问句**：在分解式检索管线里，闭环纠错应施加在 **alignment** 段还是 **interaction** 段？两段收益**是否可加**？
- **主张**：收益**不可加且不对称**——上游（alignment）误差被下游**锁死**（回放不纠错），故上游纠错的边际收益 > 下游。
- **机制**：误差传播是**串联**的；修上游 = 一次性校正整条轨迹；修下游 = 每一步都要修，且已锁死的偏差修不回来。
- **独立自变量**：2×2（alignment 闭环 on/off × interaction 闭环 on/off）。
- **决定性实验**：M0 + 4 组；报成功率 + 阶段级失败归因。**若 interaction 单独闭环收益 ≥ alignment，主张被推翻。**
- **六段骨架**：①共识"开环有累积误差、闭环能救" → ②反常"RTCF 在饱和基线上只 +2.0 pp，说明闭环不是万灵" → ③原因"误差在串联管线里被锁死，纠错位置决定收益" → ④主张"归因-干预匹配" → ⑤实验=2×2 → ⑥边界"视觉闭环，**不回答触觉**；单平台"。
- **⚠️ 与 2026-10-13 裁决的关系（必须写进论文 related work）**：那次裁决判「**2A 单纯"闭环化"被 BPC/RTCF 占、降级**」。
  本篇**不是**"给 MT3 加闭环"，而是"**闭环该加在哪一段**"——BPC 换的是整个控制律、RTCF 修的是冻结 VLA，
  **两者都不做分解管线内部的阶段归因**。**这条划界句是 P5 能否成立的关键，也是审稿人第一刀。**
- **数据/刊/风险**：M0 + treatment B ／RA-L／**八篇里风险最高**（要实时闭环 + 视觉监测 + 重检索，14 天）。

### P6 ·（机制）几个相机才够：视角对检索的边际价值曲线
- **问句**：检索式操作的性能对观测视角的敏感度，在 alignment 与 interaction 两段是否**不同**？加相机的边际收益在哪里饱和？
- **主张**：alignment 段对**第三人称**敏感、interaction 段对**腕部**敏感；故"腕 + 第三人称"两目即可达三目 **95%** 的性能，**第三目的边际收益落在统计噪声内**。
- **机制**：检索度量在特征空间做匹配。alignment 需要**全局位姿**（第三人称好），interaction 需要**局部接触几何**（腕部好）——两者信息源不同，故配置效应**按段分化**。
- **独立自变量**：4 配置（腕单目 / 第三单目 / 腕+第三 / 三目）。
- **决定性实验**：4 配置 × M0；报成功率 + **检索命中率**（top-1 是否落在同任务同相位的演示上）。**若三目显著优于两目，主张被推翻。**
- **六段骨架**：①共识"多视角更鲁棒" → ②反常"MT3 单目就报出高成功率" → ③原因"两段要的信息源不同" → ④主张"配置应按段分配，两目饱和" → ⑤实验=4 配置 → ⑥边界"**型号一致性未确认**；桌面任务、固定工作空间"。
- **邻居与划界**：多视角 IL 文献多，但**未见"检索度量对视角的边际价值"**；MT3 单 D415 未做配置消融。
- **数据/刊/风险**：M0 + treatment C ／《仪器仪表学报》／**若 3 台型号不一致 → 配置与型号混淆，结论不可解释**（v0.2 §8-③ 未解）。

### P7 ·（测量）比较一次要跑多少试次：检索式操作的最小可判定效应
- **问句**：在 MT3 类方法之间做一次"谁更好"的比较，**最少需要多少试次**才能判定？现有论文报的差异，有多少落在噪声内？
- **主张**：**任务间方差 ≫ 试次间方差**，故有效样本量 ≈ **任务数**而非试次数；"每任务 2 trials × 1,000 任务"与"每任务 20 trials × 20 任务"的精度差可计算，而**多数论文按后者设计、按前者报结论**。
- **机制**：成功率是**嵌套数据**（试次 ⊂ 任务 ⊂ 物体）。忽略层级 → 置信区间被低估 → 小差异被当成结论。
- **独立自变量**：无（方法学）；输出 = 不同设计下的 **MDE（最小可检测效应）**表。
- **决定性实验**：用 M0 的嵌套结构做方差成分分解 → 算 MDE → 给出"要在 α=0.05、power=0.8 下判定 Δ pp 需要多少任务 × 多少试次"的**可查表**。
- **六段骨架**：①共识"报成功率" → ②反常"同领域 trial 预算差 3 个数量级（2 vs 2,000）" → ③原因"嵌套结构被当成独立同分布" → ④主张"给 MDE 下限表" → ⑤实验=方差分解 → ⑥边界"单一领域、二值成功、不含连续指标"。
- **邻居与划界**：RoboDojo / LIBERO-Pro 一类审"**基准是否有效**"；本篇给"**比较需要多少样本**"的可计算下限——**前者审尺子准不准，本篇算尺子的分辨率**。
- **数据/刊/风险**：M0 协议层 + 已发表数字／《控制与决策》／**⚠️ 若把已发表差异回算成"不显著"，属推翻他人结论 → 升级门，须先请裁决**。

### P8 ·（综合）检索式操作的三次转向：从数据增强到免训练控制，再到资产评价
- **问句**：2024–2026 检索式操作的结构性变化是什么？下一道坎在哪？
- **主张**：三次转向（对象/角色/评价对象），且**第三次尚未完成**——领域把"库"变成一等公民，却仍用"策略级"指标评价它。
- **机制**：见 §3。
- **独立自变量**：无（系统综述）。
- **决定性实验**：不适用；替代 = **语料纳入/排除标准 + 逐篇核验层级表 + 拒收记录**（架构 v3 要求"报出多少 / 拒了多少"）。
- **六段骨架**：①共识"检索省数据" → ②反常"越省数据，越依赖库；而库没有指标" → ③原因"评价对象滞后于范式" → ④主张"三轴分层 + 资产级指标缺口" → ⑤实验=语料分层统计（各转向的论文数与时间分布） → ⑥边界"语料偏英文、偏 arXiv、未含工业界"。
- **邻居与划界**：现有综述多按**方法族**分；本篇按**检索对象 / 检索角色 / 评价对象**三轴分层。
- **数据/刊/风险**：已核语料 + 本轮 9 篇／《机器人》综述／**风险 = 语料面（84 篇是否够）与"综述不新"**。

## 6. 采用的科研方法（"常见的科研方法"落到哪一篇）

| 方法 | 用在哪篇 | 具体做法 | 为什么必须用它 |
|---|---|---|---|
| **复现研究（replication）** | P1 | 独立任务集 + 阶段级评分，逐项对照原文口径 | 免训练方法的最大卖点是"可复算"，不复现就无从判断 |
| **失败模式分类（扎根式编码）** | P1、P5 | 7 类归因，双人编码 + 一致性系数（Kappa） | "成功率"是标量，掩盖机制；分类才能做归因 |
| **因子设计消融（2^k）** | P2、P5、P6 | 2×2 / 5×3 / 4 配置，全因子而非一次一变量 | 交互效应是这三篇的核心（不是主效应） |
| **预算配平受控对比** | P3 | 同 demo 数、同 GPU 小时、同评分 | 不对撞的跨论文比较会被口径差污染（10-13 已证：7 倍分裂） |
| **设计空间扫描 + Pareto 前沿** | P2 | 二维参数网格 → 非支配解集 | 单点比较无法证明"支配" |
| **方差成分分析 / 功效分析（MDE）** | P7 | 嵌套随机效应模型 → 方差分解 → MDE 表 | 只有它能回答"多少试次才够" |
| **元分析（效应量 + 异质性）** | P4 | 成对效应量、按调节变量分层、I² 异质性 | 单篇无法回答"边界条件" |
| **系统综述（PRISMA 式流程）** | P8 | 检索式留痕、纳入/排除、核验层级表、拒收记录 | 综述的可信度全在流程可复跑 |
| **误差传播追踪（敏感度分析）** | P1、P5 | 串联管线的阶段级误差预算 | 归因不靠猜，靠逐段注入/阻断 |
| **案例研究（case study）** | P4、P8 | 反例任务族深描（按压、擦拭） | 解释"为什么反例反" |

**一句提醒**：以上十种方法里，**没有一种是"新方法"**——这是刻意的。八篇的贡献不在方法新颖，在**用标准方法回答本领域没回答过的问题**。
