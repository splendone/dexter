**关键观察**：**这 13 个东西彼此不像"路"，它们像"零件"。**
「效率/部署」不是"通用性从哪来"，是"跑得动吗"；「动作表示」不是"通用性从哪来"，是"动作该长什么样"；「力控」不是"通用性从哪来"，是"接触怎么稳"。
→ **它们回答的是另一个问题：改的是哪一块。这跟"通用性从哪来"是正交的两个轴。**

## 4. 所以"八条路"错在哪（本件的核心判断）

**用户的假设是**："每篇论文的贡献都应该是在不同研究路线上朝着最终目标靠近"。

**验证结果：这个假设对一半。**

- **对的一半**：每篇论文确实都在**某个组件上**推进（数据、表示、策略、控制、编排、评测、部署）——40/40 都能落进组件轴。
- **错的一半**：**不是每篇都在"靠近通用"**。16/40 的论文**根本不宣称通向通用**——它们优化的是"推理快 30%""力控更稳""动作表示更可学"。**把组件改进说成"道路"，会系统性高估覆盖率，也会把工程优化误读成科学进展。**

**正确的结构（本件的建议）**：

| | 数据 | 表示 | 策略 | 控制 | 编排 | 评测 | 部署 |
|---|---|---|---|---|---|---|---|
| **H1 覆盖** | R2 | R1/R5 | R1 | | | | |
| **H2 组合** | | R3 | R3/R4 | | R3 | | |
| **H3 语义** | | R5/R6 | R7 | | R7 | | |
| **H4 时间** | R2/R8 | | R8 | | R8 | | |
| **— 无来源** | | R20/R15/R16/R17 | | R12/R18 | R14/R19/R21 | X1 | R11 |

**读法**：一行 = 一条"通用性来源"；一列 = 一个"组件"。**一篇论文 = 一个格子（或跨两格）**。
- **同一行不同列**：共享同一个通用性假设，但改的零件不同 → **可比**（同一把尺）。
- **同一列不同行**：改同一个零件，但押不同的通用性来源 → **不可比**（不同的尺）。

> **这解释了 138/160 基准 model-agnostic、仅 11 个建显式对照**：
> 大家在同一列里各做各的零件，**没有人保证自己跟别人在同一行**。

## 6. 诚实清单

1. **40 篇是抽样，不是全量**。47.5% 这个数有抽样误差（n=40，粗估 ±15 pt），**但"约一半装不进去"这个量级是稳的**。
2. **编码是我一个人做的**（abs 级、前 230 字符），**无第二编码者、无 Kappa**。边缘案例（如 02 算 R4 还是"鲁棒性"）可能被判错。
3. **"组件"这一轴是我事后加的**——**这是本件最该被质疑的地方**：用一个新的轴去解释旧轴的失败，可能只是把问题挪了个位置。**要证伪它，得再做一次抽样，看组件轴自己有没有残差。**
4. **本次池仍是"技术词"抽样**，偏 manipulation，不含导航/足式/人形运动——**那些会再引入至少两条路（SLAM、步态控制）**，本件没测。
5. **R²SI 仍是媒体转述**，本件未用它做编码依据。
