## §1 MT3 全文核实结论(摘要级 → 全文级)

**来源**:arXiv:2511.10110v1 LaTeXML HTML 全文(383KB,散文 ≈100% 读毕;
保留 `<math alttext>` 提取,公式数字未丢)。Science Robotics 10, eadv7594 (2025),
DOI 10.1126/scirobotics.adv7594,2025-11-12 定稿;Imperial College Robot Learning Lab
(Dreczkowski / Vitiello / Vosylius / Johns,前两人 equal contribution)。
**arXiv v1 自称 author's version,晚定稿 1 天;本地 HTML 缺 Data availability /
Funding 段(疑裁剪),无法判定正文数字与定稿是否完全一致。**

### 1.1 硬件(对委托人最关键)

- **单臂 Sawyer + Robotiq 2F-85 平行夹爪 + 单个 RealSense D415 RGB-D(头顶)**;
- **无触觉、无力传感**(状态量只有 6D 末端位姿 $T_{RE}\in SE(3)$ + 二值夹爪开合);
- **单台机器人采集 17 小时**(不是多站并行;演示员人数全文未提及);
- 工作空间 $80\times45$ cm,物体位置随机化、朝向 ±180°(受控实验)/ ±45°(1,000 任务实验);
- **遥操作设备、GPU、训练超参全文未提及**(MT3 免训练,故无训练超参;
  BC 基线 MT-ACT+ 的训练超参也只说"per data regime 独立优化参数量",不给值)。

### 1.2 方法核心(全文级,远细于摘要)

- **分解**:alignment 阶段(移动到"适合后续操作的位姿",**只有终点位姿重要,
  路径不重要**)+ interaction 阶段(实际操作,**需精确轨迹执行**)。
- **切分不是算法,是采集时人工定录制起点**:只录 interaction 段;
  **alignment 目标位姿 = 录制轨迹的第一帧位姿**("The alignment target pose was
  extracted as the first pose of the recorded interaction trajectory")。
  **不是**基于接触/夹爪状态/距离阈值的自动切分。
- **检索机制(两级层次)**:
  ① **语言**过滤——用**模板匹配**(template matching,非学习式)从任务描述抽
  micro skill 名(如 "open bottle"),过滤出同 micro skill 的演示;
  ② **几何+位姿**取 top-1——用 **PointNet++ 编码器**(训成 occupancy-grid 预测器,
  数据来自同组前作 [46] Vitiello/Dreczkowski/Johns CoRL 2023)把目标物体
  **分割后点云(robot frame)**编码,取**余弦相似度最高**的演示。
  - **检索对象 = 一整条完整演示轨迹**(不是动作片段、不是嵌入插值);
  - **检索在执行前一次性完成**,alignment 与 interaction **共用同一次检索结果**;
  - **存储极轻**:每条演示只需"单张 RGB-D + 一串位姿向量";
  - **新任务入库零训练**:"appending demonstrations to the existing dataset,
    avoiding fine-tuning and retraining"。
- **alignment 检索策略 = 解析式(非学习)**:[46] 位姿回归 + Open3D Generalised ICP
  精化求相对位姿 $T_\delta$ → $T_{WE}^{Test}=T_\delta T_{WE}^{Demo}$ → **运动规划**到达。
- **interaction 检索策略 = 开环速度回放**:在**末端坐标系**回放演示的 EE 速度序列
  ("replaying demonstrated end-effector velocities in the end-effector frame");
  **非加权平均、非神经策略条件输入**。
- **MT3 = Ret-Ret = 完全免训练检索**("fully retrieval-based",2 次命中);
  **不训练任何策略网络**("completely bypassed the need to learn these mappings
  from limited demonstrations");依赖三个**预训练/外部组件**:PointNet++ 几何
  编码器、[46] 位姿回归器 + Generalised ICP、Grounding DINO(首帧分割)+ XMem(传播)。
- **novel object instance 泛化机制**:"identify the closest demonstration object
  and **proceed as though the novel object were identical to the training instance**"
  ——把新物体当最近邻那个训练物体,刚性配准 $T_\delta$ 吸收位姿差;
  有效因为"optimal trajectories often maintain similar structures across object
  instances within a category, with task tolerance accommodating geometric variations"。

### 1.3 对撞设计与关键数字

- **2×2 消融**:BC-BC / BC-Ret / Ret-BC / **Ret-Ret(=MT3)**,对照单体 BC 基线
  **MT-ACT+**(改自 RoboAgent 的 MT-ACT:PointNet++ + CLIP 语言嵌入 + FiLM 调制 +
  VAE 变分推断;action chunk k=3,history horizon 10,**主动移除本体感觉**
  "removing proprioception... improved spatial generalisation",加 terminal action)。
- **统计**:每任务 3 次评价(受控)/ 2 trials(1,000 任务);95% Wilson CI;
  two-proportion Z-test;n=36(seen)/24(unseen)。
- **scaling 两轴**:① 1→50 demos/task;② 固定 150 demos 摊到 10/30/50 任务
  (15/5/3 demos each)。
- **scaling 定性结论(数字在 Figure 4 图内,文本无)**:分解法在 **1-10 demos
  快速增益但 ~50 平台**;单体 MT-ACT+ 在 **10-50 加速**,差距收窄;
  作者预期"**MT-ACT+ to eventually outperform decomposition-based methods given
  sufficient data**",但**交叉点未测**("the exact crossover point would depend on
  the number of tasks and their similarity")。
- **多样性轴反转**:"**unseen task performance improved** as retrieval accessed
  more object instances ... whereas **seen task performance paradoxically degraded**";
  MT-ACT+ 受益于任务多样性("trading diversity for data efficiency");
  **分解反而破坏 BC 的多样性红利**("decomposition prevented this beneficial
  representation sharing")。
- **唯一文本内定量关系式断言**:"**MT3 with just three demonstrations per task
  outperformed all other methods, even when they were provided with 50
  demonstrations per task**"(3 demos 打 50 demos)。
- **1,000 任务实验文本内数字**:MT3 **seen 78.25% / unseen 68%**;
  评价条件 5-20 干扰物、光照变化、±45° 随机放置;2,200 rollouts(每任务 2 trials)。
- **任务 taxonomy(可复用)**:**31 macro skills × 534 micro skills × 402 objects**;
  "任务" = micro skill 落在具体物体实例上;Appendix C/D 表完整给出 macro/micro
  名 + 计数(place 187 / insert 112 / pick up 90 / pour 89 / remove 79 / wipe 62 /
  open 42 / scoop 40 / stir 37 / close 31 / stack 24 / wash 24 / hang 23 / fill 20 ...);
  另 **100 unseen tasks** 跨同 macro skills。

### 1.4 MT3 自陈的四个缺口(= 四透镜的天然锚点)

**这是 v0.2 重构的核心**——MT3 全文自陈的局限,恰好一一对应委托人的四透镜:

| MT3 自陈缺口(逐字) | 对应透镜 | 为什么是天然锚点 |
|---|---|---|
| **① 无触觉**:"Our reliance on **vision alone** made it impossible to infer dynamic properties of **deformable objects without tactile feedback**";形变物体(backpack/shorts/folding fabric)失败;高精度插入(plug/socket,**millimetre-level**)失败;抓取物体失败 20.2%(inconsistent grasp poses) | **透镜②** | MT3 自己点名触觉缺失是失败根因;委托人硬件(Realman FT?/柔性夹爪触觉?)正好补 |
| **② 开环 + 单交互**:"**Once a trajectory begins, there is no mechanism for the policy to detect errors or adjust a course mid-execution**"(open-loop 全文 **13 次**);"each task involved a **single interaction**";多步靠"chaining using high-level planners"(**真机未验证**) | **透镜②③** | 开环→闭环(触觉纠错)= 透镜②;单交互→长程 chaining + LLM 路由 = 透镜③ |
| **③ 单本体 / 跨本体缺席**:`embodiment` 全文 **0 命中**;双臂只作外推("Extension to bimanual... would require dual-arm coordination",引同组前作 [48]) | **透镜①** | MT3 完全没做跨本体;委托人有 2 Sawyer + 2 Realman = 天然跨本体对 |
| **④ 检索的内禀缺陷**:"retrieval... **fundamentally could not interpolate** between demonstrated behaviours";"geometry-based retrieval had to balance two competing objectives... **similar object pose**(for transfer)versus **similar object geometry**(for suitability)... This **fundamental tension**... became more pronounced as object instances per micro skill increased";检索是失败主因(**22.3%**) | **透镜①④** | 检索度量改进 = 透镜① 方法创新;检索库作为"资产"的成本-收益 = 透镜④ |
| **(附)长程仅 LLM PoC**:Appendix F 用 **Grok 3** + micro skill CSV 做检索 PoC;**无真机成功率**;失败模式"get overwhelmed... **starts hallucinating incoherent task sequences**" | **透镜③** | MT3 检索库 = 资产,LLM 路由 = agentic;PoC 没严格做,委托人可做严格版 = 立场文章支 1 直接实证 |

**§1 小结(这是判断,置信度高——直接读自全文)**:MT3 不是"一个需要被超越的
SOTA 数字",而是"**一个有四个清晰自陈缺口的、免训练的、Sawyer 平台的、
委托人已复现的方法**"。**论文思路不应是"打败 MT3",而是"在 MT3 的受控基底上,
攻它的某一个缺口"**——这既符合委托人的重构框架(科学问题→路径→创新方法),
又因 reproduction base 而工期可控。

## §2 顶层科学问题(统一框架)

**按委托人重构框架,先立"最上层的研究目标和待解决的科学问题",再谈路径。**

### 2.1 顶层研究目标(一句话)

> **在"分解 + 检索"(MT3)这一免训练、轻算力、Sawyer 平台的受控基底上,
> 系统攻其四个自陈缺口(无触觉 / 开环单交互 / 单本体 / 检索内禀缺陷),
> 并在同一受控框架(同硬件、同任务 taxonomy、同预算、同评价协议)下横向对比
> 各透镜的不同研究路径,最终回答:"具身操作策略的能力边界由什么决定,
> 什么任务该走什么路径"——产出一张"任务族 × 路径"的条件表,而非又一个 SOTA 数字。**

### 2.2 为什么这个顶层目标成立(与已签发产物一致,不推翻)

- **综述 v1.0.2 §6.3**:"最该做的增量**不是更强的模型,而是更诚实的对撞**"——
  顶层目标的"横向对比条件表"正是"诚实对撞"的产物。
- **立场文章 v1.0.2 核心主张**:"从路线站队到资产工程...最大的开放缺口不是
  数据规模,而是缺乏①资产质量的度量标准 与 ②同预算受控对比范式"——
  MT3 检索库(534 micro skills)= 现成的"资产",MT3 的 2×2 消融协议 =
  现成的"同预算受控对比范式"雏形。**顶层目标直接实证立场文章。**
- **四透镜分图的最大开放问题**全部指向"对撞/条件表":
  ①"数据成本-成功率曲线不可比"②"模态-收益条件表只有散点"
  ③"三力受控对撞缺失"④"混合配比系统消融缺失"。
  **MT3 的四个缺口恰好是这四个开放问题的"可操作切入点"。**

### 2.3 框架的使用规则(按委托人指令)

1. **不要求研究路径合并**——每透镜给 2-3 条路径,**各路径独立深入**;
   路径之间是"同一科学问题的不同攻法",不是"必须整合成一个系统"。
2. **横向对比只为卡住时找新思路**——当某路径进展困难,用同科学问题的
   其他路径(或其他透镜的替代锚点)做横向对比,**发现新思路/新方法**,
   不是为了"评出哪条路径赢"。
3. **最终目的是解决顶层科学问题**——任何路径,只要能推进"能力边界由什么
   决定 / 什么任务走什么路径"这张条件表,就是有效产出;**不执着于某条路径**。
4. **MT3 是共同受控基底**——四透镜的路径尽量共享 MT3 的硬件(Sawyer)、
   任务 taxonomy(31×534×402)、评价协议(3 trials + Wilson CI + Z-test),
   **使横向对比诚实**(同基底才可对比;这是综述账本"对撞缺席"的解法)。

## §3 四透镜 × 科学问题 → 多路径 → 创新方法(核心重构)

**每透镜结构**:科学问题(精确陈述)→ MT3 对应缺口 → 研究路径(2-3 条,
各含:创新方法 / 与 MT3 关系 / 硬件 / 是否同科学问题 / 工期[有 reproduction base])
→ 横向对比设计 → 替代锚点(若 MT3 不是该路径最优基底)。

### 3.1 透镜① · 泛化与数据效率

**科学问题(精确)**:在**少演示区间(<10 demos/task)**,操作策略的泛化能力
来自"数据规模"还是"结构先验(分解+检索)"?其**能力边界**(何时失效、
与单体 BC 的交叉点在哪)由什么决定?

**MT3 对应缺口**:④检索内禀缺陷(不能插值 / 位姿-几何张力 / 检索是失败主因
22.3%)+ ③单本体(cross-embodiment 0 命中)+ scaling 交叉点未测
("MT-ACT+ eventually outperform... exact crossover point" 未测)。

**研究路径(三条,同科学问题,不要求合并)**:

- **路径 1A · 跨本体检索迁移**(MT3 直接延伸;**v0.1 误设已更正:MT3=Sawyer,
  委托人有 2 Sawyer,故"同本体复现"零成本;"跨本体"才是创新点**):
  - **创新方法**:在 Sawyer 上建 MT3 检索库,**零样本/少样本驱动 Realman**
    (或反之);设计**跨本体对齐层**(运动学重定向 / 末端位姿空间对齐 /
    潜空间对齐)。MT3 的 alignment 是解析式位姿映射($T_{WE}^{Test}=T_\delta
    T_{WE}^{Demo}$),**天然适合跨本体改造**(只要两臂末端位姿空间可对齐)。
  - **与 MT3 关系**:直接延伸(MT3 完全没做,embodiment 0 命中)。
  - **硬件**:2 Sawyer + 2 Realman(跨本体对)+ 3 RealSense + 4090。
  - **工期(有 reproduction base)**:**6-9 月**(跨本体对齐是技术风险;
    若 Sawyer↔Realman 运动学差异过大,检索库迁移可能失败——**但失败本身
    也是论文**:测出"分解+检索的本体无关性边界")。
  - **替代锚点**:Morphometric(2609.28660,跨手重定向,真机 89.3% 零样本;
    **⚠️ v2 口径:匹配阈值 4.5mm、"On a Sharpa hand"单手限定、F1 增量
    "8 to 28 分" + paired bootstrap 显著性保留,不得作"无条件全面胜出"读法**)。
    若跨本体太难,Morphometric 的跨手重定向是更成熟的替代锚点。

- **路径 1B · 检索度量改进**(MT3 方法创新;攻缺口④):
  - **创新方法**:针对 MT3 自陈的"**位姿 vs 几何张力**"(similar pose for
    transfer vs similar geometry for suitability)与"**不能插值**",设计新检索:
    ① **解耦位姿/几何**的双通道检索(分别编码,加权融合);② **检索后插值**
    (top-k 演示的轨迹加权/插值,补 MT3 "fundamentally could not interpolate");
    ③ **任务感知的几何特征**(攻 MT3 "pose estimation operates in a task-agnostic
    manner... without understanding which specific geometric features are relevant")。
  - **与 MT3 关系**:方法创新(改 MT3 的检索核心,其余不变)。
  - **硬件**:2 Sawyer + 3 RealSense + 4090(检索编码器训练,PointNet++ 级,单卡够)。
  - **工期**:**4-6 月**(改检索度量 + 在 MT3 任务子集上对撞;有 reproduction base)。
  - **替代锚点**:FlowRetrieval / SAILOR / Behavior Retrieval(MT3 Related Work
    提及但**未实测对比**——这本身是缺口:把这三个检索方法拉进 MT3 基底做受控对撞)。

- **路径 1C · 分解 vs 单体的 scaling 交叉点测定**(MT3 受控对撞;**最快、不依赖新硬件**):
  - **创新方法**:MT3 说"MT-ACT+ eventually outperform given sufficient data"
    但**没测交叉点**。用 reproduction base **系统扫 1→50+ demos/task**,
    测分解(MT3)与单体(MT-ACT+)的**交叉点**,并测"多样性 vs 数据效率"
    的换算率(MT3 已有苗头:"trading diversity for data efficiency",但未量化)。
    **直接填综述"数据成本-成功率可比表"缺口(透镜① 最大开放问题)。**
  - **与 MT3 关系**:受控对撞(不需新方法,只需诚实的 scaling 实验)。
  - **硬件**:2 Sawyer + 3 RealSense + 4090(MT-ACT+ 训练,单卡够)。
  - **工期**:**3-4 月**(纯对撞,无需新硬件/新方法;**四条路径里最快**)。
  - **替代锚点**:无需(MT3 + MT-ACT+ 都在 reproduction base 内)。

**横向对比设计(同科学问题)**:三条路径都回答"少演示区间泛化来自什么",
但角度不同——1A 测**本体无关性**、1B 测**检索机制**、1C 测**scaling 边界**。
**共享 MT3 任务 taxonomy + 评价协议**(3 trials + Wilson CI + Z-test),
使三条路径的结果可横向对比。**若 1A 跨本体卡住,用 1C 的 scaling 数据找新思路**
(如"交叉点是否随本体变化")。

### 3.2 透镜② · 触觉与多模态传感(**v0.2 最推荐的一支**)

**科学问题(精确)**:接触信息(触觉/力)在操作策略的"**哪个阶段、什么条件下**"
产生边际价值?——不是"有没有用"(已有定论:条件性有用),而是"**怎么用、
何时用**"(透镜② 分图 v1.0.2:"真问题不是有没有用而是怎么用")。

**MT3 对应缺口**:①无触觉(**MT3 自己点名是形变物体失败根因**)+
②开环无中途纠错(open-loop 13 次)。**这是 MT3 最强、最直接的缺口,
且委托人硬件正好补它。**

**研究路径(三条,同科学问题,不要求合并)**:

- **路径 2A · interaction 阶段闭环化**(MT3 直接延伸;**v0.2 最推荐**):
  - **创新方法**:MT3 的 interaction 是**开环速度回放**("no mechanism to detect
    errors or adjust course mid-execution")。加入**触觉/力反馈做闭环纠错**:
    检索仍用于 alignment + 生成初始 interaction 轨迹,**触觉用于执行中检测
    偏差并调整**(如插入任务检测到接触力异常→微调位姿;形变物体检测到
    滑动→调整握力)。**直接回应 MT3 自陈的形变物体/高精度插入/抓取物体失败。**
  - **与 MT3 关系**:直接延伸(补 MT3 最核心的开环缺口)。
  - **硬件**:2 Sawyer(MT3 同平台)+ **Realman 末端 FT(若带,则力反馈主力;
    型号待明示)** + **3D 打印柔性夹爪集成触觉(压阻/电容/PVDF;方案待明示——
    这是本路径关键硬件)** + 3 RealSense + 4090。
  - **工期(有 reproduction base)**:**6-8 月**(需触觉硬件集成 + 闭环控制器设计;
    若柔性夹爪已是纯结构件,须先做 2-4 周触觉集成)。
  - **替代锚点**:若柔性夹爪无法集成触觉,**改用 Realman 末端 FT 做力反馈**
    (不一定需要指尖触觉);或改用 WAM 系(DexTacWAM/VT-WAM/TacWAM,把触觉
    做进世界预测)——但 WAM 系**不基于 MT3 reproduction**,工期上调。

- **路径 2B · 阶段级触觉消融**(受控对撞;**方法论最干净、若 Realman 带 FT 则无需新硬件**):
  - **创新方法**:借 MT3 的 alignment/interaction 分解,做"**逐阶段加减触觉**"
    的受控对撞——对齐 When Does Touch Matter?(2609.24068)的"逐模态加减",
    但**升级到"逐阶段"**(触觉只在 alignment?只在 interaction?两者都?都不?)。
    科学问题=触觉在 alignment vs interaction 阶段的边际价值是否不同。
    **直接填透镜② 开放问题②(视触融合消融证据薄)+ OpenViTac 幸存子缺口④(统计严谨性)。**
  - **与 MT3 关系**:受控对撞(用 MT3 分解框架做消融脚手架)。
  - **硬件**:2 Sawyer + **Realman FT(若带)** + 3 RealSense + 4090;
    **若 Realman 带 FT,本路径无需柔性夹爪集成触觉**(用力反馈即可做阶段级消融)。
  - **工期**:**4-5 月**(若 Realman 带 FT;纯对撞 + 消融,无需新方法)。
  - **替代锚点**:When Does Touch Matter?(2609.24068,受控对撞方法论模板)、
    OpenViTac(2610.10384,统一 sim-real 视触基准;**⚠️ 高风险锚点警告:
    intro 最强 WAM 53.3%/48.5% 与自身 Table 2/3 的 37.4/29.0 矛盾,不得作外部
    引用锚点**;且披露不足、第三方不可复现,不能充当复现论证证据)。

- **路径 2C · 触觉做进检索度量**(MT3 方法创新;攻缺口④+①交叉):
  - **创新方法**:MT3 检索用**几何**(PointNet++ occupancy)。加入**触觉签名**
    作为检索维度(如物体的接触刚度/纹理/形变特性),使检索能区分
    "几何相似但接触特性不同"的物体(**直接攻 MT3 自陈的"形变物体 despite
    visual similarity 失败"**——backpack 视觉相似但动态交互差异大)。
  - **与 MT3 关系**:方法创新(改检索度量,加触觉模态)。
  - **硬件**:同 2A(需触觉硬件)。
  - **工期**:**7-9 月**(视触联合检索是新方法,须先 pilot;四条路径里最难)。
  - **替代锚点**:VisTacAlign(2609.30959,17-DoF 触觉手,视触对齐)、
    UVTA(2609.34182,触觉动作捕捉)。

**横向对比设计(同科学问题)**:三条路径都回答"触觉的阶段级边际价值"——
2A 是"补 MT3 开环缺口"、2B 是"干净测量"、2C 是"改善检索"。

### 3.3 透镜③ · 语言条件长程操作

**科学问题(精确)**:语言条件长程操作的能力应该"**学进权重**"(端到端)、
"**留在慢系统**"(分层)、还是"**外化成可复用资产 + 推理路由**"(agentic)?

### 3.4 透镜④ · 数据采集与合成

## §7 横向对比设计(共同受控基底)

**按委托人指令"横向对比也是为了在这一个方向没有思路和进展困难的时候进行
对比发现新思路和新方法"。**

**共同受控基底(使横向对比诚实)**:
- **同硬件**:Sawyer(MT3 同平台)+ RealSense(MT3 同传感器);
- **同任务 taxonomy**:复用 MT3 的 31 macro × 534 micro × 402 objects
  (Appendix C/D 表完整,可 grep;选 20-100 任务子集,不必重采 1,000);
- **同评价协议**:每任务 3 trials(对齐 MT3 受控实验)+ 95% Wilson CI +
  two-proportion Z-test(**直接填 OpenViTac 幸存子缺口④统计严谨性**);
- **同预算**:固定演示数(如 3 demos/task,对齐 MT3 "3 demos 打 50 demos"断言)+
  固定计算预算(4090 单卡时数);
- **守 P-004 数字并列守则**:同轴同口径 / 区分成绩与领先幅度 / 不同子集均值不并列
  (尤其 LIBERO-Pro 五数四设定、77.5 不与 61 并列[选项 A 维持从严])。

**横向对比的用法(不是"评出哪条路径赢")**:
- 当某路径**进展困难**时,用**同科学问题的其他路径**做横向对比,
  **发现新思路**(如透镜② 2A 闭环控制卡住→用 2B 阶段级消融数据定位
  "触觉在哪个阶段最有价值"→指导闭环控制器设计);
- 当某透镜**所有路径都卡住**时,用**其他透镜的替代锚点**做横向对比
  (如透镜② 触觉硬件不到位→借透镜① Morphometric 的跨手重定向思路,
  看"重定向"能否替代"触觉");
- **最终目的**:推进顶层科学问题(§2.1)的"任务族 × 路径条件表",
  **不执着于某条路径赢**。
