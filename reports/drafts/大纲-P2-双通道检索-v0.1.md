## 0. 一句话主张

> **MT3 用同一个度量同时服务两个互斥目标——alignment 要"位姿对得上",interaction 要
> "几何合得来"。这不是调参问题,是度量设计问题。把它拆成两条通道、并允许在 top-k
> 演示之间插值,可以在不训练任何策略的前提下降低检索类失败。**

**⚠️ 天花板必须写在摘要里**:MT3 原文的失败分布是 **检索 22.3% / 位姿 23.9% / 分割 19.5%**
(其余略)。本文只针对**检索**这一类,**理论最大增益由 22.3% 封顶**。
任何"大幅提升"的措辞都是失实的——**这句话本身要进 Introduction 最后一段**。

## 1. 与 MT3 的差异(逐条,写进 Introduction 的贡献列表)

| MT3 的做法 | 本文 | 为什么这是**问题**而不只是"另一种选择" |
|---|---|---|
| 检索对象 = **一整条完整演示轨迹**,top-1 直接回放 | 检索 top-k,在 SE(3) 上**加权插值** | MT3 原文自陈 "fundamentally could not interpolate"。**top-1 意味着:当真实初始位姿落在两条演示之间时,系统只能二选一,误差无法被摊薄** |
| 单一相似度度量 | **位姿通道 + 几何通道**双路,加权融合 | MT3 原文自陈 "位姿相似" 与 "几何相似" 是 **fundamental tension**。**单一标量无法同时表达"位置接近"与"形状合适"** |
| 任务路由:语言模板 → micro skill 名 → 候选集 | **保留不动** | 路由层不是本文对象。**改动它会把"检索度量"与"任务理解"两个变量搅在一起** |
| 评价:3 试次 + Wilson CI + Z-test | **10 试次 + 配对检验(McNemar)+ Holm 校正** | 3 试次下单个任务的 CI 宽到无法分辨 10% 的差异;配对设计能消掉任务难度这个 nuisance 变量 |

**G6 独立性声明(草)**:本文的独立贡献 = 检索度量与插值;**共用 M0 与基线**;
**不使用 P5(treatment B)与 P6(treatment C)的任何试次**。

## 3. 方法

### 3.1 问题设定(沿用 MT3,不重新定义)

给定任务描述 $l$,语言模板抽出 micro skill 名 $m$,候选集 $\mathcal{C}=\{D_i\}_{i=1}^{N}$
为库中所有 micro skill $=m$ 的演示。每个演示 $D_i=(T_i^{0}, \tau_i)$:
$T_i^{0}\in SE(3)$ 为首帧物体位姿,$\tau_i$ 为 interaction 阶段的关节轨迹。

MT3 做:$\;i^\*=\arg\min_i d(D_i,\text{scene})$,回放 $\tau_{i^\*}$。
**本文做**:排序 → 取 top-$k$ → 条件插值。

### 3.2 位姿通道(alignment 用)

$$d_{\text{pose}}(i)=\big\|\log\!\big((T^{0}_{\text{cur}})^{-1}T^{0}_{i}\big)\big\|_{\Sigma}$$

即当前场景物体位姿与演示首帧位姿的相对变换在李代数上的加权范数($\Sigma$ 为各轴尺度归一,
避免平移与旋转量纲混算)。**这一路回答的是"手该从哪儿下去"。**

### 3.3 几何通道(interaction 用)

对首帧分割掩码做半径 $r$ 的膨胀,取**接触区域局部点云** $\mathcal{P}$(不是全局点云——
全局点云会被背景与桌面主导),计算几何描述子 $\phi(\mathcal{P})$:
- 方案甲(无学习):FPFH 直方图,卡方距离;
- 方案乙(轻学习):PointNet 类编码器,在**公开数据上预训练**,本文不训。

$$d_{\text{geo}}(i)=\|\phi(\mathcal{P}_{\text{cur}})-\phi(\mathcal{P}_{i})\|$$

**这一路回答的是"手下去之后能不能抓得住"。**

> **为什么必须局部**:MT3 的失败里有相当一部分是"几何相似但接触特性不同"。
> 全局点云距离对"物体在桌上还是被手挡了一半"极其敏感,局部接触区才与抓取成败相关。

### 3.4 融合与插值

排序分:$s_i=\alpha\, \tilde d_{\text{pose}}(i)+(1-\alpha)\,\tilde d_{\text{geo}}(i)$,
$\tilde d$ 为按候选集内 min-max 归一化后的距离。

**插值(仅当 top-1 与 top-2 分数接近时启用)**:

$$T^{*}=\exp\!\Big(\sum_{j=1}^{k} w_j \log(T_{j})\Big),\qquad
w_j=\frac{\exp(-s_j/\tau)}{\sum_{l}\exp(-s_l/\tau)}$$

interaction 轨迹按 DTW 对齐后同权重加权平均。

**退化保护(关键设计)**:
$$\text{if}\;\; s_{(2)}-s_{(1)}>\delta \;\;\Rightarrow\;\; \text{退回 top-1 回放(即 MT3 行为)}$$

> **这一条是为了"插值不伤已有成功"。** 没有它,插值会在本来 top-1 就很确定的样本上
> 引入无谓的平均误差——**审稿人一定会问这个**,所以要在方法节主动给出来。

## 4. 实验设计

### 4.1 2×2 因子设计(本节的骨架)

| | top-1(无插值) | top-$k$ + 插值 |
|---|---|---|
| **单通道**(MT3 原版度量) | **C0 = MT3 基线** | **C3 = 只加插值** |
| **双通道**(本文度量) | **C1 = 只加解耦** | **C2 = 完整方法** |

**这个 2×2 是本文最重要的一张表**:它能把"解耦"与"插值"两个改动的贡献**分开归因**,
而不是像多数改进论文那样只报"我的方法比基线好"。**没有这个设计,审稿人无法判断
增益来自哪一半。**

### 4.2 试次与统计

| 项 | 设定 | 依据 |
|---|---|---|
| 任务 | M0 的 **20 个任务**(冻结) | 母实验协议 |
| 试次 | **10 试次/任务/条件** | MT3 原文为 3 试次;10 试次使单任务 CI 半宽从 ~±28% 降到 ~±15%(二项近似) |
| 条件 | 4(C0–C3) | 2×2 |
| 总试次 | 20 × 10 × 4 = **800**,双 Sawyer 各 400 | 单试次 1–2 min → 每臂约 7–13 h |
| 主指标 | **检索类失败子集上的成功率** | 方法只针对这一类;总成功率会被位姿/分割失败稀释 |
| 次指标 | 总成功率 / 分层成功率(alignment、interaction)/ 检索时延 / 库存储 | — |
| 检验 | **McNemar**(逐试次配对二元)+ Wilson CI | 配对能消掉任务难度;MT3 用的非配对 Z-test 在配对数据上功效更低 |
| 多重比较 | **Holm–Bonferroni**,6 组两两比较 | 4 条件 → 6 对 |
| 预注册 | $\alpha$ 扫 $\{0,0.25,0.5,0.75,1\}$ **全报**,不挑最优 | 防"事后挑参" |

### 4.3 消融与敏感性(全部预注册)

1. **$\alpha$ 敏感性**:5 个 $\alpha$ 全报(即使 $\alpha=0$ 或 $1$ 更差也要报);
2. **$k$ 敏感性**:$k\in\{2,3,5\}$;
3. **退化阈值 $\delta$**:$\{0,\;0.05,\;0.1,\;0.2\}$——$\delta=0$ 即"永远插值",作为对照;
4. **几何描述子**:FPFH vs 轻学习编码器(若时间允许,否则明写只做了 FPFH);
5. **位姿噪声耦合分析**(必做,见 §6-①):按位姿误差分箱,看检索增益是否随位姿误差上升而消失。

## 7. 预注册:若结果相反怎么办(动笔前定死,不许事后改)

| 观测 | 判定 | 处置 |
|---|---|---|
| **C1 ≈ C0**(解耦无增益) | MT3 的 "tension" 在实测中不构成瓶颈 | **主张改为负结果**:"位姿-几何张力在 20 任务测试床上未复现为性能瓶颈",附归因。**仍有价值**(直接挑战 MT3 的自陈),但降级投中文核心 |
| **C3 ≈ C2**(插值无增益) | 插值不是有效手段 | 砍掉插值主张,论文缩为"解耦"单点;篇幅降为研究通讯 |
| **C2 < C0**(完整方法更差) | 融合引入噪声 | **必须报**。检查是否 $\delta$ 阈值失效;若确认,结论为"单度量在小候选集上更稳" |
| **C1 > C0 但 C3 < C0** | 插值有害、解耦有益 | 报"两个改动方向相反",这是**比全正结果更有信息量**的结论 |
| 检索失败子集提升但总成功率不提升 | 失败被挪到位姿/分割 | **必须报**;结论改为"检索不是瓶颈,位姿才是"——这会直接改写 P1 的归因,须触发 P1 重审 |

> **最后一条最危险也最有用**:若结果指向"位姿才是真瓶颈",P1 的结论要改,
> 而 P1 是系列地基。**这一条须写进 P1 的"待重审标记"**,不等投稿后才发现。

## 8. 风险

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| **①** | **位姿通道依赖 [46] 位姿回归精度;而 MT3 失败分布里位姿(23.9%)比检索(22.3%)还大** | 双通道的分辨力可能被位姿噪声吃掉 → 增益消失 | 必做位姿误差分箱分析(§4.3-5);**这是本文最可能翻车的地方,要在实验设计阶段就埋好** |
| ② | 天花板 22.3% | 增益上限有限,难写成"大幅提升" | 摘要与 Intro 主动写明;**把"精确归因"当作贡献,而不是把"数字大"当贡献** |
| ③ | 20 任务是否够 | 审稿人质疑样本量 | 报 20 任务的 Wilson CI 与配对设计;明写"任务数受 14 天窗口限制,后续扩到 MT3 的 1,000 任务子集" |
| ④ | 800 试次排不开 | 数据不足 | 降到 8 试次并**明写**;或砍 C3(只测 3 条件)——**砍条件比砍试次好**,因为 2×2 是骨架 |
| ⑤ | FPFH 在低纹理物体上失效 | 几何通道退化为噪声 | 补"仅高纹理子集"的分层分析;必要时换轻学习编码器 |

## 9. 待确认(3 项,不确认不动笔)

1. **MT3 harness 是否提供"候选集检索"这一层的可替换接口**——若检索是硬编码进流程的,
   改度量要动主干代码,工期 ×2;
2. **M0 的 20 任务里,检索类失败是否占足够比例**——若 20 任务上检索失败 <5 次,
   主指标没有统计意义,须换任务集(这会波及 P5/P6,须在 D3 前定);
3. **几何通道是否允许用预训练的 PointNet 类编码器**——涉及"是否算训练"的定性,
   若审稿人认为"预训练编码器也算训练",则"免训练"主张要改成"免策略训练"。
