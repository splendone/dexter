## §1 MT3 论文创新点提炼(外部核实,摘要级)

**来源**:arXiv:2511.10110v1 摘要(2026-10-13 curl 实抓,与 arXiv API
`search_query=ti:"Learning+a+Thousand+Tasks+in+a+Day"` 双向核对一致)。
**定稿**:Science Robotics 10, eadv7594 (2025),DOI 10.1126/scirobotics.adv7594,
2025-11-12 在线。**机构**:Imperial College London Robot Learning Lab
(项目页 robot-learning.uk/learning-1000-tasks,已核实存在,未打开)。

**六项摘要级事实**(逐字忠于原文,不脑补):

1. **两个先验**(two fundamental priors):
   - **分解**(decomposition):把操作轨迹拆成**顺序的 alignment 阶段与
     interaction 阶段**(sequential alignment and interaction phases);
   - **检索式泛化**(retrieval-based generalisation)。
2. **3,450 次真机 rollout** 系统研究该分解;比较 alignment/interaction
   两阶段的不同设计选择,对比**当今主导范式**——**单阶段单体策略的
   行为克隆**(behavioural cloning with a single-phase monolithic policy)。
3. **少演示区间(<10 demonstrations per task)**:分解较单阶段学习取得
   **数量级**(order of magnitude)数据效率改进;**检索一致优于行为克隆**
   (retrieval consistently outperforming behavioural cloning),
   **alignment 与 interaction 两阶段都是如此**。
4. **MT3(Multi-Task Trajectory Transfer)**:基于分解 + 检索的模仿学习方法;
   **每任务少至 1 条演示**(as little as a single demonstration each)即可学;
   **泛化到新物体实例**(novel object instances)。
5. **规模**:1,000 个不同的日常任务,**<24 小时人类演示员时间**。
6. **2,200 次额外真机 rollout** 揭示 MT3 的能力与局限跨不同任务族。

**摘要级创新点归纳(这是判断,置信度高——直接读自原文摘要)**:

- **方法论创新 = 分解 + 检索,不是新架构**——MT3 没有提出新的策略网络,
  而是把"学什么"从"整条轨迹"改成"两阶段 + 检索库";
- **对当前主导范式的挑战**——直接对撞"单阶段 BC"(即 Diffusion Policy /
  ACT / π0 微调的主流用法),不是对撞"端到端 VLA"(OXE/OpenVLA);
- **少演示区间的数量级改进**——这是最强的数字锚点,但**只在 <10 demos
  区间成立**,>10 demos 区间摘要未声明;
- **1 demo/task 泛化到新物体实例**——这是"数据效率"的最强主张,
  但**"新物体实例"的口径**(同类新个体 vs 新类别)摘要未明,
  **须全文核实**;
- **1,000 tasks/<24h** 是**演示员时间**口径,不是**采集总时间**
  (可能含并行站);**须全文核实**采集站数量与并行度。

**MT3 与本所四透镜的语义对位(这是判断,置信度中-高)**:

- **对透镜①**(泛化与数据效率):MT3 是"**分子**"(数据效率)路线的
  **最强新锚点**——1 demo/task 直接压过 TP-Flow(1-shot 66.8%)、
  Res-HIL(20 demos + 10 min 在线)、MimicGen(~200 → 50K+ 合成);
  但 MT3 **不用合成数据**,而是**用检索替代训练**——这是路线 B/C 之外的
  **第三条子路线**(可命名"**检索式少样本**",retrieval-based few-shot)。
- **对透镜②**(触觉与多模态):**MT3 摘要未提触觉**——这是**空白**,
  也是**机会**:alignment 阶段天然视觉主导,interaction 阶段天然接触主导,
  **MT3 的分解框架给"触觉在哪个阶段有价值"提供了干净的实验脚手架**。
  直接回应透镜② 分歧 1(触觉边际价值)与开放问题 ②(视触融合消融证据薄)。
- **对透镜③**(语言条件长程):MT3 是**每任务 1 演示**,不是**长程**;
  但 **1,000 任务的检索库本身就是"资产"**——立场文章 v1.0.2 的核心主张
  (从路线站队到资产工程)在 MT3 里已经**隐性实现**(检索库 = 可复用中间资产)。
  **把 MT3 的检索库当 WAA/K1 意义上的技能库,用 LLM agent 做检索路由 +
  失败重规划**——这是透镜③ 首选方案的骨架。
- **对透镜④**(数据采集与合成):MT3 的 **1,000 tasks/<24h** 本身就是
  **数据引擎创新**——但**它把数据当"检索库"而不是"训练集"**,
  这直接挑战透镜④ 路线 A(端到端规模化:数据当工业品)的默认假设。
  **混合配比研究**(真机 alignment + 合成 interaction,或反之)是
  G2 §7.2 配比实验的**新自变量维度**。

## §2 四透镜当前进展 · 综述说明

**来源**:四份已签发透镜分图 v1(①v1.0.1 / ②v1.0.2 / ③v1.1.1 / ④v1.0)+
综述 v1.0.2 §3.2 12 格矩阵 + 立场文章 v1.0.2 §3 三支。**忠于原文骨架,
不发挥**;每透镜按"范围 / 主流路线 / 分歧 / 开放问题 / 三力对位"五字段。

### 2.1 透镜① · 泛化与数据效率(v1.0.1)

- **范围**:泛化 = 策略对新物体实例/新任务/新本体的适应;数据效率 =
  给定预算下达标所需数据成本。**问句**:"要泛化到 X,最少需要多少、
  什么形态的数据?"——四透镜里**最"钱"**的一条。
- **主流路线(五条 + 规模供给参照)**:
  A 规模数据泛化(OXE/RT-X、OpenVLA、π0);
  B 数据引擎泛化(MimicGen、DexMimicGen、Morphometric、Real-to-Sim-to-Real、SynthDemo-RL);
  C 少样本结构化(TP-Flow、Res-HIL);
  D 骨干与对照(ALOHA/ACT、Diffusion Policy);
  E 架构内改进(GAM、2606.27663)。
- **主要分歧**:
  ①端到端 vs 结构化分解 vs agentic(三力**同基准未对撞**——对撞缺席本身是发现);
  ②数据 vs 结构先验(结构先验买"低数据区斜率",数据规模买"高数据区上限");
  ③合成/重定向的真实性边界(缺同策略同预算下真机 vs 合成受控对比)。
- **开放问题**:①新类别泛化无零样本口径;②各路线"数据成本-成功率"曲线
  **不可比**(总图点名的"剩余唯一大缺口");③合成数据分布覆盖边界,
  视频(非动捕)人演重定向空白;④触觉×演示合成检索零命中。
- **三力对位**(原样):"端到端在透镜①的贡献是'**分母**'(数据规模),
  结构化分解是'**分子**'(数据效率),agentic/程序合成是'**零数据极**'
  (演示→程序,几乎不依赖策略训练数据)。""三条线在透镜①上**不在同一
  坐标竞争**……'数据成本-成功率'可比表,是把这根坐标轴立起来的第一步。"
- **MT3 的位置(这是判断)**:MT3 开辟**第三条子路线**——"检索式少样本",
  既不是"分子"(不训新策略)也不是"零数据极"(仍需 1 demo/task),
  而是**把数据当检索库,把泛化当最近邻**。这**填不上**开放问题②
  (数据成本-成功率可比表),但**给了一个新的对照点**。

### 2.2 透镜② · 触觉与多模态传感(v1.0.2)

- **范围**:视觉之外接触侧感知(触觉/力矩/接触音频/近觉)及其与
  视觉-本体感觉的配对融合。**问句**:"接触信息在多大程度上、以什么方式
  真正提升策略?"——**争议最尖锐**的一条;与①分工:①问"多少数据",
  ②问"哪些模态"。
- **主流路线(五条 + 一篇方法论模板)**:
  A 触觉预训练与表征(PROPRA、TACIT);
  B 视触世界模型 WAM 系(DexTacWAM、VT-WAM、TacWAM);
  C 多模态采集基建(PolyUMI、RH20T、AgiBot World);
  D 反路线,绕开触觉硬件(Force Regulation、GIFT);
  E 触觉仿真与 Sim2Real(Tacchi 2.0、SBLR);
  方法论模板:When Does Touch Matter?(2609.24068,受控对撞)。
- **主要分歧**:
  ①触觉的边际价值(正方 2609.24068 受控实证 + WAM 系消融;反方 TACIT
  naive 3D 视触融合 10.0%/20.0% 低于纯视觉 DP3 20.0%/43.3%、GIFT 25/25、
  Force Regulation)——**真问题不是"有没有用"而是"怎么用"**;
  ②触觉怎么进模型:直接喂观测(naive,可负收益)vs 做进世界预测
  (范式正从"多一个输入通道"转向"多一个预测目标");
  ③触觉数据从哪来:真实采集 vs 仿真(SBLR 主动规避触觉仿真——空白可能是
  选择而非无人问津)。
- **开放问题**:①触觉在大规模数据占比过低(RH20T 仅 7 号构型);
  ②视触融合消融证据仍薄(v1.0.2 更新:OpenViTac 已推进一大步,
  但仍缺多骨干复现、表征×整合全因子交叉、多种子/方差/显著性、
  **灵巧手本体**、可复现披露);③触觉×演示合成空白(检索零命中);
  ④双系统快系统的触觉空位(LiMA 未纳入触觉,作者列 future work)。
- **三力对位**(原样):"触觉在本方向**与三股力量正交**:它既服务端到端
  (当额外模态),也服务结构化分解(WAM 把触觉做进世界预测),还与 agentic
  无直接关系。""因此透镜②的产出不是'哪条路线赢',而是一张
  **模态-收益的条件表**……这张表目前只有散点。"
- **MT3 的位置(这是判断)**:MT3 摘要**未提触觉**——这是**空白也是机会**。
  alignment/interaction 分解**天然对应**"视觉主导 / 接触主导"两阶段,
  **给"触觉在哪个阶段有价值"提供了干净的实验脚手架**。透镜② 首选方案
  (§5.2)直接基于这一点。

### 2.3 透镜③ · 语言条件长程操作(v1.1.1)

- **范围**:把自然语言指令转成跨多阶段、多子任务的连续行为(指令接地/
  任务规划/状态跟踪与记忆/重规划与失败恢复)。**问句**:"语言在哪一层
  被消费?"——四透镜里**三股力量正面相遇**的一条。**口径警告**:
  本领域**尚无统一的"长"的定义**(步数/子任务数/时间跨度/记忆依赖深度混用)。
- **主流路线(六条)**:
  A 端到端 VLA(RT-2、OpenVLA、π0、π0.5、OXE/RT-X);
  B 分层/双系统(LiMA、Rolling-WAM);
  C **Agentic 程序合成与工具调用**(本窗口最活跃:WAA、Robo-Harness K1、
  RAPID、Coding Agents for TAMP、RACaP、AdaHVLA、DexAgent、
  Recursive Harness Distillation);
  D 长程记忆与状态跟踪(ADM-Planner、ReCAT);
  E 3D 接地与空间锚点(GAM、2606.27663);
  F 长程执行的失效诊断与效率(MAIL-Bench/MINT、VLA readout 诊断、
  Action Upcycling、Adjoint Guidance Flow)。
- **主要分歧**:
  ①长程能力从哪里来(端到端派/分层派/Agentic 派**同基准未对撞**——
  对撞缺席本身是发现;π0.5(53%)是现成换算锚点,但没人做那个实验);
  ②语言在哪一层被消费(token 级/意图级/代码工具级,失败模式各不同;
  "'哪层更好'是错问题;'**什么任务该在哪层**'才是问题");
  ③记忆该不该显式("要不要"已有答案,"用哪种"没有);
  ④评测口径不统一(LIBERO-Pro "五个数字,至少四种设定":61/75.6/77.8·88.9/45.0/77.5;
  同号不同轴警示:2610.10526 的 97.8 与 61)。
- **开放问题**:①**三股力量受控对撞缺失**——本透镜最大现成缺口,
  **不需要新方法只需一个诚实的实验**;②"长程"无统一口径;③记忆更新规则
  无选择准则;④失效下的长程鲁棒性刚起步;⑤**agentic 的"资产"没有
  评测口径**(复用率/跨任务迁移率);⑥语言条件的数据侧未被分离。
- **三力对位**(原样):"透镜③是**三股力量正面相遇的唯一透镜**
  (透镜②里它们正交)。""端到端 = 把语言压进权重;分层 = 把语言留在
  慢系统;agentic = 把语言外化成程序与资产。"产出是两张表:
  ①"语言在哪一层被消费"的对照表;②"同基准对撞"的实验设计。
  "**本透镜的最大增量不在读更多论文,而在设计那个对撞实验**。"
- **MT3 的位置(这是判断)**:MT3 不是长程方法,但**1,000 任务检索库 =
  可复用资产**——这**正是** agentic 路线(WAA/K1/RAPID/DexAgent)的
  共同产物形态(立场文章 v1.0.2 支 1)。**把 MT3 检索库当"技能库",
  用 LLM agent 做检索路由 + 失败重规划**——这直接落地透镜③ 开放问题⑤
  (资产没有评测口径),也直接实证立场文章的核心主张。

### 2.4 透镜④ · 数据采集与合成(v1.0)

- **范围**:机器人训练数据怎么被造出来——采集(遥操作/动捕/自中心人类视频)
  与合成(仿真引擎/生成模型/任务规划)的手段、规模、保真度、成本与合法性。
  **问句**:"要拿到 X 规模、Y 形态的机器人数据,该走哪条管线,代价与
  合法性边界在哪?"与①分工:**①把数据当分母,④把数据当产品**。
  **口径警告**:"数据量"度量不统一(轨迹/小时/任务/场景/本体混用)。
- **主流路线(六条)**:
  A 真机遥操作规模化(AgiBot World、DROID、ALOHA/ACT、OXE/RT-X、MATE、GAE);
  B **人演示→机器人**(本窗口最厚:Morphometric、DexRoam、DexWeave、P2P-T、
  Praxis、KnowDemo、Ego2Robot、UMR/WEPVLA、VisTacAlign、UVTA、EgoSpeedUp);
  C 程序化仿真合成(MimicGen、DexMimicGen、DynaForge、PhyVisGen、SynthDemo-RL);
  D Real2Sim2Real 资产化合成(Real-to-Sim-to-Real、DEXTERA、ZeroBot、DREAM);
  E **数据"翻新"与复用**(本窗口新出现:Kintsugi-VLA、ε4P);
  F **异构语料工程**(本窗口新出现:InternW0-Δ、WB-WAM)。
- **主要分歧**:
  ①真机 vs 合成(焦点从"能不能生成"移向"分布覆盖与接触物理差距";
  新增维度——路线 E 显示"坏数据"也含信息,使二分会更复杂);
  ②人演示"按任务够用"还是"必须规模化"(per-task 派 Praxis 一条 /
  UMR 10 分钟 / DexRoam 一半 vs 规模化派 Ego2Robot 18,561 小时 /
  InternW0-Δ >20K 小时;真正争点是预训练规模的收益来自"数据量"还是"数据多样性");
  ③人-机器人差距要对齐到什么程度(全对齐派 vs 绕开派);
  ④合成保真度是必要条件还是可放宽(高保真派 vs 低保真抽象派)。
- **开放问题**:①**合成-真机混合配比的系统消融缺失**——本透镜最大现成缺口,
  **不需要新方法**;②视频(非动捕)人演重定向仍开放;③触觉数据引擎
  ("触觉×合成"与"触觉×人演示"是两条不同空白);④数据"翻新"的
  **质量度量缺失**;⑤异构语料的"统一表示"是否无损;⑥"数据量"无统一口径;
  ⑦许可与合规(✅ 已建 `dataset-selection-matrix.md`,12 数据集 × 许可 ×
  可复现性 × 透镜适用)。
- **三力对位**(原样):"端到端规模化:路线 A+F——**把数据当工业品**。
  结构化分解:路线 B+C+D——**把数据当可造的中间物**。Agentic/程序合成:
  路线 D 的 DREAM + 路线 E——**把数据当可推理、可回收的信号**。"
  "一句话对位:**端到端 = 采更多;结构化 = 造更多;agentic = 推理出来、
  回收回来**。""本透镜的最大增量不在采数据,而在设计'**混合配比**'的
  对撞实验。"
- **MT3 的位置(这是判断)**:MT3 的 1,000 tasks/<24h 是**数据引擎创新**,
  但它**把数据当"检索库"而不是"训练集"**——这**直接挑战**路线 A 的
  默认假设(数据当工业品)。**混合配比研究**(真机 alignment + 合成
  interaction,或反之)是 G2 §7.2 配比实验的**新自变量维度**;
  透镜④ 首选方案(§5.4)直接基于这一点,与 G2 v1.1 合批。

### 2.5 综述 12 格矩阵(§3.2 骨架,四透镜 × 三股力量)

| | 甲·端到端 VLA | 乙·结构化分解/分层 | 丙·Agentic/程序合成 |
|---|---|---|---|
| **①泛化与数据效率** | "**分母**"(数据规模):OXE、OpenVLA、π0、DROID、AgiBot World。**高** | "**分子**"(数据效率):MimicGen、DexMimicGen、Res-HIL、Diffusion Policy。**高** | "**零数据极**"(演示→程序):RAPID、Coding Agents for TAMP、Morphometric。**中** |
| **②触觉与多模态** | 触觉作额外模态融入:OpenViTac、2610.10283、TACIT、GIFT。**中-高** | WAM 把触觉做进世界预测:DexTacWAM、VT-WAM、TacWAM、SBLR。**中-高** | ⚠️ **触觉×agentic 几乎空白**。**低(空白本身是发现)** |
| **③语言长程** | 把语言压进权重:GAM(LIBERO-Pro 61% vs π0.5 53%)、π0.5。**高** | 把语言留在慢系统:LiMA、Rolling-WAM、ReCAT、ADM-Planner。**高** | 把语言外化成程序与资产:WAA(75.6%)、K1(77.8%/88.9%)、RAPID、RACaP、AdaHVLA。**高** |
| **④数据引擎** | 采更多(数据当工业品):ALOHA、DROID、OXE、AgiBot World。**高** | 造更多(数据当可造中间物):UMI、DexRoam、MimicGen 系。**高** | 推理出来+回收回来:DREAM、数据翻新(路线 E)。**中(路线 E/F 各仅 2 篇)** |

**§3.3 核心结论**:12 格中**无一格能判定某股力量"通吃"**——三力是
**角色分工**而非优劣排序。四透镜三力关系**根本不同**:①不同坐标 /
②正交 / ③正面相遇但对撞缺席 / ④三种数据观。

**§6.2 四条贯穿性方法论缺口**:同基准对撞缺席(最大)/ 评测口径不统一 /
触觉规模化受控对撞仍缺 / 许可与可复现性。

**§6.3**:最该做的增量"**不是更强的模型,而是更诚实的对撞**"。

**MT3 在 12 格矩阵里的位置(这是判断,置信度中-高)**:
- **①×乙**(分子)——**直接延伸**(检索式少样本 = 新子路线);
- **②×乙**(WAM 把触觉做进世界预测)——**空白填补机会**(MT3 分解 +
  触觉在 interaction 阶段 = 干净对撞);
- **③×丙**(把语言外化成资产)——**隐性实现**(检索库 = 资产,但 MT3
  自己没做 agentic 路由);
- **④×丙**(推理出来+回收回来)——**挑战路线 A**(数据当检索库,不是工业品)。
- **②×丙**(触觉×agentic 几乎空白)——**MT3 也没填**,这是**双重空白**,
  风险高但新颖性也高(本文件不推荐作为首选)。

## §3 MT3 × 四透镜 = 四个可能的论文切入点

**判据**:对每透镜,MT3 的哪一根创新能对该透镜的哪个开放问题;
关系是"**直接延伸**"(MT3 已做,我们扩展)/ "**跨域迁移**"(MT3 没做,
我们把它的框架搬过去)/ "**受控对撞**"(MT3 提供了对照点,我们做诚实对撞)。

| 透镜 | MT3 创新点 | 对应开放问题 | 关系 | 强度 |
|---|---|---|---|---|
| **①** | 分解 + 检索(1 demo/task) | 数据成本-成功率可比表缺失 | **直接延伸**(新增检索式子路线的对照点) | 中-高 |
| **②** | alignment/interaction 分解 | 触觉边际价值未定案 / 视触融合消融证据薄 | **跨域迁移**(MT3 没做触觉,我们借它的分解脚手架) | **高**(硬件最匹配) |
| **③** | 1,000 任务检索库 = 资产 | agentic 资产没有评测口径 | **跨域迁移 + 受控对撞**(检索库当技能库,LLM agent 做路由) | **高**(立场文章直接实证) |
| **④** | 数据当检索库,不是训练集 | 合成-真机混合配比系统消融缺失 | **直接延伸**(把分解作为新自变量维度) | 中(须等 G2 v1.1) |

**§3 小结(这是判断)**:四透镜**都能**与 MT3 发生关系,但**强度不同**——
**透镜② 与透镜③ 最强**(硬件匹配 + 立场文章铺垫),**透镜① 中-高**
(需跨本体验证),**透镜④ 中**(须等 G2 真人反馈)。

### 5.1 透镜① · 泛化与数据效率

**首选方案(推荐度:中-高)**

- **题目(草)**:《**跨本体检索式少样本:MT3 分解框架在 Sawyer-Realman
  双臂对上的零样本迁移**》(Cross-Embodiment Retrieval-Based Few-Shot:
  Zero-Shot Transfer of MT3's Decomposition Framework on a Sawyer-Realman Pair)

  在 Sawyer 上采集的 1 demo/task 检索库,**能否零样本驱动 Realman**
  (或反之)?若能,则"检索式少样本"是**本体无关**的方法论;若不能,
  则**本体差异**是 MT3 范式的**隐藏边界条件**。
- **与 MT3 的关系**:**直接延伸**——MT3 论文用单一本体(Franka,待全文核实),
  我们用**双本体**(Sawyer + Realman)测跨本体迁移,这是 MT3 没做的。
- **与已签发产物的关系**:直接落地透镜① 开放问题①(新类别泛化无零样本口径)
  与②(数据成本-成功率可比表);与综述 12 格矩阵 ①×乙(分子)格对话;
  与 Morphometric(2609.28660,跨手重定向)、TP-Flow(1-shot 66.8%)、
  DexRoam(一半机器人演示即匹配)构成**同轴对照**。
- **硬件映射**:2 Sawyer + 2 Realman(跨本体对);3 RealSense(alignment
  阶段 3D 感知);4090(检索编码器训练 + 最近邻推理);3D 打印柔性夹爪
  (统一末端执行器,控制变量)。**机械狗不用**。
- **实验设计骨架**:
  - **自变量**:本体(Sawyer / Realman)、演示数(1 / 3 / 5 / 10)、
    任务族(对齐 MT3 的 everyday tasks,选 20-50 个可复现子集);
  - **因变量**:成功率(主)、alignment/interaction 分阶段成功率(次)、
    检索命中率(机制);
  - **对照**:同本体 BC(单阶段单体策略,MT3 的对撞基线)、
    同本体 MT3 复现(分解+检索)、跨本体 MT3(本文核心);
  - **样本量**:每格 ≥20 任务 × 50 rollout(对齐 MT3 的 3,450 rollouts 量级,
    但缩到 1/3);
  - **统计**:配对置换检验(注意 n≤4 时 p 下限 0.125,须告警检验力不足,
    见 lessons.md);
- **撰写路径**(借 paper-autopilot 十段流水线):
  gap(透镜① 开放问题①② + MT3 未做跨本体)→ survey(透镜① 分图 v1.0.1
  已核 14+2 篇,直接复用)→ method(MT3 分解 + 检索编码器 + 跨本体对齐层)
  → **sim(先仿真验证,RoboTwin 2.0 或 LIBERO,4090 可跑)** → real
  (Sawyer + Realman 真机)→ audit(results-auditor 全口径,含不利数字)
  → figures → write → red-team → submit。
- **目标刊物(判断)**:**CoRL 2027 / ICRA 2027 / RA-L**(跨本体迁移是
  这三个刊物的常见主题);**Science Robotics 难度过高**(需 1000 任务级规模)。
- **6-12 月完成可能性(判断,置信度中)**:**中**——跨本体对齐是技术难点,
  若 Sawyer 与 Realman 的运动学/动力学差异过大,检索库迁移可能失败
  (但**失败本身也是论文**,只要诚实报告边界条件)。
- **残余不确定性**:①MT3 全文未读,检索编码空间/相似度度量/分解判据不明;
  ②Sawyer/Realman 具体型号与力矩传感精度待核;③跨本体对齐层的设计
  (运动学重定向?潜空间对齐?)是**方法创新点**,须先做 pilot;
  ④20-50 任务子集的选择须与 MT3 的 everyday tasks 可比。

**备选方案(推荐度:中)**

- **题目(草)**:《**检索式少样本 vs 合成数据引擎:同预算受控对撞**》
