## 1. 目标(为什么做这件)

在 G1 权威认识地基(四透镜分图 ×4 + 12 数据集卡 + 5 基准卡 + 3 处跨源口径定案 + 争论账本三本)已交付的基础上,**把散在四份分图里的判断整合成一份可投稿的综述**——给出**「四透镜 × 三股力量」的原创分类框架**,并对领域内的核心分歧给出**定案**。

**为什么是现在**(时机判断,这是判断):
1. **G1 时机门已解锁**(2026-09-30 四图齐);
2. **G3 里程碑① 教程已交付**(2026-09-30 签发 v1.0,自查复核 0 实质错误)——**教程工序验证通过**,综述可沿用相同的自查复核管线;
3. **G2 卡 P0**(硬件预算未给),**G4 卡前置门**(设备依赖未表态),G3 里程碑② 是**当前唯一可启动的目标产出**(见 2026-10-08 22:28 目标—差距审视);
4. **备料已足**:四份分图共 81 篇已核实工作(①14+2 / ②13+1 / ③24 / ④30)+ 12 数据集卡 + 5 基准卡 + 争论账本三本(其中账本一「端到端 vs agentic vs 程序合成」已含 4 条 agentic 证据);
5. **风险**:再等下去,新工作累积 → 综述的「分类框架」可能被别人的综述抢占先发优势(这是判断,置信度:中)。

**为什么是这个题**(选题依据):
- **能力缺口**:领域内**没有一份综述同时覆盖四透镜并对位三股力量**——现有综述或按硬件(灵巧手 / 移动操作)、或按方法(RL / IL / VLA)、或按数据(遥操作 / 仿真)组织,**没有一份以「透镜 × 力量」矩阵为骨架**;
- **原创判断**:四透镜分图各自的「与三股力量对位小结」已经给出**局部判断**,综述要做的是**把 4 个局部判断合成一个全局分类框架**,并给出**每格的力量对比结论**(哪股力量在该透镜上占优、证据是什么、置信度多少);
- **可辩护性**:所有数字与断言可回指到 G1 已核实的 81 篇语料 + 12 数据集卡 + 5 基准卡 + 争论账本三本(承 TP-Flow 溯源缺口教训,**必须配语料回指表**)。

## 3. 验收判据(逐条自检,缺一不合格)

**承 G3 成功判据 + 综述类特殊要求**:

1. **结构完整可投**:摘要(≤250 字)/ 引言 / 相关工作 / **分类框架(§3,原创)** / 四透镜分述(§4.1-4.4)/ **分歧与裁决(§5)** / 讨论 / 结论 / 参考文献齐全;
2. **原创分类框架**:「四透镜 × 三股力量」矩阵必须给出**12 格对位表**(4 透镜 × 3 力量)+ **每格的判断**(哪股力量在该透镜上占优、证据是什么、置信度高中低);**不得只是四份分图的拼接**;
3. **分歧裁决**:至少对 `controversies.md` 三本账本给出**定案引用**(账本一 端到端 vs agentic vs 程序合成 / 账本二 真机 vs 合成 / 账本三 触觉边际价值);已定案的三处跨源口径(DROID 86 / OXE 21·60 / LIBERO-Pro 论文未声明)必须在综述正文正确使用;
4. **全部事实性陈述带可核查出处**:每个数字带原文位置(「见论文表 2」),每处断言带 arXiv 编号或工作区路径;**未证实的内容不入正文**;
5. **语料回指表**:凡列数字必能回指到某条核实记录(承 TP-Flow 溯源缺口教训 + honor 09-29「97.8 无源数字」教训);回指表覆盖 81 篇已核实语料 + 12 数据集 + 5 基准;
6. **数字并列守则**(P-004 过渡期守则,批准前立即生效):凡写「A vs B」式并列,先确认两数**同轴、同口径**;不同任务数/不同子集的均值不得并列;不同基准/版本的数字不得并列;
7. **会签前自查复核**(承 `re-review` §6):
   - **独立子任务复核**(未参与起草,异检索路径):逐条比对全部量化数字 + 专查四类错误(数字-结论错配 / 不同轴并列 / 归属错 / 无源数字)+ 实抓入口 URL;
   - **外部交叉源**:至少一个外部/原始来源(abs 页 / 官方页 / 许可文件),不得只靠本地库互证;
   - **存疑即 FAIL,无部分通过**(P-007 精神,批准前作为过渡守则);
8. **不署名对外**——稿件到 `final/` 即视为「可投状态」,**投稿与否由委托人决定**;Dexter **不自行投出、不署名对外**(红色事项);
9. **诚实条款**:综述的**分类框架是判断非测量**——必须显式标注「这是判断」并附依据与置信度;不得用肯定的综述语气掩盖判断属性。
