> - **② test-time compute ↔ 专家演示兑换率 → 仍开着(高)**。**无一篇给兑换率拟合**。四个"点"级近邻均**不是**我们要的轴:EmbodiedCLBench 的 k-样本曲线(k=0→6)中 **k = 智能体自己完成的基础任务(自采经验),非专家演示**,且 k>1 后"fluctuates without a clear upward trend",并**明说算力不能替代经验**(逐字"additional tolerance **cannot replace** the role of prior experience");Scale-and-Selection 的 B-rollout 曲线中 **B = task agent 自己的评测 rollout(证据),非专家演示**(逐字"Each case is a **full agentic rollout of the task agent**"),且"stops at B=100…still rising…remains open";AdaRSI 的 "28% GPU time + 22% self-collected demonstrations" 是**单点比值**,其演示=**仿真自采训练数据**(逐字"collects demonstrations in simulation itself…rejection sampling…or write a scripted expert that reads privileged state";"No human demonstrations"),算力=**GPU 训练非测试期推理**;ENCORE 变 K∈{0,1,3} 反而报"demonstrations reduce attempts, while agent time and cost **stay similar**"——**否定简单兑换**。

## §0 核心结论(TL;DR)

1. **连续三次"找方法缺口"全部被抢跑**(MT3 缺口①② → PHASE/BPC/RTCF;机会#1 test-time compute
   → SAIL/E-TTS/综述;autoresearch 搬到机器人 → SimEX/ASPIRE/ENPIRE/4 综述/发布后第 4 天的逐字 fork)。
   **这不是运气差,是方法错**:方法缺口在 2025-2026 的具身领域以**周-月速度闭合**,
   "读一篇论文的自陈局限 → 当作开放缺口"或"看一个相邻域的成熟方法 → 当作迁移机会",
   **结构上必然迟到**。
2. **四篇综述/批判文全文级一致指认:领域的耐久缺口已从"缺新方法"转向"缺可信测量与验证"。**
   13 条权威开放问题里 **9 条属测量/验证/评测协议类**;**4/4 篇共同指认**的头两条是
   ①**in-loop 指标增益 ≠ 独立 held-out 增益**(实测夸大 **2.0~2.6 倍**)②**缺"自我改进"的
   共享基准与协议**。
3. **五条独立线索收敛到同一处**(委托人"对撞层"裁决 / 立场文章"资产质量度量+同预算受控对比" /
   机会#1 唯一幸存增量"算力↔数据兑换率" / 操作图谱 #1 开放问题"数据成本-成功率可比表" /
   P4 的"skill-library reuse rate")——**这是本件重定向的依据,不是我个人偏好。**
4. **唯一经全文级验证仍开着的方法层窄缝**:**"检索式免训练操作策略的设计空间"作为搜索对象**
   ——12 词根 × 4 篇全文 grep **全 0 命中**;SEAR 的 "Policy form" 分类学只有 CaP/AaP/AR
   **三格,没有第四格**。置信度**高**(全文级)。

- **只给 audit access 不够**:HO-EarlyStop/HO-Revert 最高 ρ^audit 仅 **0.67**,ΔC 仍 ≥0.55。
- **表面多样性监控无效**:"Any monitor that watched only S_t would have raised no flag."
- **数据级 mitigation 只部分迁移**:ρ 从 ≈0.43 提到 ≈0.58,但 "neither fully closes the gap nor
  preserves in-loop performance (ḡ^opt degrades by 3% to 13%)"。
- **P3 关键量化基线(供我们对照)**:迭代 300 轮 in-loop 夸大 held-out **2.0~2.6 倍**;
  ρ^audit **0.38-0.49**;1000 轮后 ρ^audit **0.46→0.31**、H_T **1.18→0.94**,"collapse deepens
  rather than self-corrects";DAPS 把 ρ^audit 提到 **0.79**、ρ^blind **0.74**、墙钟代价 **+1.4%**。
- **P3 的 confidence cliff 近邻证据**(《Rehearse》2607.27687):有用改动比例从前 2 轮 **70%**
  掉到第 6 轮后 **43%**;选择性准确率 **82.8%→56.9%**。→ **我们的循环须预设"何时停"的判据,
  不能假定收益恒定。**

## §7 单卡 4090 可行性 + 硬边界

**能做(有逐字依据)**:
- **P3 线(#1/#6/#7)**:其自身实验 "**bounded at 5 minutes on a single A100**",target 模型 1B
  (8B 复现同模式),proposer 走 API,基座是 Karpathy 的 630 行脚本,明说 "**operates at
  single-GPU scale**"。→ **4090 可做单次 run 与中小 sweep**;但全量 sweep 用了 **~6,200 A100-hours**,
  **只能做子集,须显式降规模并披露**(这本身符合 #8 预算记账)。
- **P3 Limitations 亲自点名的开放轴**(最直接的"领域说自己没做"):"executor and target scale, and
  **horizons beyond 1,000 iterations**"、"**extend the diagnosis beyond the preliminary non-ML loop**"、
  "**study how multi-agent loops alter the picture**"。其中 >1000 iter 的 horizon 与 multi-agent
  是**时间/编排问题,单卡可跑**;非 ML 域须按 §3.2 协议重新推导分类法
  ("the derivation protocol of §3.2 is **domain-general**")——**纯人工+嵌入聚类,零 GPU 门槛**。
  → **"把 P3 的诊断仪器迁到机器人操作域"本身就是一条单卡可行、且领域自陈没做的路。**
- **P4 线(#2)**:Table 9 前两量落在 **LIBERO-100 lifelong 仿真**,第三量落在
  **Open X-Embodiment held-out-embodiment splits(离线数据 + 仿真,22 embodiments)**,
  第四量(provenance check)是**纯文档审计,零算力**。
- **P1 线(#2/#3)**:其 §6.3 Table 4 列的 embodied benchmark **全是单卡可跑仿真**
  (Meta-World/RLBench/robosuite/robomimic/CALVIN/LIBERO/ManiSkill3/RoboTwin/SIMPLER/LIBERO-PRO);
  **缺的是协议层,不是硬件**。且 P1 明确**仿真即算 physical grounding**:
  "whether in a physics simulator or in the real world"。
- **#4/#5/#8/#12**:元验证、披露审计、预算记账、新颖性审计——本质是**对已发布 artifact 的
  重新审计与协议设计,几乎不需训练算力**(P2 整篇方法就是全文编码 + checklist)。

**不能做(P1 逐字划界,诚实条款)**:
- **硬件安全**:"**Simulation evidence alone does not establish hardware safety**, which requires
  assessment of the deployed system under its intended physical conditions."
- 真机 physical grounding 的 release 授权、#9 的安全跨代再验证
  ("can exceed physical trial budgets and itself incur harm")、#13 的跨具身实物迁移验证。
- **→ 触觉/真机类 Track(原 Track A)仍属真机依赖,不能靠本纲领的仿真测量替代;
  且按宪法,真机执行 = 红色,由真人执行并签字,AI 不驱动硬件。**
