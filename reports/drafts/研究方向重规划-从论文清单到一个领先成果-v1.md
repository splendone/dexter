## 0. 一页纸结论

- **主攻方向(唯一)**:**"演示即上下文"——免训练检索式操作策略(training-free retrieval-based manipulation)的可信测量与改进**。它踩在地图指认的两条线的交点上:领域最热的新线索(8.10.2"物理提示/上下文学习",路线 C 与 D 之间的新子路线)× 领域公认的最大短板(评测有效性,地图判断 7、§9.5、选题八)。
- **三个"领先点"**(领域目前没有、我们可交付、且硬件算力完全匹配):
  1. **检索-上下文 scaling 曲面**:任务成功率随「演示库规模 × 检索条数 × 上下文长度」三个轴的变化曲面与等预算兑换率——目前领域只有 RoboTTT 测过单轴(上下文 timesteps),无人系统测过这个曲面;
  2. **单演示换算率协议**:1 条演示 ≈ 多少条后训练轨迹的受控测量协议与公开曲线(Skild S1 声称"1 条≈380 条"但无协议、无独立复现;地图 8.10.2 明确将其列为"仍待验证");
  3. **阶段级失败归因协议**:把 MT3 式任务分解的失败按阶段解剖、归因到"该修哪一段"的测量协议(既有 v0.3 选题论证已设计,直接继承)。
- **为什么不换方向**:MT3(《Learning a Thousand Tasks in a Day》,Sci. Robotics 10(108), 2025-11,Imperial College Robot Learning Lab)官方代码 **MIT 许可已开源**(`github.com/kamil-dreczkowski/learning_thousand_tasks`,含模型架构、训练脚本、部署示例,2026-10-27 核实)——此前 8 篇论文计划的"生死门"(harness 是否存在)**已解除**;本所已有 9 篇邻居论文 abs 级核实、一份 46KB 规格书草案、一台同平台 Sawyer。**换方向的成本远高于在此方向上收敛。**
- **新组织原则(纠正"之前组织方式")**:一个主攻方向、三个领先点、四层递进实验(E0→E3);**论文是成果的载体,不是目标**——每篇论文只在前一个实验产出可复算数字之后才开写;一切检索绑定"这回答哪个领先点的哪个问题"。

## 2. 对当前领域的理解(浓缩版,作为方向选择的根据)

### 2.1 领域现状(地图口径,2026-10)

- **七条路线**(模型/TAMP、RL、模仿示教、VLA、世界模型、本体/灵巧/人形、组合 Agent)+ 数据/评测底座。当前最强系统在 **G3—G4 之间**(开放物体/场景泛化 ↔ 新任务少样本),且"强"只在特定任务族、本体、时间跨度内成立(地图 §1.3)。
- **VLA 已成主干但未通关**:语义泛化"第一公里"解决,物理可靠性"最后一公里"未解决;竞争已从"谁的模型大"转向"数据质量、动作接口、后训练、系统集成"(地图 §8.2、判断 1)。
- **2025—2026 四个转折**(地图 §2.4 结论三):①离线模仿 → 部署中 RL(π*0.6 RECAP、LWD);②视频生成 → 世界—动作模型(Cosmos 3、VLA-JEPA、ABot-PhysWorld);③基准排行榜 → 分布式真实评测(RoboArena)与评测有效性反思;④**任务接口从语言扩展到视频演示/物理提示**(GEN-1.5、Skild S1、RoboTTT)。

### 2.2 高影响 × 可行象限(地图 §6.8)

近期(1—2 年)最该做的是"高影响、低难度"基础设施:**评测协议、数据/动作空间对齐、失败/恢复数据**。我们选的三个领先点恰好落在:scaling 曲面+换算率 = 评测协议与数据效率的交叉;失败归因 = 失败数据。

### 2.3 本周(2026-10-20—27)新信号,验证方向窗口正开

- arXiv cs.RO 最近一周出现 **ICL-for-manipulation 论文集群**(2026-10-27 arXiv API 检索,"retrieval/in-context + manipulation",20 条):

## 3. 方向选择:主攻一个,其余不碰

### 3.1 主攻:「演示即上下文」的可信测量与改进

**一句话**:让机器人"看一遍演示就会新任务"的方法正爆发,但领域不知道**这些方法在什么条件下值得用、一条演示到底值多少、失败了该怪哪一段**——我们把这三件事做成可复算的协议、曲线和改进方法。

**选它的五个理由**:
1. **地图背书**:物理提示/ICL 是 8.10 五条新线索之首、被列为对地图的五点修正之一;评测有效性是十个判断里的判断 7("最被低估的瓶颈")。两个判断的交集只有这一个方向。
2. **硬件与算力完全匹配**:免训练 = 单张 4090 可做全部仿真实验(不训练大模型);Sawyer×2 = MT3 原生平台(复现零适配);RealSense×3 支撑多视角变量;无触觉硬件**不构成本方向约束**(本方向不依赖触觉)。领域里 90% 的热方向(VLA 训练、WAM、人形全身控制、触觉基础模型)我们都没有算力/硬件入场券,这个方向有。
3. **积累可复用**:9 篇邻居论文已 abs 级核实、检索式设计空间规格书 v0.1 已写(46KB)、12 件测量协议要素已逐条溯源、失败归因重框已设计。换方向 = 全部作废。
4. **成果形态可领先**:测量协议+曲线+开源代码是"别人无法绕开"的成果(地图 §10.4 给研究者:"选一个可测量的 gap,做某个评测协议的第一")。方法论文要赢过 π*0.6/GEN-1.5 级别的算力,协议论文不需要。
5. **窗口正开但未关**:ICL 方法在爆发,测量学空着;等别人填上就没有"第一"了(地图教训:方法产出极快时"方法缺口"是易腐品——所以我们做的正是**不易腐的测量品**)。

### 3.2 明确不做的(负清单,防注意力稀释)

- 不训练/微调 VLA(算力不允许,且地图 §10.5:不要做"在 OXE 上再训练一个更大 VLA"的同质化工作);
- 不做人形/全身控制、世界模型训练、触觉基础模型(无硬件/算力入场券);
- 不做"又一个短程桌面基准"(除非诊断具体失败模式——我们的协议附属于方法比较,满足这条);
- 世界模型动作条件因果诊断(地图选题二第一步)登记为 **G4 前置探索备选**,本季度不启动。

### 3.3 感兴趣的理由(委托人要求"找寻感兴趣的方向",明说)

这个方向本质上是回答"**一条演示里到底有多少信息、怎么把它榨干**"——它是机器人版的 in-context learning,兼具认知科学味道(人类看一遍就会,凭什么?)和工程价值(每个新任务几百条遥操作轨迹的成本结构被改写)。它小到 4090 能做完,大到可能改写"教机器人"的成本函数——这种"小切口、大回声"是值得投入两年的形状。

## 5. 实验方案(简单可行,四层递进)

> 共同约束:仿真实验全部在单张 4090 上可跑(免训练);真机实验只动 Sawyer×2 + RealSense×3(红色动作由真人执行,Dexter 出规格与判据);所有比较**同预算、同起点、配对检验、≥3 seeds、报置信区间**(协议要素继承 10-15 规格书 12 件,不重复发明)。

### E0 环境验证与复现冒烟(第 1 周,前置,不改结论)

- **做什么**:4090 机器上 `git clone github.com/kamil-dreczkowski/learning_thousand_tasks`(MIT),按 README 跑通 1 个已训练 checkpoint 的部署示例与 1 个任务的评测循环;记录环境、依赖版本、单 episode 耗时。
- **验收判据**:README 流程可走通或卡点清单明确(卡哪一步、报什么错);单任务评测耗时 < 2 min/episode(MT3 论文口径 1—2 min)。
- **风险/降级**:Docker/驱动问题 → 记录后换 conda 裸装;checkpoint 未随 repo 发布 → 转 E1 自训检索库(MT3 训练脚本在 repo 内,70 物体库规模缩减为 20 任务仍可验证管线)。
- **产出**:`journal/daily/` 复现环境记录 + E0 报告(半天工作量级别)。

### E1 复现 + 阶段级失败解剖(第 2—3 周,仿真,零训练)

- **做什么**:在 LIBERO(或 MT3 自带任务分布)上复现检索式基线;对失败 episode 做**阶段级标注**(接近/抓取/搬运/放置),统计失败集中在哪个阶段、检索错在哪个环节(没检到对的演示 / 检到了但上下文没用好)。
- **指标**:总成功率;阶段级失败占比;检索命中率(检索回的演示是否与目标任务同任务/同物体)。
- **统计**:≥3 seeds × 每任务 ≥20 rollouts;配对 bootstrap 置信区间;检验力告警(n≤4 时最小 p≥0.125 不得判"无差异",继承规格书 L2 底线)。
- **产出**:复现报告(含与论文数字 78.25%/68% 的口径对照,**不得直接当本平台验收目标**,继承 A-020 禁令)+ 失败解剖表。这份解剖表直接成为 E3 真机实验的设计依据。

### E2 检索-上下文 scaling 曲面 + 单演示换算率(第 4—7 周,4090 主战场,零训练)★核心产出

- **做什么**:
  1. **曲面**:固定评测任务集(≥20 任务),扫三个轴——库规模 N ∈ {10, 25, 50, 100}(每任务演示条数)、检索条数 K ∈ {1, 2, 4, 8}、上下文长度(喂给策略的历史长度)∈ {单步, chunk, 全轨迹}——得成功率的 N×K×L 曲面族与**等预算 isoquant**(同等"演示总成本"下哪种配置最优);
  2. **换算率**:固定目标任务,对照"0/1/2/4/8 条演示的免训练检索"vs"0/25/50/100/200 条演示的监督后训练"(在可训练的小策略上,如 diffusion policy 小模型),拟合两条曲线,给出**等效点:1 条演示 ≈ x 条训练轨迹**及其任务族差异;
  3. **检索度量消融**:位姿-几何解耦双通道 vs 单通道嵌入(Pareto 支配单标量,继承 P2 设计)。
- **指标**:成功率曲面、isoquant、换算率等效点 x(±CI)、检索命中率。
- **判"领先"的口径**:检索时先用 Google Scholar/arXiv/OpenReview 核"retrieval scaling / demonstration-equivalent"无占位(每月复核);报告写作口径为"首次在免训练检索式操作策略上系统测量 X",**不做"无人做过"的全称断言**。
- **产出**:测量报告 v1(可投 RA-L / CoRL workshop / ICRA 2027)+ 开源评测代码与曲线数据。
- **风险/降级**:换算率对照的"训练侧"若算力吃紧 → 缩到单任务族 + 公开曲线注明覆盖范围;若发现 RoboTTT 已覆盖某轴 → 该轴降为复现对照,主贡献移到未覆盖两轴。

### E3 真机单演示适配 + 干预实验(第 8—14 周,Sawyer×2 + 1×RealSense 起步,真人执行)

- **做什么**:20 个桌面任务(继承 M0 母实验设计:每任务 1 条演示 + 评分标定 + 基线);跑免训练检索策略,记录全部失败;对失败做**归因×干预匹配**(哪个阶段失败 → 施加对应干预 → 是否恢复),回答"闭环该修哪一段"。
- **指标**:单演示适配成功率;阶段级失败分布(与 E1 仿真对照);干预后恢复率;每任务人工干预次数。
- **统计**:每任务 ≥20 试次 × 2 臂;报告置信区间与失败案例全部视频留档(可复算)。
- **红线**:真机执行由真人操作,Dexter 只出规格、协议与判据(宪法硬边界);力/安全限按 MT3 原生 Sawyer 配置。
- **产出**:真机论文(目标 RA-L 或 Sci. Robotics 短文级)——"单演示适配的失败解剖与干预协议"。
