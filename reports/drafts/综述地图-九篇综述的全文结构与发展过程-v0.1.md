## 0. 先说这个方法本身的偏置（否则后面的图会被误读）

读综述不是"中立的取地图"，理由见 §6 的实测：**每篇综述的参考文献构成由它的标题决定，不由领域构成决定**。
所以本件不是"读一篇综述得到地图"，而是"**读九篇不同宣告范围的综述，看它们在哪一层上收敛**"。

**选法**：OpenAlex 按 `cited_by_count` 排序 + 主题词约束（6 条检索式）→ 82 篇候选 → 取被引最高且**有 arXiv HTML 全文**者。**这是便利抽样，不是系统抽样**（见 §7 诚实 1）。

## 2. 核心发现：九篇综述用的是**四条轴**，没有一篇用我的轴

**把九篇的顶层章节摊开，主轴只有四种**：

| 轴 | 问的是 | 代表 | 顶层章节（原文） |
|---|---|---|---|
| **A 方法轴** | 怎么迁 | S1 | Methodologies for Sim-to-Real / Application Scenarios |
| **B 学习对象轴** | **学的是什么** | S2 | Object and Environment **Representations** / Transition **Models** / Skill **Policies** / **Preconditions and Effects** / **Compositional and Hierarchical** Structures |
| **C 系统部件轴** | **改的是哪一块** | S4 | Embodied **Robots** / Embodied **Simulators** / Embodied **Perception** / Embodied **Interaction** / Embodied **Agent** / Sim-to-Real |
| **D 资源轴** | **用什么做的** | S5 S6 S8 S9 | **Datasets** / **Benchmarks** / **Data Engines** / **Simulators** / **Robot Hardware** |
| （C′ 任务-控制轴） | 接触怎么做 | S3 | Tasks requiring manipulation in contact / **Control** / **Representing** / Learning and planning |

**我此前那八条路（R1–R9）用的是第五种轴：**「**通用性从哪来**」——H1 覆盖 / H2 组合 / H3 语义 / H4 时间。

> **九篇综述里，一篇都没有这个轴。**

### 这解释了我前面所有的不顺

| 我遇到的麻烦 | 真正的原因 |
|---|---|
| 40 篇抽样里 **40% 装不进八条路** | 那些论文是按**部件/资源**组织的，不是按"通用性来源"组织的 |
| 我不得不补 **R9 感知/建图/导航**（占 30%） | 在 S4 里它是 **§IV Embodied Perception**，是**顶层章节**，不是"补一条路" |
| 我不得不承认组件轴缺"**本体/机构**" | 在 S4 是 **§II Embodied Robots**、在 S6 是 **§VI Robot Hardware**，也是**顶层** |
| 我以为"8×3=24 格"很整齐 | 整齐是因为我按自己的轴切；共同体的轴根本不用"3"这个数 |

> **判（本件最重要的一句）**：**"通用性从哪来"是一条分析轴，不是领域的地图轴。**
> 它适合回答"为什么这个方法会泛化"，不适合回答"这个领域在做什么"。
> **我把分析轴当地图轴用了四轮**——这是前面所有"覆盖率不足""要补路""残差太多"的总根源。
> **修法不是继续补路，是把主轴换掉**：以共同体的轴（B/C/D）为主，我的轴降为**副轴**（见 §7）。

## 3. 研究发展过程：**方法 → 学习对象 → 系统部件 → 资源**

这是从"综述选择怎么组织自己"读出来的分期，不是从成果时间线读出来的。

| 时期 | 主流组织方式 | 证据（顶层章节） | 该期隐含的判断 |
|---|---|---|---|
| **2020** | **按方法** | S1：Methodologies for Sim-to-Real | 瓶颈在"迁移算法" |
| **2021** | **按学习对象** | S2：表示 / 转移模型 / 技能策略 / 前置-效果 / 组合分层 | 瓶颈在"该学什么" |
| **2022** | **按任务-控制-表示** | S3：Tasks / Control / Representing / Learning&Planning | 瓶颈在"接触怎么控" |
| **2024** | **按系统部件** | S4：**机器人 / 仿真器 / 感知 / 交互 / 智能体** | 瓶颈在"哪一块不够" |
| **2024–25** | **按模型 + 资源** | S5/S6：VLA Models / Datasets,Benchmarks / Simulators（S6 加 **Robot Hardware**） | 瓶颈在"模型与数据" |
| **2026** | **按资源** | S8：Datasets / Benchmarks / **Data Engines**；S9：Real-Robot / UMI / Egocentric / Simulation / General **Data** | **瓶颈在"数据从哪来"** |

**两处独立证据支持 2026 这一期**：S8（2026-04）与 S9（2026-07）**彼此不知情、机构不同，却都把资源放在顶层、把模型放进"应用"一章**。

> **判**：**领域对自己的描述，从"我们有什么算法"移到了"我们有什么数据"。**
> 这不是修辞变化：**按资源组织知识，等于宣称瓶颈是资源不是想法。**
> 这个判断可检验（§5 的 S8 原话给了同一判断）。

## 6. 偏置检验：**综述的参考文献构成 ≠ 领域的实际构成**

对每篇综述的参考文献标题做同一套关键词分类（与 §3.1 同规则），再与无偏随机样本（400 篇 cs.RO，主贡献口径）对照：

| 主题 | S2 (2021) | S4 (2024) | S5 (2024 VLA) | S9 (2026 数据) | **领域实际** |
|---|---|---|---|---|---|
| 强化学习 | **15.0%** | 2.6% | 6.9% | 3.1% | **11.8%** |
| 感知 / SLAM / 导航 | 5.5% | **18.1%** | 3.0% | 2.6% | **30.0%** |
| VLA / 语言条件 | **0.7%** | 13.2% | **18.8%** | 14.1% | 7.5% |
| 数据 / 基准 | 3.2% | 10.1% | 6.9% | **34.0%** | 15.0% |
| 技能 / 分层 | 12.0% | 1.8% | 3.0% | 3.1% | 7.5% |
| 抓取 | 10.0% | 4.4% | 0.6% | 3.1% | — |
| 触觉 / 接触 | 5.0% | 9.3% | **0.0%** | 6.2% | 0% |
| **扩散 / flow 策略** | **0.0%** | **0.0%** | 1.2% | 0.2% | 默认骨架 |

**四条判读**：

1. **每篇综述的参考文献构成由它的标题决定**。S5（VLA 综述）引 18.8% VLA、**0% 触觉**；S9（数据综述）引 34% 数据。**这是"透镜"，不是"地图"。**
2. **没有任何一篇的构成接近领域实际**。感知/SLAM 实际占 30%，在 S5 只占 3.0%、S9 只占 2.6%；只有范围最宽的 S4 到 18.1%。
3. **RL 被系统性低估**：实际 11.8%，四篇综述分别 15.0/2.6/6.9/3.1%（除 2021 那篇外全部低于实际）。
4. **扩散/flow 在四篇综述里几乎不存在（0–1.2%）**，而它是当前策略的默认骨架。→ **印证上一件的发现：方法成为默认后，名字会消失，综述继承了这个盲点。**

> **方法学结论（本件对"换思路"这件事的交代）**：
> **"读综述"不是"拿到地图"，是"拿到 N 个透镜"。**
> 要得到地图，必须（a）选**宣告范围不同**的综述（方法 / 学习对象 / 部件 / 资源各一），并且（b）**用无偏产出样本做对照**。
> **只读同一轴的综述（比如只读三篇 VLA 综述），会把 18.8% 的 VLA 当成领域的 18.8%——而它实际是 7.5%，同时看不见 30% 的感知。**

## 8. 诚实清单

1. **九篇是便利抽样**：按被引排序 + "有 arXiv HTML"这个可用性条件筛出来的。**被引高 ≠ 最有代表性**，且 2026 年的两篇被引还很低（发表不足半年），我是**按"最新"而非"最有影响"纳入的**。
2. **章节结构是从 HTML 的 `<h2>` 机械抽取的**，`<h3>` 全部为 0——说明这些综述用**加粗行内标题**而非子章节。所以"顶层章节"是可靠的，**子层级不可靠、未使用**。
3. **参考文献构成用标题关键词分类**，标题短、术语少，**误差明显大于摘要级分类**。§6 的表只能读**量级与方向**，不能读精确比例。
4. **S8（2604.23001）的 HTML 无 bibitem**（refs=0），因此它不参与 §6；其词数 10.7k 明显短于其他（28–45k），**可能是不完整版本**。
5. **"方法→学习对象→系统→资源"这个分期是我读出来的**，不是任何综述自己说的。**九篇综述没有一篇回顾"综述体裁怎么变"**。这条最容易被质疑为叙事。
6. **S5/S6/S7 的被引数没取到**（OpenAlex 未索引或为 0），表里留空——**不能用它们排影响力**。
7. **本件没有回答"哪一行最重要"**。共同体的轴是**并列的**（S4 把六章并列），并列本身不携带优先级。**优先级只能由本所自己的判据给**，那是下一件的事。
