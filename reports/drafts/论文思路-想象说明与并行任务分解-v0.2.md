# Part 0 · 一页纸总览(给忙碌的人看这一段就够)

**背景锚点论文**:《Learning a Thousand Tasks in a Day》(MT3),Science Robotics 2025,
Imperial College Robot Learning Lab。**它做什么**:把机器人操作轨迹拆成
**alignment(对准)阶段 + interaction(交互)阶段**,用**检索**(而非训练策略网络)
在测试时调出最相似的一条演示来执行;**每个任务只要 1 条演示**;一台 **Sawyer** 机械臂
+ 单个 RealSense D415,**17 小时**教会机器人 **1,000 个日常任务**;**完全不训练
策略网络**(免训练、轻算力)。

**为什么我们以它为基底**:① 它的硬件**就是我们的硬件**(Sawyer + RealSense);
② 我们**已有复现基础**(不必从零复现);③ 它**免训练**,单张 4090 就够;
④ 它**自己诚实承认了四个缺口**,而这四个缺口**恰好对应我们要做的四个方向**。

**MT3 的四个自陈缺口 = 我们的四个机会**:
1. **没有触觉** → 形变物体、高精度插入、抓取都失败(论文原话:只靠视觉
   "无法推断形变物体的动态属性")。
2. **开环执行 + 单步交互** → "轨迹一旦开始,就没有机制检测错误或中途调整"
   (open-loop 在全文出现 13 次);每个任务只是"单次交互",多步任务没真机验证。
3. **单一本体** → 全文 "embodiment" 出现 0 次,完全没做跨机械臂迁移。
4. **检索的内禀缺陷** → "本质上无法在演示之间插值";检索时"位姿相似"与
   "几何相似"两个目标互相打架;检索是失败主因(占 22.3%)。

**四条能力透镜(我们的四个研究方向)**:① 泛化与数据效率 / ② 触觉与多模态 /
③ 语言条件长程 / ④ 数据采集与合成。

**顶层科学问题(所有路径殊途同归指向它)**:
> **具身操作策略的能力边界由什么决定?什么任务该走什么路径?**
> ——产出一张"任务族 × 方法路径"的**条件表**,而不是又一个孤立的 SOTA 数字。

**三种方法论范式(三条研究路径,各自押注瓶颈在哪,不必对撞)**:
- **端到端**:赌瓶颈是**规模/数据**——单一模型 + 海量数据能走多远?(RT-2/OpenVLA/π0)
- **分层(结构化分解)**:赌瓶颈是**结构/效率**——显式中间表示能用更少数据换更多能力?
  (**MT3 属这一路**;LiMA/世界模型/记忆)
- **agentic(资产外化)**:赌瓶颈是**外化/复用**——能力能否外化成可复用资产?
  (WAA/K1/RAPID;**MT3 的检索库配上 LLM 路由就变成 agentic 资产**)

**并行分配总览(4 个 track,可分给 4 组人)**:

|---|---|---|---|---|---|
| **A** | ② 触觉 | 2A 闭环交互 / 2B 阶段消融 | **需触觉硬件**(Realman FT?柔性夹爪触觉?) | 4-8 月 | 能力推进 |

# Part 1 · 顶层科学问题与框架(讲清"我们在做什么、为什么这么做")

## 1.1 研究框架:科学问题 → 研究路径 → 创新方法

我们用三层结构组织所有工作(这是委托人定的框架):

- **科学问题**(最上层):要回答的根本问题。**所有路径殊途同归指向它。**
- **研究路径**(中层):解决科学问题的**不同攻法**。**路径之间不要求合并**——
  各路径可独立深入;横向对比**只在某路径卡住时**用来找新思路,**不是为评出谁赢**。
- **创新方法**(下层):每条路径上的具体技术贡献。

## 1.2 顶层科学问题(一句话 + 展开)

> **具身操作策略的能力边界由什么决定?什么任务该走什么路径?**

**展开**:当前领域有三条方法论范式(端到端/分层/agentic),各自报告亮眼的数字,
但**用的是不同基准、不同协议、不同本体**,导致**没人能真正比较它们**,也没人
说清"**什么样的任务,用哪条路径最划算**"。我们的目标**不是再造一个更强的模型**,
而是**在一个统一的受控基底(MT3 + Sawyer + 固定任务集 + 固定评价协议)上,
沿四条透镜各自推进,逐步拼出一张"任务族 × 路径"的条件表**。

**这张条件表怎么拼出来**:不是一次大对撞,而是**每篇论文贡献表的一块**——
- 透镜① 的论文贡献"少演示区间,泛化靠规模还是结构"那一块;
- 透镜② 的论文贡献"接触富集任务,触觉在哪个阶段值多少"那一块;
- 透镜③ 的论文贡献"长程任务,语言该在哪一层消费"那一块;
- 透镜④ 的论文贡献"数据该采/造/推理回收,配比怎么定"那一块。

## 1.3 三条方法论范式:定位、解决的问题、现有方案(回答"端到端属哪个路径")

**端到端、分层、agentic 是三条并列的研究路径(方法论范式),不是必须对撞的三方。**
每条是对"操作能力瓶颈在哪"的不同押注:

### 端到端(end-to-end VLA)
- **押注的瓶颈**:**规模 / 数据**。
- **根本上解决的领域问题**:"能否用**单一模型**把感知-语言-动作压进权重,
  靠**数据规模 + 跨本体共训练**获得泛化?这条路能走多远?"
- **现有代表方案**:RT-2(语言 grounding 进 VLA)、OpenVLA(7B,970k 演示,
  29 任务较 RT-2-X +16.5% 而参数 1/7)、π0 / π0.5(VLM 上流匹配,RSS 2025)、
  GAM(LIBERO-Pro 61% vs π0.5 53%)、OXE/RT-X(22 本体/1M+ 真机轨迹的规模供给)。
- **它的强项**:规模上去后泛化上限高。**它的软肋**(领域已观察到的):
  语言措辞脆弱(π0.5 "switch on the stove" 100% vs "switch on the hot plate" 2%);
  数据成本高;可解释性差。

### 分层 / 结构化分解(hierarchical / structured decomposition)
- **押注的瓶颈**:**结构 / 效率**。
- **根本上解决的领域问题**:"能否引入**显式中间表示**(任务分解/世界预测/记忆),
  把**慢意图与快执行解耦**,用**更少数据**换更高效率与可解释性?这条路能走多远?"
- **现有代表方案**:
  - **双系统**:LiMA(异步双系统,延迟较 Cosmos-Policy 降 45.8%)、Rolling-WAM(滑窗错峰,4.5× 重规划提速);
  - **世界模型(WAM 系)**:DexTacWAM / VT-WAM / TacWAM(预测未来触觉/状态);
  - **记忆**:ReCAT(Mamba-2 循环记忆)、ADM-Planner(持久工作区知识);
  - **分解+检索**:**MT3(我们的基底)**、MimicGen 系(数据引擎分解)。
- **它的强项**:数据效率高、可解释、轻算力。**它的软肋**:中间表示的设计依赖
  任务结构;分解可能破坏跨任务的表示共享(MT3 全文自陈:"decomposition
  prevented this beneficial representation sharing")。

### agentic / 程序合成与资产外化
- **押注的瓶颈**:**外化 / 复用**。
- **根本上解决的领域问题**:"能否把长程能力**外化成可复用的程序/工具/技能资产**,
  用 VLM/LLM 做高层 harness,**演化期生成、部署期调用**,从而几乎不依赖策略训练数据?
  这条路能走多远?"
- **现有代表方案**:WAA(视觉动作工作区+动作排练,LIBERO-Pro 75.6%)、
  Robo-Harness K1(感知做成工具,77.8%/88.9%)、RAPID(单条人演→编码代理循环)、
  RACaP(演化期编码+部署期 ReAct 调冻结 Policy API,13.2× 加速)、
  DexAgent(技能+验证器)、Recursive Harness Distillation(playbook,真机 37.3%→64.0%)、
  DREAM(部署期演示生成)。
- **它的强项**:零/少训练数据、长程组合、可复用。**它的软肋**:依赖高层模型
  (LLM/VLM)的可靠性;资产质量没有评测口径;失败模式是"幻觉出不连贯的任务序列"
  (MT3 Appendix F 自陈)。

## 1.4 为什么"殊途同归、不必对撞"(委托人 2026-10-13 框架更正)

**三条路径不是同一道题的三个竞争答案,而是对"瓶颈在哪"的三个不同押注。**
- 端到端赌"规模就是一切";分层赌"结构比规模划算";agentic 赌"能力该外化成资产"。
- **各自把押注推到极致,都是对顶层科学问题的贡献**——端到端告诉我们规模的上限,
  分层告诉我们结构的效率,agentic 告诉我们外化的复用性。**合起来才是完整的条件表。**
- **对撞(同预算受控对比)只在两种情况下才需要**:
  ① 你**专门想做一个基准贡献**("同预算下谁强"是一类窄但有效的论文);
  ② 某条路径**卡住了**,想借另一条的思路找突破口。
  **对撞是可选工具,不是每篇论文的义务。**
- **我们的处境尤其不必对撞**:我们有 **MT3 复现基础**,MT3 属**分层路径**;
  我们最有优势的论文是"**在分层路径上攻 MT3 的四个缺口**"——这是**能力推进型**
  论文,**不需要拉端到端/agentic 来对撞就能独立成立**。
- **一个有用的桥**:MT3 的检索库(534 micro skills)是**分层路径的产物**,
  但配上 LLM 路由就**变成 agentic 资产**——**沿分层往前走,自然走到 agentic**,
  不必"跳过去对撞"。

## 1.5 路径分类:能力推进型 vs 基准对撞型(决定并行分配逻辑)

| 类型 | 含义 | 路径 | 并行适配性 |
|---|---|---|---|
| **能力推进型** | 把一条范式推得更远(攻某个缺口) | 1A 跨本体 / 1B 检索度量 / 2A 闭环交互 / 2C 触觉检索 / 3A 检索库→agentic / 3C 记忆恢复 / 4C 翻新喂库 | **高**(各攻不同缺口,彼此独立,最适合并行) |
| **基准对撞型** | 比较范式或条件(需共享协议) | 1C 分解vs单体scaling / 3B 三力对撞 / 4A 检索库vs训练集 / 4B 阶段配比 / 2B 阶段级消融(半对撞) | **中**(需统一对撞协议,宜串行协调或由共享基底组统管) |

**分配原则**:**能力推进型优先并行**(独立性强);**基准对撞型**要么由共享基底组
统一做(保证协议一致),要么放在能力推进型有结果之后再做(届时有自产数据可对撞)。

# Part 2 · MT3 共同基底(讲清"我们站在什么之上")

## 2.1 MT3 是什么(给没读过原文的人)

- **核心思想**:不训练策略网络,而是**把演示存成检索库**;测试时**检索**最相似的
  一条演示来执行。
- **两阶段分解**:
  - **alignment(对准)**:把末端移动到"适合开始操作的位姿"——**只有终点重要,
    路径不重要**;用**解析式位姿估计 + 运动规划**完成(不是学出来的)。
  - **interaction(交互)**:实际操作——**需要精确轨迹**;用**开环回放**演示的
    末端速度序列完成。
- **检索机制(两级)**:① 用**语言模板匹配**从任务描述抽出 micro skill 名
  (如 "open bottle"),过滤出同类演示;② 用 **PointNet++ 几何编码器**把目标物体
  点云编码,取**余弦相似度最高**的那条演示。**检索在执行前一次性完成,两阶段共用。**
- **泛化机制**:把新物体**当作最近邻那个训练物体**,用刚性配准($T_\delta$)吸收位姿差。
- **规模**:一台 Sawyer,17 小时,1,000 个任务(31 macro skill × 534 micro skill ×
  402 个物体),每任务 1 条演示;seen 任务成功率 78.25%,unseen 68%。
- **免训练**:MT3 本体不训练任何策略网络,只用三个**预训练/现成组件**
  (PointNet++ 编码器、位姿回归器+ICP、Grounding DINO+XMem 分割)。

## 2.2 为什么 MT3 是我们的理想基底

1. **同平台**:MT3 = Sawyer + RealSense D415 + Robotiq 2F-85;**我们有 2 台 Sawyer
   + 3 台 RealSense**——复现零成本。
2. **已有复现基础**:委托人明示已复现过 MT3 方法——**新论文在此之上创新会更快**。
3. **免训练 + 轻算力**:不训策略网络,**单张 4090 极其充裕**(对比:训 π0/OpenVLA
   全参微调单卡放不下)。
4. **四个缺口清晰**:MT3 自己诚实列出的局限,**恰好对应我们的四条透镜**——
   我们不是"打败 MT3",而是"**在 MT3 的受控基底上,攻它的某一个缺口**"。
5. **任务 taxonomy 可复用**:31×534×402 的任务清单在原文附录完整给出——
   **我们不必重采 1,000 任务,选 20-100 个子集即可**。

## 2.3 MT3 四大自陈缺口 → 四透镜(逐字证据)

| 缺口 | MT3 原文逐字(英) | 对应透镜 | 我们的机会 |
|---|---|---|---|
| **①无触觉** | "Our reliance on **vision alone** made it impossible to infer dynamic properties of **deformable objects without tactile feedback**" | ② | 加触觉/力反馈,攻形变物体/高精度插入/抓取失败 |
| **②开环+单交互** | "**Once a trajectory begins, there is no mechanism for the policy to detect errors or adjust a course mid-execution**"(open-loop ×13);"each task involved a **single interaction**" | ②③ | 闭环纠错(②);长程 chaining + LLM 路由(③) |
| **③单本体** | `embodiment` 全文 **0 命中** | ① | 跨本体迁移(Sawyer↔Realman) |
| **④检索内禀缺陷** | "retrieval... **fundamentally could not interpolate**";"位姿 vs 几何 **fundamental tension**";检索=失败主因 **22.3%** | ①④ | 改检索度量;检索库作为"资产"的数据观 |
| (附)**长程仅 PoC** | Appendix F 用 **Grok 3** + micro skill CSV 做检索 PoC,**无真机成功率**;"**hallucinating incoherent task sequences**" | ③ | 把 PoC 做成严格的 agentic 资产评测 |

## 2.4 引用 MT3 时的两个陷阱(所有 track 必读)

1. **"数量级改进"归给分解,不是检索**:原文 "In the few-demonstrations-per-task
   regime (<10 demonstrations), **decomposition** achieves an order of magnitude
   improvement... **with** retrieval consistently outperforming behavioural cloning"。
   → **分解(vs 单阶段)= 数量级;检索 > BC = 定性"一致优于"**(具体数字在 Figure 4.C
   图内,文本无)。**引用务必分清,不得把"数量级"安到"检索 vs BC"头上。**
2. **图内数字本地不可得**:per-method × per-demo 的成功率表、per-macro-skill 成功率
   都在 Figure 4/6(外部图像)。**文本内可引数字仅**:78.25%(seen)/ 68%(unseen)/
   >80%(wipe/stir/place/grasp)/ 失败分布(检索 22.3% / 位姿 23.9% / 分割 19.5% /
   其余 29% 含抓取 20.2%)/ "3 demos 打 50 demos"。**需要图内数字须另取
   Science Robotics 定稿或图像。**

# Part 3 · 四透镜:科学问题与研究路径(每透镜 2-3 条,可独立并行)

**每透镜结构**:科学问题 → MT3 对应缺口 → 研究路径(各含创新方法/硬件/工期/类型)。

## 3.1 透镜① · 泛化与数据效率

**科学问题**:在**少演示区间(<10 demos/task)**,泛化来自"数据规模"还是
"结构先验(分解+检索)"?其**能力边界**(何时失效、与单体 BC 的交叉点)由什么决定?

**MT3 缺口**:④检索内禀缺陷 + ③单本体 + scaling 交叉点未测。

**路径**:
- **1A 跨本体检索迁移**(能力推进):Sawyer 检索库零样本/少样本驱动 Realman,
  设计跨本体对齐层(MT3 alignment 是解析式位姿映射,天然适合改造)。攻缺口③。
  硬件:2 Sawyer + 2 Realman + 3 RealSense + 4090。工期 6-9 月。
  替代锚点:Morphometric(跨手重定向 89.3%)。
- **1B 检索度量改进**(能力推进):攻"位姿 vs 几何张力"+"不能插值"——
  解耦双通道检索 / top-k 插值 / 任务感知几何特征。硬件:2 Sawyer + 4090。
  工期 4-6 月。
- **1C scaling 交叉点测定**(基准对撞):MT3 说"单体 BC 数据够多会反超"但没测
  交叉点;系统扫 1→50+ demos 找交叉点。**填透镜① 最大开放问题"数据成本-成功率
  可比表"**。硬件:2 Sawyer + 4090,**不需新硬件**。工期 3-4 月(**最快**)。

## 3.2 透镜② · 触觉与多模态(硬件最独特,但依赖触觉硬件明示)

**科学问题**:接触信息(触觉/力)在操作的"**哪个阶段、什么条件下**"产生边际价值?
——不是"有没有用"(已有定论:条件性有用),而是"**怎么用、何时用**"。

**MT3 缺口**:①无触觉(MT3 自己点名是形变物体失败根因)+ ②开环无中途纠错。

**路径**:
- **2A interaction 阶段闭环化**(能力推进,**最推荐**):MT3 interaction 是开环回放,
  加触觉/力反馈做**执行中纠错**(插入检测到接触力异常→微调;形变物体检测滑动→调握力)。
  **直接回应 MT3 自陈的形变物体/高精度插入/抓取失败**。
  硬件:2 Sawyer + **Realman FT(若带)** + **柔性夹爪集成触觉(待明示,关键)** + 4090。
  工期 6-8 月。
- **2B 阶段级触觉消融**(半对撞):借 MT3 分解做"逐阶段加减触觉"受控对撞
  (升级 When Does Touch Matter? 的"逐模态加减"到"逐阶段")。
  硬件:2 Sawyer + **Realman FT(若带则无需柔性夹爪触觉)** + 4090。工期 4-5 月。
- **2C 触觉做进检索度量**(能力推进):MT3 检索用几何,加触觉签名区分
  "几何相似但接触特性不同"的物体(攻"形变物体 despite visual similarity 失败")。
  硬件:同 2A。工期 7-9 月。替代锚点:VisTacAlign / UVTA。

**⚠️ 透镜② 的硬件前置门**:2A/2C 需触觉硬件;**须先明示** Realman 是否带末端 FT +
柔性夹爪是否集成触觉。若都不到位,透镜② 改用 WAM 系(DexTacWAM/VT-WAM/TacWAM)
或 OpenViTac 作替代锚点(**但脱离 MT3 复现基底,工期上调**)。

## 3.3 透镜③ · 语言条件长程(纯仿真为主,4090 可跑,不依赖新硬件)

**科学问题**:语言条件长程操作的能力该"**学进权重**"(端到端)、"**留在慢系统**"
(分层)、还是"**外化成可复用资产+推理路由**"(agentic)?——**各路径可独立推进,
不必对撞**(对撞版 = 路径 3B,可选)。

**MT3 缺口**:②开环单交互(多步靠 chaining,真机未验证)+(附)长程仅 Grok 3 PoC。

**路径**:
- **3A 检索库作为 agentic 资产 + LLM 路由**(能力推进,**分层→agentic 桥**):
  把 MT3 的 534 micro skill 检索库当技能库,用 LLM agent 做长程任务分解→检索路由→
  失败重规划;**把 MT3 Appendix F 的 Grok 3 PoC 做成严格评测**。
  创新点:①资产质量度量(复用率/跨任务迁移率,填"agentic 资产没有评测口径"的空白);
  ②失败重规划(攻"hallucinating incoherent task sequences")。
  硬件:2 Sawyer + 4090(跑 Qwen3.5-9B/Qwen3-VL-8B 级)+ 端侧板(可选机载路由)。
  工期 5-7 月。替代锚点:WAA / K1 / RACaP。
- **3B 三力受控对撞**(基准对撞,**可选**):同基准(LIBERO-Pro/RoboTwin 2.0,4090 可跑)
  对撞端到端/分层/agentic。**不需新模型,只需诚实对撞协议——填综述最大缺口
  "对撞缺席"**。硬件:4090 纯仿真。工期 3-5 月(**最快之一**)。
  **⚠️ 守数字并列守则**:LIBERO-Pro "五个数字至少四种设定",须标口径,不得跨设定并列。
- **3C 长程记忆 + 失败恢复**(能力推进):MT3 无记忆无纠错,加显式记忆
  (ReCAT/ADM-Planner)+ 失败恢复(MAIL-Bench)。硬件:2 Sawyer + 4090。工期 7-9 月。

## 3.4 透镜④ · 数据采集与合成(纯计算,不依赖真机/外部平台)

**科学问题**:机器人数据该"**采更多**"(工业化)、"**造更多**"(合成)、还是
"**推理出来+回收回来**"(agentic/翻新)?混合配比的最优解?

**MT3 缺口**:④检索库作为"数据当检索库不是训练集"的范式(挑战"数据当工业品")。

**路径**:
- **4A 检索库 vs 训练集的成本-收益对撞**(基准对撞):同一数据集(DROID/OXE 子集,
  公开)对比"建 MT3 检索库"与"训策略(MT-ACT+/DP)"的成本-收益曲线。
  **挑战"数据当工业品"的默认假设**。硬件:4090 纯计算,**不依赖真机/外部平台**。
  工期 3-4 月(**最快之一**)。
- **4B alignment 真机 / interaction 合成的阶段级配比**(能力推进,**须等外部平台**):
  借 MT3 分解测"哪个阶段用真机、哪个用合成"。扩展 G2 数据引擎规格书的配比实验。
  **硬阻塞:须等 G2 v1.1 真人试制反馈**。工期:反馈及时则 5-7 月。
- **4C 失败数据翻新喂检索库**(能力推进):MT3 只存成功演示,加 ε4P/Kintsugi 式
  翻新(失败 rollout→恢复数据)扩充检索库覆盖,攻 MT3 自陈的失败任务族。
  硬件:2 Sawyer + 4090。工期 5-6 月。

  改进可直接用于 3A 的检索)/ → 共享基底(资产质量度量可上升为通用协议)。
- **风险与替代锚点**:MT3 检索库长程 chaining 真机失败率高 → 改用 WAA/K1 成熟
  agentic 资产(脱离 MT3 基底);LLM 幻觉 → 加显式记忆约束(借 Track B 的 3C 思路)。

# Part 5 · 共享基底与接口(并行不打架的关键)

**这是 4 个 track 的公共地基,必须先做(1 人或负责人统管),否则并行会各跑各的、
结果不可比。**

## 5.1 共享基底组的工作(先于 track 启动)

1. **MT3 复现验证**:确认复现范围(完整 1,000 任务?受控子集?检索库/PointNet++
   编码器/位姿回归器是否跑通?)——**这决定所有 track 的工期**。
2. **任务 taxonomy 提取**:从 MT3 Appendix C/D 提取 31 macro × 534 micro × 402 objects,
   建一个**共享任务清单**,各 track 从中选子集(保证任务可比)。
3. **统一评价协议**:每任务 3 trials(对齐 MT3 受控实验)+ 95% Wilson CI +
   two-proportion Z-test + **多种子(≥3)+ 方差 + 显著性**(直接填领域"统计严谨性"缺口)。
4. **硬件清点与标定**:Sawyer/Realman/RealSense/柔性夹爪/端侧板,统一标定与坐标系。
5. **数字并列守则**:同轴同口径 / 区分成绩与领先幅度 / 不同子集均值不并列
   (尤其 LIBERO-Pro 五数四设定、77.5 不与 61 并列)。

## 5.2 track 之间的接口(数据/代码/结论怎么流动)

- **Track C(检索度量 1B)→ Track B(3A 检索路由)**:改进的检索度量可直接用于 3A。
- **Track A(触觉)→ Track B(3A 检索维度)**:触觉签名可作 agentic 检索/路由的维度。
- **Track C(scaling 1C)→ Track D(4A 成本-收益)**:scaling 数据作成本-收益输入。
- **所有 track → 共享基底**:各 track 的成功率-演示数曲线、消融表、资产度量,
  汇总成顶层"任务族 × 路径条件表"(Part 1.2 的终极产物)。

## 5.3 并行节奏(建议)

- **第 0-1 月**:共享基底组做 §5.1(复现验证 + taxonomy + 评价协议 + 硬件清点);
  各 track 同步做 gap→survey(survey 直接复用本所四透镜分图的已核文献)。
- **第 1 月起**:4 个 track **并行**启动(能力推进型优先:2A/3A/1B/4C;
  基准对撞型 1C/3B/4A 可稍后或由共享基底组统管)。
- **每 2 周**:track 间同步会(对接口、共享数据、避免重复)。
- **每月**:对照顶层条件表,看各 track 贡献了哪一块。

# Part 7 · 执行须知(所有 track 必读的硬规则)

1. **证据纪律**:每个事实性结论带出处(URL/文件路径);论文条目只报**实际打开过
   原文**的;摘要内容逐句忠于原文,**禁止凭标题/记忆/想象脑补**;张冠李戴是死刑级错误。
2. **MT3 引用两陷阱**(Part 2.4):"数量级"归分解非检索;图内数字本地不可得。
3. **数字并列守则**:同轴同口径;区分成绩与领先幅度;不同子集均值不并列
   (LIBERO-Pro 五数四设定;77.5 不与 61 并列)。
4. **硬件安全(红色)**:**AI 绝不驱动硬件**;真机实验每一步由**真人执行并签字**;
   涉及人身安全(力/温/电/运动范围)的规格须真人复核;大额采购须先批预算。
5. **统计严谨**:多种子(≥3)+ 方差 + 显著性;**配对置换检验 n≤4 时 p 下限 0.125,
   差异再一致也达不到 0.05,须告警检验力不足,不得据此判"无差异"**。
6. **含不利数字**:全口径报告(含失败/负结果);**若触觉无增益、跨本体迁移失败、
   翻新无提升,诚实报告——失败本身也是论文(测出边界条件)**。
7. **不夸大新颖性**:引用前人须核实;改进/结合的新观点标"这是判断"+置信度;
   跨域迁移诚实标注(不声称"无人立论")。
8. **署名/投稿/发布 = 红色**:由真人(委托人)亲手执行;一句话批复不构成红色事项的
   明示授权。
9. **活文档**:论文成稿后,对应的透镜分图/综述/立场文章须升版本追记(实证闭环)。
10. **pilot 失败不硬撑**:每条路径须先做 1-2 周 pilot;失败→换备选路径或替代锚点。
