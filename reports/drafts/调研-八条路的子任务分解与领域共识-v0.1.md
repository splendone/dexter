## 1. 趋势层：用"上升/下降"判八条路

**检索**：`cat:cs.RO AND all:manipulation AND submittedDate:[…]`，四个半年桶，每桶取该期末最近 100 篇。

### 1.1 判八条路（这才是对的问题）

- **四条上升趋势，八条路全接住了**：VLA→R1、检索→R4、世界模型→R6、评测→X1。**作为"趋势代表"，八条路是合格的。**
- **三条高位常驻主题，八条路没有位置**：**效率/部署（39–53%）**、**触觉（28–38%）**、**安全/形式化（19–28%）**。
  它们不是"新路"，是**一直在的背景**。→ **八条路是趋势地图，不是地形图。**
- **一条下降趋势要写进去**：agentic 从 35 掉到 18。**"agent 直接控机器人"正在退潮**，但"agent 生产资产"（R7 的资产支）没退——**这印证了 R7 该拆成"控机器人"和"造资产"两支**。

> **结论（判断，置信度中高）**：八条路**能代表趋势，不能代表地形**。要当地形图，得补三个常驻列（效率、触觉、安全），而它们在上一件里已被我识别为"组件"——**两条分析在这里合上了**。

## 2. 分解：八条路 → 子任务 → 科学问题 → 可测目标

**格式**：每条路给"路级目标"一句 + 3 个子任务。**每个子任务必须有一个问句（科学问题）和一个能被第三方复算的数字（可测目标）。**

### R1 规模（端到端 VLA）
**路级目标**：在任务分布 D 上，用可扩展的训练配方把成功率推到部署阈值。
- **1.1 动作表示与架构**｜Q：动作该用什么分布（离散 token / flow / diffusion / 双系统）才同时满足精度与推理速度？｜目标：同数据同算力下**动作误差–延迟的 Pareto 前沿**
- **1.2 数据配比与负迁移**｜Q：跨本体、跨任务的数据配比如何决定负迁移？｜目标：**配比–迁移率的定量曲线**（出现负迁移的临界比例）
- **1.3 训练目标与后训练**｜Q：纯行为克隆 vs 世界模型辅助预训练，哪个给出更好的闭环？｜目标：**同预算闭环成功率差**（含置信区间）

### R2 数据引擎
**路级目标**：让"覆盖度"成为可测量、可购买的变量。
- **2.1 采集形态的单位成本**｜Q：遥操作 / UMI / 人手视频 / 仿真，每单位成本换来的有效覆盖谁高？｜目标：**每千元有效覆盖曲线**
- **2.2 质量筛选是否有效**｜Q：平滑度、关键性这类筛选指标，是否真能预测下游成功率？｜目标：**筛选指标与下游增益的相关系数**（已有审计工作指出"平滑度排技能不排成功"）
- **2.3 覆盖度的定义**｜Q：库/数据集的"覆盖度"怎么定义、怎么测？｜目标：**覆盖率指标 + 它对新任务零样本成功率的预测力（R²）**

### R3 结构先验（分解 / 分层 / 技能）
**路级目标**：用组合换数据。
- **3.1 分解的边界**｜Q：什么时候该切、切几段？｜目标：**分解收益 vs 相位可分性的函数**（何时由正转负）
- **3.2 段间接口**｜Q：段与段之间该传什么（位姿 / 接触状态 / 子目标）？｜目标：**接口信息量–端到端成功率的消融曲线**
- **3.3 技能从哪来**｜Q：技能靠人工定义、演示切分，还是自发现？｜目标：**技能库规模 vs 新任务成功率**（边际收益何时饱和）

### R4 检索与非参数
**路级目标**：把"策略"变成"库 + 检索规则"。
- **4.1 相似性的定义**｜Q：相似该定义在什么空间（位姿 / 几何 / 运动 / 分布），能否叠加？｜目标：**双通道是否 Pareto 支配任何单标量**
- **4.2 检索之后做什么**｜Q：回放、插值，还是残差修正？｜目标：**插值能力–成功率曲线**（含"不能插值"的代价量化）
- **4.3 库的治理**｜Q：库该多大、怎么版本化、怎么淘汰？｜目标：**覆盖率预测力 + 回滚代价**

### R5 语义迁移
**路级目标**：让没见过的指令与物体也能对。
- **5.1 语义→几何**｜Q：语言先验如何落到 6D 位姿与抓取？｜目标：**开放词汇抓取成功率**
- **5.2 指令鲁棒性**｜Q：指令改写到什么程度会崩？｜目标：**改写强度–成功率曲线**（含崩溃点）
- **5.3 语义与接触的接缝**｜Q：语义对但接触错，怎么发现？｜目标：**语义–接触一致性检验的召回率**

### R6 世界模型
**路级目标**：让"预测"能替代一部分"试错"。
- **6.1 预测什么**｜Q：像素、几何，还是任务相关状态？｜目标：**预测保真度与闭环增益的相关性**
- **6.2 如何进入控制**｜Q：预测用于 MPC、残差修正，还是候选筛选？｜目标：**闭环增益曲线**（per-capability，而非单一数）
- **6.3 能否当评测代理**｜Q：世界模型能否替代真机评测？｜目标：**与真机成功率的排序一致性（如 Kendall τ）**

### R7 agentic
**路级目标**：把能力外化成可复用资产（**注意：不是"agent 直接控机器人"**）。
- **7.1 资产形态**｜Q：技能、工具、程序、playbook，哪种外化最可复用？｜目标：**复用率**（同一资产被多少新任务调用）
- **7.2 执行门控**｜Q：证据到什么程度才允许执行？｜目标：**误执行率 vs 覆盖率**的权衡曲线
- **7.3 思考与行动的预算**｜Q：算力如何在"想"与"做"之间分配？｜目标：**同算力预算下的任务完成率**

### R8 自进化
**路级目标**：让时间变成资产。
- **8.1 经验的表示**｜Q：一次执行该存成什么（日志 / 技能修订 / 数据）？｜目标：**经验复用率**
- **8.2 修订与验证**｜Q：改完怎么知道真的变好？｜目标：**自评与外部评的一致性**（无测试门时的一致率下降幅度）
- **8.3 遗忘与回滚**｜Q：持续学习如何不忘记？｜目标：**新旧任务成功率的同时保持率**

> **这 24 行才是"路"的可操作形态。** 上一件说"16 篇装不进八条路"，其实装不进的是**子任务层**——
> 比如"动作表示"（2610.18855）就是 **R1.1**，"力控"（2610.22813）是 **R3.2 的接口之一**，"效率"（2610.22146/21389）是 **R1.1 的延迟轴**。
> **上一件把它们误判成"新路"，是因为没有下钻到这一层。**

## 4. 本所定位（**与前四节严格分开**：这里才引入硬件约束）

### 4.1 定位的推导方式（不是挑喜欢的，是排除法）

1. 先看**共识里"已定但缺测量"的格子**——共识越硬、测量越缺，越值得做。
2. 再看**上升趋势里"方法论缺口"**——趋势会带来引用，缺口会带来贡献。
3. 最后用硬件筛：**2 Sawyer + 1 Realman + 3 RealSense + 触觉 0**。

### 4.2 交集结果（四个格子）

| 格子 | 为什么是它 | 需要什么 | 本所能否 |
|---|---|---|---|
| **R2.3 覆盖度的定义** | C1 说数据是瓶颈，但**没人能给"覆盖度"一个数** | 公开数据 + 仿真，**零真机** | ✅ |
| **R4.3 库的治理** | C2 说复用省数据，但**库没有质量门、没有版本、没有淘汰** | 小规模真机 + 仿真 | ✅ |
| **R3.1 分解的边界** | C3 说分解有益但有代价，**代价何时超收益无人测** | 纯文献元分析，**零硬件** | ✅ |
| **X1 跨基准换算** | C5 说不可比，2609.29669 直接判"目前不可能"——**空位且对手具名** | 公开数字，**零硬件** | ✅ |

**四个格子的共同点**：都不争"能力上限"，都做"**能力的度量与复用**"。这就是本所该待的位置。

### 4.3 一句话定位

> **不做"更强的机器人"，做"让能力可算、可复用、可复算"的那一层。**
> 对应本所契约使命：**把分歧变成可判定的实验，把实验变成别人能复算的稿子。**

### 4.4 明确不做的（写出来，防跑偏）

- **R1 主线**（训练更大 VLA）：算力与数据都不在量级，做了也是跟随。
- **R6 世界模型**：闭环证据缺失是领域级难题，本所只能仿真，**做不出决定性证据**。
- **R8 自进化**：需长期部署，本所无部署场景。
- **R5 语义**：可借开源权重，但**不构成独立贡献**。

## 5. 诚实清单

1. **趋势数据是关键词占比**，不是人工编码；"评测 47%" 被 `evaluat` 灌水，**只能读趋势不能读绝对值**。
2. **每桶 100 篇是"期末最近 100 篇"**，不是随机抽样；半年内的分布可能偏后段。
3. **24 个子任务是我构造的**，不是从文献里抽出来的既有分类。**它们的价值在于可立项、可判据，不在于"文献都这么分"。**
4. **共识 8 条的证据强度不均**：C1/C5/C6 硬，C8 软（一半靠趋势、一半靠媒体源）。
5. **§4 的定位是判断**，且**只用了本所当前硬件**；若硬件变化（补触觉、加本体），交集会变。
6. **本件没有推翻上一件的 16 个残差**——而是把它们**重新安置**到子任务层。**这算不算"事后合理化"，须由下一轮独立抽样检验。**
