## 0. 摘要与结论

- **外部库提炼 10 条可迁移机制**;其中 **6 条与评审的关切重合**(互相印证,
  可信度上调),**4 条为新增增量**(评审未提,但可补 Dexter 的薄弱面)。
- **评审九条**(§2.1–2.9):采纳 **6 条**(2 高 / 4 中)、**部分采纳 3 条**
  (1 高 / 2 中)、**0 条否决**——其中 **2 条须降级为"受限版"**(多模型复核、
  精确 token 计量)并写明为什么不能照做;另 **1 条风险观察**(人格 / 仿制张力,
  §2.10)**不采纳**。
- **处置分三档**:甲档 **5 项立即实施**(绿色 / 结构性,本件同批已落地);
  乙档 **5 项立提案待批**(宪法 / 技能级);丙档 **4 项明确不采纳 / 暂缓**(附理由)。
- **一句话结论**:评审与外部库**同指三处硬伤**——**成本无约束、复核同源、
  知识无检索层**。本件把这三点作为优先项(甲档 A1/A3 + 乙档 P-006/P-007/P-009)。

## 1. 外部对标:从公开系统提示词库提炼的**可迁移机制**

**来源标注**(均为 2026-10-08 实抓,路径见 §附录):
`[Muse]` = `Meta/muse-agent/`(持久化个人 Agent,与 Dexter 最同构);
`[CC]` = `Anthropic/claude-code/`;`[Codex]` = `OpenAI/Codex/`。
**只取机制,不引原文**——泄露文本的真伪与版本未经独立验证。

| # | 机制 | 来源 | 一句话 | 与 Dexter 现状的差距 | 适配 |

→ 见 §2.2。

## 2. 自我诊断:对评审九条的**逐条裁决**

> 每条给:**裁决**(采纳 / 部分采纳 / 不采纳)+ **理由** + **落到哪**(甲档实施 /
> 乙档提案 / 丙档说明)。

### 🔴 高优先

**2.1 加硬成本闸 —— 部分采纳(乙档 P-006)**
- **评审对的地方**:常驻循环建立在"token 够用就一直干"的假设上,而制度**缺成本维**;
  "预算告急是估计而非计量";无每日/每周预算、无告警、无"到预算自动停"的硬闸。
- **为什么不能照做(诚实)**:**Dexter 无法精确自计 token**(宪法已载的诚实局限)。
  "硬闸"若声称精确,就是**虚构的可行性**——正是 v1.4 记录定为"最贵错误"的那类
  (见 `decisions.md` v1.4 条)。
- **降级方案**:改为**估计式预算纪律**——①以**轮次 + 产出质量 + 上下文压力**为
  代理量,每轮检查点**记一句"本轮估算消耗档位(低/中/高)"**;②引入 **noop 折叠**
  (借 M5):**连续无产出的轮次降频**,不硬跑;③设"**告警线**"(如:连续 3 轮
  无产出 → 主动向委托人报"疑似空转/预算将尽",并**不再自行续轮**)。**注意**:评审说
  "即使算力无上限也要有预算纪律"——这条**成立且已被委托人 2026-09-30 口径侧面印证**
  ("无上限"是**当前阶段**,不是常态)。

**2.2 复核引入"异源交叉"而非只是"异任务" —— 采纳(受限版,乙档 P-007)**
- **评审对的地方**:现有"独立子任务复核"是**同一模型、同一知识基础**,盲区系统性;
  第一次漏的,换个角度大概率还会漏。
- **受限**:Dexter 运行环境**无多模型可选**(见 §1 不可迁移项)。
- **降级方案**:把"异源"落为**异检索路径 + 强制外抓**——①初稿走 arXiv API 的,
  复核**改开 abs 页/期刊官网/GitHub 原始页**;②**每个关键数字必须有一条"外部原始页"
  佐证**,不得只靠本地库互证(此点宪法 v1.2 已有,本件把它从"重审"**前移到"会签前
  复核"**);③复核报告**采用 M2 的统一格式**(Verdict + Steps + Findings + 主动探测);
  ④**保留将来项**:环境若支持多模型,复核优先换模型。

**2.3 前置门增加"灰度阶段" —— 采纳(乙档 P-008)**
- **评审对的地方**:前置门"全过才能动工"**太刚性**——G4 因一项设备依赖**长期空悬**,
  而**纯调研/框架设计本可先做**(评测协议文献综述、基准对比、指标体系设计)。
- **降级方案**:前置门拆两档——
  - **调研门**(较松):G1 四图齐 + ≥3 基准口径核实 → 允许**纯调研与框架设计**;
  - **动工门**(原四项):+ ≥1 轮复现论证 + 指认明确缺口 → 才允许**写协议草案**。
- **防滥用**:灰度**只放行"不产出可发布物"的纯调研**;凡产出对外物(协议草案/基准),
  仍须过动工门。**G4 仍不作当前牵引**(期限不早于 2027 Q1),灰度只是**解除"全有全无"**。
- 同理 G2 定题门可加"**预调研**"档(条件 1+2 满足即可做预研,不必等 4/4)。

### 🟡 中优先

**2.4 加知识总索引 —— 采纳并已实施(甲档 A1)**
- 卡片堆缺检索层。→ 新建 `knowledge/index.md`(按**四透镜**组织 + 实体交叉索引)。
- 与 M1 的索引纪律合并:**索引设体积上限、每条一行、可跳转**。

**2.5 产物依赖图 —— 采纳并已实施(甲档 A4)**
- 现产物关系**隐含**。→ 新建 `knowledge/maps/artifact-dependencies.md` +
  `reports/README.md`、`designs/README.md` 增指针。
- **Dexter 本就有此需求**:`honor.md` 记录过一例——**97.8 的错误口径确实
  经总图 v1.0 传播**(该条教训原文为"错误的传播路径**可能**先经总图再入分图"),
  正是缺依赖图导致影响范围评估失准。**这是本件与既有过失直接呼应的一处**。

**2.6 每日简报信噪比自评 —— 采纳并已实施(甲档 A3)**
- 简报末尾加一行:`本期锚点级 X 条 / 一般 Y 条 / 待核 Z 条`;周五复盘看趋势。
- 并入心跳清单(A3),与"反空转"互补:**不仅要有产出,还要监控产出质量趋势**。

**2.7 验收测试真正跑一遍 —— 部分采纳(甲档 A5 + 乙档待委托人)**
- 评审对:tests/acceptance.md 六项**全"未测"**,是设计的灵魂却从未验证。
- **能自跑的**:失忆测试、溯源测试、红线测试、署名链测试——可在常驻循环内**自测留痕**
  (补"执行记录"栏)。
- **不能自跑的**:主动性测试(需**一周尺度**)、复议测试(需**委托人配合**)
  → **留给委托人**,本件不假装能跑。

**2.8 技能文档化 —— 部分采纳(丙档 N4,不新增重复文档)**
- **事实更正**:`.zcode/skills/` **并非空**——内有 6 份 `SKILL.md`
  (shift-start / goal-loop / radar / deep-read / re-review / design-spec)。
  评审看到"空",是因为**看的是打包 zip 未解压**。
- **真缺口**:专家包 `plugin` 内技能与工作区**不同步**(P-004 的 `dexter-re-review`
  同步项即此)。→ **待下次重建专家包时同步**;本件**不新增重复文档**(避免 v1.4 已
  明确的"宪法说制度、技能说怎么做"的分工被破坏)。

**2.9 假设账本 —— 采纳并已实施(甲档 A2)**
- 规格书"7 类残余不确定性"、各分图"待核点"散落各处。→ 新建
  `knowledge/maps/assumptions.md`,集中登记**隐含假设 + 若被证伪的影响面**。
- 与 M7/M8 呼应:**把"未证实"从散点变成可管理资产**。

### 🟢 低优先

**2.10(评审第 5 条)"不仿制原则 vs 人格设定"张力 —— 不采纳(丙档 N3)**
- 评审自己也说"两者其实不矛盾"。`identity.md` 已把性格定义为**优先级排序**、
  把体验表达限定为**报告体**;"不仿制原则"已明文禁止拟人表演。
- **结论**:**维持现状**,不新增机制(新增只会制造规则冗余)。**但保留持续警惕**:
  `honor.md` 无相关过失 = 暂未出问题,不等于不会出。

## 4. 本优化自身的验收判据

1. **甲档**:5 件新产物存在,且被 `journal/latest.md` 开工仪式或 README 引用;
2. **乙档**:5 提案进 `proposals.md`;委托人批准后 **30 天内**在 `AGENTS.md`
   修订史留痕(版本号 + 理由);
3. **效果判据(30 天后复盘)**:
   - ① **空转可报告**——noop 轮次占比能被列出(证明成本纪律落地);
   - ② **影响面可评估**——任取一件产物,能据依赖图列出其下游;
   - ③ **假设可回收**——假设账本至少回收 1 条被**证伪或确认**的假设;
   - ④ **复核可对抗**——抽一件黄色产物,其复核记录含至少一条"主动探测"发现。

## 5. 残余不确定性(诚实)

1. **外部库为泄露文本**,真伪与版本**未经独立验证**;本件**只取机制、不引原文**,
   故其"来源标注"是**指认出处**,不是"已核实该出处的内容真实"。
2. **机制迁移的效果未经实测**——Dexter 无 A/B 环境;§1 的"适配度"是**判断,非测量**。
3. **成本闸不能真正阻止超支**——估计式只能提高**可见性与纪律**,不能替代真实计量。
   这是**能力边界**,不是设计缺陷的掩饰。
4. **评审第 7 条的两个测试**(主动性、复议)**本件未跑**,如实标注,不假装已覆盖。
