## 〇、前提:SCI ≠ 顶会

机器人领域最顶尖工作多发表在**会议**(CoRL / RSS / ICRA / IROS),通常**不被 SCI 收录**。
真正的 SCI 期刊主要是:

| 期刊 | 定位 | 门槛 |
|---|---|---|
| **T-RO**(IEEE Trans. Robotics) | 顶刊,系统性大工作 | 极高 |
| **IJRR**(Int. J. Robotics Research) | 顶刊 | 极高 |
| **RA-L**(IEEE Robotics & Automation Letters) | 短文快审,最常见 | 中高 |
| **Science Robotics / Nature MI** | 跨学科 | 极高 |

**推论**:「发 SCI」这一目标本身要求把工作做到**期刊级完整度**——比会议论文更系统的
实验、更充分的 related work、更强的可复现性。下面所有能力的标准线据此设定。

## 一、领域知识 + 问题定义

| 能力 | 关键证据 / 验收信号 | 自动化 |
|---|---|---|
| 子方向纵深(操作/灵巧手/VLA…) | 能画出该方向 method taxonomy,说清各流派取舍 | 🟡 |
| 文献地图与 SOTA 追踪 | benchmark/SOTA/开放问题清单,每条可溯源、开过 abstract 页 | 🟢(须逐条开原文核对) |
| 找到可验证的 research gap | 一句话讲清「新在哪、为何重要」,且能用实验证伪 | 🟡 |
| 问题价值与新颖性裁决 | 与最近邻工作的差异化陈述 | 🔴(决定选题生死) |

## 二、技术硬实力

| 能力 | 关键证据 / 验收信号 | 自动化 |
|---|---|---|
| 机器人学基础(运动学/动力学/力控) | 推导正确、坐标系一致、控制律可实现 | 🟡(人复核物理正确性) |
| DL 工程(PyTorch/Diffusion Policy/RL) | 代码可跑、loss 收敛、超参可复现 | 🟢 |
| 仿真平台(Isaac/MuJoCo/SAPIEN/Genesis) | 环境搭建正确、域参数合理 | 🟢(有算力/环境时) |
| 真实硬件(机械臂/灵巧手/遥操作/传感器) | 实机采集数据、真机跑通 demo | 🔴(AI 无物理执行权) |

## 三、实验与研究方法

| 能力 | 关键证据 / 验收信号 | 自动化 |
|---|---|---|
| 实验设计(消融/baseline/多 seed) | 设计矩阵无遗漏变量,对照组公平 | 🟡(人审完备性) |
| 评测口径诚实(选对 metric) | 报告全口径数字含不利结果,配置(单臂/双臂)与结论匹配 | 🟡(人守「不选择性引用」红线) |
| 统计显著性 | 方差/置信区间/显著性检验齐全 | 🟢 |
| sim-to-real gap 量化 | gap 数值化 + 残差不确定性诚实声明 | 🟡(人确认诚实性) |

## 四、写作与表达

| 能力 | 关键证据 / 验收信号 | 自动化 |
|---|---|---|
| 学术英语 + 结构化叙事 | motivation→方法→实验→结论闭环,语言达期刊线 | 🟢 |
| 高质量可视化(demo/定性图/失败案例) | 图表自解释、达出版分辨率 | 🟡(真机截图 🔴) |
| Related work 组织 | 批判性归类而非罗列 | 🟡 |
| 可复现材料(附录/代码/数据) | 第三方能照做复现 | 🟢 |

## 五、投稿与同行评议

| 能力 | 关键证据 / 验收信号 | 自动化 |
|---|---|---|
| 选刊匹配(T-RO/IJRR/RA-L) | 工作体量与期刊定位对齐 | 🟡(AI 给建议,人拍板) |
| 投稿执行(署名/format/提交) | 符合期刊规范 | 🔴(红色事项) |
| Rebuttal 写作 | 逐条、用证据回应审稿人 | 🟡(人审承诺与语气) |
| 学术诚信(一稿多投/数据真实) | 无违规 | 🔴(不可让渡) |

## 六、研究素养(贯穿全流程)

| 能力 | 关键证据 / 验收信号 | 自动化 |
|---|---|---|
| 项目/算力/预算管理 | 计划可执行、资源不超支 | 🟡(人批预算锚点) |
| 批判性诚实与证据纪律 | 每个结论可溯源,声明与实际修改一致 | 🟢(须独立复核) |
| 迭代韧性(多轮拒稿抗压) | 每轮 review 转化为改进 | 🔴(动机与决策) |

## 人必须把关的四道闸(其余可交给 Dexter 自主循环)

1. **物理执行**——真机实验、数据采集;宪法明令 Dexter 不跑真机、不做实物。
2. **价值裁决**——选题新颖性、gap 是否值得做。
3. **诚实红线**——评测口径不选择性引用、声明与实测一致(AI 易自欺,须独立复核)。
4. **红色事项**——署名、投稿、预算承诺,须委托人明示授权(一句话批复不覆盖)。
