## 二、按"能不能直接用"分三档(**选型速查**)

**A 档 · 宽松可用(可商用,工程首选)**

- **Open X-Embodiment**(聚合层;但**内 60 源须逐查**)、**ALOHA / Mobile ALOHA**(MIT,
  **硬件 + 软件全开**)、**BridgeData V2**(CC BY 4.0)、**MimicGen / DexMimicGen 的数据**
  (CC BY 4.0)。
- → **G2 规格书的"合成增强"与"基线预训练"优先取这一档**(许可干净)。

**B 档 · 有坑(可用但要小心)**

- **DROID**:数据 CC BY 4.0 可,**官方代码无许可 → 实际不可复用**(要联系作者);
- **MimicGen / DexMimicGen 的代码**:NVIDIA **自定义许可**,**勿当 MIT / Apache 用**;
- **UMI**:软硬件"开源"但**许可类型未核**——**不得默认 MIT**,引用前查。

**C 档 · 禁商用(研究可、商用不可)**

- **AgiBot World**(CC BY-NC-SA)、**RH20T**(含 BY-NC 分卷)、**GRAB**(研究用途)。
- → **若目标含商用,这三者只能作"研究复现",不得进产品线**(判断)。

**D 档 · 待核(先查再用)**

- **Ego4D / Ego2Robot / UVTA** 许可未核;**UMI** 许可类型未核。

## 三、按"数据源谱系"看(承接数据集库 README)

**从左到右越靠"人"**(越上游越便宜、越需对齐):

```
Ego4D(纯人自中心视频) → Ego2Robot(人视频→机器人合成) → UMI / GRAB(人采集) → ALOHA / DROID(机器人遥操作)
```

- **越靠左**:许可风险越高(多为研究用途)、可复现性越低(需对齐管线);
- **越靠右**:许可越干净(ALOHA MIT)、可复现性越高(硬件软件开源)、但**采集越贵**;
- **选型含义(判断)**:G2 平台**采集端**取右侧(ALOHA/UMI 范式),**预训练端**可取左侧
  (Ego2Robot / Ego4D)但要**核许可 + 做对齐**。

## 五、本表对 G2 的直接用途(落点)

- **G2 规格书 §3 选型**:采集端取 **ALOHA / Mobile ALOHA(范式)**,数据端取 **A 档**;
