# 主张卡 · 模板

> **本档管什么**：一张卡 = 一条**可判真假的主张**。原子单位是主张，不是论文（一篇论文 1–3 张）。
> **不归本档**：论文全文摘录 → `knowledge/papers/`；争点配对 → 争点表；读不懂的 → 简报待核区。
> **生长纪律**：七字段缺一不可，**字段 6「对手」填不出 → 本卡降为「能力报告」，不入争点表**。
> 规范见 `reports/drafts/调研架构v3-从分类到争点-v0.1.md` §4.1。

---

```markdown
## [C-YYYYMMDD-nn] <一句话主张，不是标题>

- **问句**：<它在回答什么？写成问句>
- **主张**：在 <P 条件> 下，<B> 比 <A> <更好/可行/必要>。
  （**必须可判真假**；写成"提出了一种方法"不算主张）
- **机制**：<为什么成立。因果链：改了什么假设 → 导致什么 → 所以指标动了>
  （写成"用了 Transformer/扩散策略"不算机制）
- **证据**：<数字 + 口径：任务数 / 物体数 / 回合数 / 评测协议 / 本体型号>
- **失效边界**：作者自述 <…>；我看出的 <…（这是判断，置信度 高/中/低）>
- **对手**：反驳 <谁> 的 <哪条主张>；它**未验证的假设**是 <…>
- **出处**：<DOI / arXiv>｜读到层级：<abs / 全文>｜核实日 <YYYY-MM-DD>

### 形态标注（判可比性用，不作轴）
本体 <型号>｜自由度 <n>｜关键形态参数 <等效质量 / 连杆 / 手指数>

### 若为能力报告（无对手）
它在问的问题：<一句话>｜为什么不算主张：<没有反驳对象 / 只是集成>
```

---

## 使用要点

1. **主张 ≠ 贡献**。"我们提出了一个框架"是贡献声明；"在 X 条件下 Y 比 Z 好"才是主张。
2. **对手可以是作者自己列的 baseline，也可以是我读出来的**——但必须写清是哪一种。
3. **失效边界是硬字段**：只写作者自述的，等于没写。至少给一条自己看出的。
4. **数字必须带口径**，与 `CONTRACT.md` 的 K2 一致——无口径的数字不得入卡。
5. **一张卡只放一条主张**。若一篇论文有三条，就开三张，别合并。
