## ALOHA / ACT(arXiv:2304.13705,v1 2023-04)

- 作者:Tony Z. Zhao、Vikash Kumar、Sergey Levine、Chelsea Finn
  (abs 页未显示机构,不作断言)。cs.RO + cs.LG。
- 口径(abs 页逐句):低成本双臂系统 + 端到端模仿学习,演示经**自制遥操作
  接口**采集;算法 **ACT(Action Chunking with Transformers)**——在动作
  序列上学生成模型;**6 个真机精细任务**(开半透明调料杯、插电池等)达
  **80-90% 成功率**,仅需 **10 分钟演示数据**。项目页
  tonyzhaozh.github.io/aloha/。
- 为什么是地基:①"低成本硬件 + 人手遥操作采集 + 动作分块策略"是当代
  数据采集与模仿学习的主干范式(**直连透镜④**);②ACT 的动作分块
  (chunking)与 Diffusion Policy 的 receding horizon 同属"一次预测一段
  动作"的思想源头——今日流/扩散策略的公共祖先之一;③"10 分钟演示
  就够"是数据效率叙事(透镜①)的早期标杆,后续论文常以其口径作对照。
- 回读待办:ACT 的动作分块长度、训练细节与 6 任务清单在正文,待全文
  (黄色级精读候选,待点名)。**系谱延伸(记忆,未核):ALOHA 后续有
  Mobile ALOHA 等工作——引用前须核。**

## DROID(arXiv:2403.12945,v2 2025-04,初版 2024-03)

- 作者:Khazatsky、Pertsch、Nair 等**超长名单**(数十人,含 Levine、Finn、
  Sadigh、Goldberg、Malik 等;abs 页未显示机构,不作断言)。cs.RO。
- 口径(abs 页逐句):DROID(Distributed Robot Interaction Dataset)——
  **76k 条示范轨迹 / 350 小时**交互数据,**564 场景、84 任务**,由
  **50 名采集员**在北美/亚洲/欧洲历时 **12 个月**采集;全文开源数据集 +
  策略学习代码 + 硬件复现指南。项目页 droid-dataset.github.io。
- ⚠️ **任务数口径(2026-09-28 查原始文本定案)**:arXiv **abs 页元数据摘要**
  写 **84 tasks**;而**论文正文**(HTML v2 的摘要渲染 / Intro / §III /
  Table I)与**官方页**均写 **86 tasks**。→ **采用 86**,84 为 arXiv 元数据
  摘要的孤例。**且论文把 "tasks" 定义为"语言指令去重后的 unique verbs
  数"**(Table I 列名即 "# Verbs")——引用须带此定义,否则"86 任务"易被误读
  为人工任务类目数。
- 正文补充数字(HTML v2):**52 buildings、18 robots、13 institutions、
  1417 相机视角**;76k 为成功回合,另有约 **16k 条标 "not successful"
  一并发布但不计入规模**。
- 为什么是地基:①"分布式人力 + 标准化低成本 rig + in-the-wild 场景"是
  当前真机数据规模化的标准范式(**透镜④**),与 ALOHA(单机低成本)、
  OXE(多数据集聚合)构成三条不同路线;②"76k/350h/564 场景"是数据规模
  叙事的当代锚点,后续论文常以其作对照;③作者名单横跨主要实验室——
  "数据是集体工程"的直观信号。

## Open X-Embodiment / RT-X(arXiv:2310.08864,v9 2025-05)

- 作者:**Open X-Embodiment Collaboration**(集体署名 + 超长名单,含
  O'Neill、Levine、Finn、Sadigh、Pathak 等;abs 页标"194 additional
  authors not shown")。cs.RO。
- 口径(abs 页逐句):标准化数据格式的**跨本体数据集** + **RT-X 模型**;
  汇集 **22 种机器人**,由 **21 家机构**协作,**527 skills / 160,266
  tasks**;RT-X 借跨平台经验显示正迁移、提升多个机器人的能力。项目页
  robotics-transformer-x.github.io。
- ⚠️ **机构数口径(2026-09-28 查原始文本)**:论文(**abs 页 + HTML v9 正文**)
  一致写 "**21 institutions**"(正文原句:"22 different robotic embodiments
  from 21 different institutions"),**60 datasets** 亦为论文口径。官方页
  (数据集卡所记)写 "**34 个研究实验室 / 60 个数据集**"。→ **60 datasets
  两源一致**;**机构数 21 vs 34 不一致**,或为"RT-X 协作成员机构"与
  "数据集来源实验室"之别(**未证实,不作断言**)。**引用须标来源。**
- 为什么是地基:①**"聚合"路线的开山**——与 ALOHA(自采单机)、DROID
  (自采分布式)并列第三条数据路线;②RT-1-X / RT-2-X 是"跨本体正迁移"的
  首个大规模证据,今日"跨本体 VLA"叙事皆以此为先例(直连透镜①泛化与
  ③语言条件);③"标准化数据格式"是此后所有数据基建的前提。

## Diffusion Policy(arXiv:2303.04137,v5 2024-03)

- 哥伦比亚组(Chi, Xu, Feng 等);策略 = 条件去噪扩散过程,学动作分布
  score,推理走随机 Langevin 步。
- 口径:12 任务 / 4 个操作基准,平均提升 **46.9%**;贡献点:receding
  horizon 控制、视觉条件化、时序 diffusion transformer。
- 代码公开:diffusion-policy.cs.columbia.edu。
- 为什么是地基:今天所有"流/扩散策略"论文(RMFP、LiMA 的 VPP 基线、
  TP-Flow)的公共对照物;RMFP 干净复用其 UNet 架构做控制变量,就是
  承认它的骨架地位。回读要点:receding horizon = 动作块思想的源头之一。

## OpenVLA(arXiv:2406.09246,v3 2024-09)

- Stanford/Berkeley 等(Kim, Pertsch, Karamcheti 等);7B 开源 VLA,
  Llama 2 + DINOv2/SigLIP 视觉编码,970k 真机演示训练。
- 口径:29 任务上较 RT-2-X(55B)绝对成功率 **+16.5%**(参数 1/7);
  微调后较 Diffusion Policy **+20.4%**;消费级 GPU 可微调,支持量化服务;
  论文 CC BY 4.0,代码/权重/微调 notebook 全开(openvla.github.io)。
- 为什么是地基:开源 VLA 的分水岭——此后 09-24 批次的 K1 论文用
  "蒸馏学生 vs OpenVLA 30.2%"作对照,它是 agentic 路线量自己的尺子。

## RT-2(arXiv:2307.15818,v1 2023-07)

- 作者/机构:abs 页未显示(Google DeepMind 系,不作断言);cs.RO + cs.CV + cs.LG。
- 口径(abs 页逐句):把互联网规模预训练的 VLM **直接纳入端到端机器人控制**;
  做法 = 在**机器人轨迹数据 + 互联网规模视觉-语言任务(如 VQA)上共微调**
  (co-fine-tune);关键配方 = **把动作表示为文本 token**,与自然语言 token 同格式
  并入训练集 → 该类别即 **VLA(vision-language-action)**;实例即 RT-2。
- 规模/证据:**6k 评测试验**;涌现能力——新物体泛化、解释**机器人训练数据中不存在
  的指令**(如"放到某个数字或图标上")、**初级推理**(拿最小/最大物体、离某物最近
  的物体);加 **chain-of-thought** 后可做多阶段语义推理(如找石头当临时锤子、
  给疲倦的人选能量饮料)。
- 为什么是地基:①**"动作即文本 token"是 VLA 的命名与范式起点**——今日所有
  端到端 VLA(RT-2-X / OpenVLA / π0 系)的直系祖先(**直连透镜③**,是分图③
  路线 A 的第一行);②**"网络语义知识迁移到控制"**是"规模换泛化"叙事的首个
  强证据(**透镜①**);③"涌现语义推理"是后续"VLA 会理解"类主张的源头——但
  ⚠️ 结合分图③的 2609.34684 方法论警告(**表征准确率可与目标态响应弱并存**),
  引用此类"理解"结论须区分**准确率 vs 响应性**。
- 回读待办:6k 试验的**具体任务/基准口径**在正文,待全文(黄色级,待点名)。

## π0.5(arXiv:2504.16054,v1 2025-04)

- 作者/机构:Physical Intelligence(π0.5 论文署名含 Black/Brown/Driess 等长名单;
  abs 页未显示,不作断言)。
- 口径(abs 页逐句):**基于 π0** 的新模型;用**异质任务共训练**(co-training on
  heterogeneous tasks)实现**广泛泛化**;数据 = **多机器人 + 高层语义预测 + web
  数据 + 其他来源**;**混合多模态样例**组合:图像观测 + 语言命令 + **物体检测** +
  **语义子任务预测** + 低层动作;实验称此类知识迁移对有效泛化**必要**;首次展示
  端到端学习系统能在**全新家庭**中做长程与灵巧操作(清理厨房/卧室)。
- 为什么是地基:①**π0 的下一代**——把"语言塞得更深"(加入**语义子任务预测**作为
  共训练目标),是分图③路线 A"端到端自己在向显式中间语义靠拢"的**关键证据**;
  ②**它是分图③/④的公共基线锚点**:GAM 报 LIBERO-Pro **53%** 即以 π0.5 为基线,
  SynthDemo-RL / MINT / DexRoam 均以 π0.5 作对照——**"换算锚点"地位的来源**;
  ③**"异质共训练"是数据侧(透镜④)的范式**:多源数据混训换开放世界泛化。
- 回读待办:共训练数据配比与"语义子任务预测"的具体形式在正文,待全文(黄色级,
  待点名);⚠️ 分图③已知脆弱点——**π0.5 作锚点(53%)目前只有 GAM 一处直接给出**,
  样本单薄,引用须标"仅一处直接给出"。

## Mobile ALOHA(arXiv:2401.02117,v1 2024-01)

- 作者/机构:abs 页未显示(Stanford 系,与 ALOHA 同组,不作断言)。
- 口径(abs 页逐句):面向**双臂 + 需全身控制**的移动操作;提出 **Mobile ALOHA**
  ——**低成本全身遥操作系统**用于**数据采集**(在 ALOHA 基础上加**移动底盘** +
  **全身遥操作接口**);用其数据做**监督行为克隆**,**与既有静态 ALOHA 数据集
  共训练**提升移动操作性能;**每任务 50 条演示**时,共训练可**提升成功率至多 90%**;
  能自主完成复杂任务——**炒并上虾**、开**双门壁柜**存重锅、**叫电梯并进入**、
  用厨房水龙头**冲洗平底锅**。
- 为什么是地基:①**"低成本全身遥操作 + 移动底盘"是移动操作数据采集的范式**
  (直连**透镜④**路线 A);②**"与静态数据集共训练"**是"**数据复用/混合**"的早期
  证据(呼应分图④路线 E/F 的"语料"思路);③"50 演示 + 共训练"是数据效率叙事
  (**透镜①**)的又一锚点。
- 回读待办:共训练的具体配比与"全身遥操作接口"细节在正文,待全文(黄色级,待点名)。

## RT-1(arXiv:2212.06817,v1 2022-12,v2 2023-08)

- 作者/机构:abs 页未显示(Google 系,不作断言)。
- 口径(abs 页逐句):论点——通用机器人模型成功的关键在于**开放式、任务无关的
  训练** + **能吸收全部多样机器人数据的高容量架构**;提出模型类别 **Robotics
  Transformer**;**基于真机大规模数据采集**,研究不同模型类别的泛化能力**随
  **数据规模、模型规模、数据多样性**的变化。
- 为什么是地基:①**"任务无关大规模训练 + 高容量架构"是 RT-2 / OpenVLA / π0
  整条 VLA 路线的立论起点**——**RT-2 的直系前身**(直连**透镜①/③**);
  ②它是"**数据规模 × 模型规模 × 数据多样性**"三轴泛化研究的**最早系统实验**
  (分图①"规模换泛化"叙事的源头);③与 RT-2 合读可见"**Transformer 化 → 动作
  token 化**"的演进两步。
- 回读待办:三轴实验的具体结论(哪一轴最敏感)在正文,待全文(黄色级,待点名)。
