## 2. 族 A：检索式操作策略（12 条）

### A1 · VINN（检索即预测的起点）
| 字段 | 内容 |
|---|---|
| 标题 | *The Surprising Effectiveness of Representation Learning for Visual Imitation* |
| 作者/机构 | Jyothish Pari\*、Nur Muhammad Shafiullah\*、Sridhar Pandian Arunachalam、Lerrel Pinto（NYU）；\*同等贡献 |
| 版本 | arXiv:2112.01511v2，2021-12 提交；**venue 未获取**（Comments 只标同等贡献） |
| 证据级 | B（abs + html v2） |

**做了什么**：在帧嵌入空间做**核加权最近邻**，直接输出动作——"预测动作就是最近图像对应动作的加权平均"（原文：*"our model's predicted action is just a weighted average of the associated actions from the nearest images."*）。检索单位 = **单帧 → 单步动作**（平移向量 + 四类夹爪状态）。行为层免训练（*"Since nearest neighbors is non-parametric, this technique requires no additional training for behavior learning."* §I），但**表征是离线在同一批 demo 帧上 BYOL 微调的** → 属"库与编码器离线共训一次"，**不是测试时训练**。

**数字**：真机 30 rollouts（Table I）——VINN 80% / 80%（抓握 / 开门）；BC-rep 56.7% / 53.3%；**端到端 BC 0% / 0%**；ImageNet 特征 + NN 20% / 0%。遮挡泛化 80 / 70 / 50 / 0。

**扫过的轴**：库规模（Pushing 930 / Stacking 750 / Door 71+21；另做 71 条子采样，Fig.4 给 MSE 曲线，档位仅在图内）；**k**（Fig.6，最优约 10；*"Beyond k=20, we didn't notice any significant improvement"*）。**无上下文长度轴。**

**没做什么 / 自陈局限**：全遮挡即失败（*"our model fails when all large, recognizable markers are removed from the scene"*）；表征不能在线适配；单任务。

**对我们的意义**：**谱系起点，且证明"上下文"是 2024 年后的概念**——它检索的是单步动作，没有"给模型看几条演示"这回事。引言开场可用：该族从"检索一个动作"(2021) 走到"检索一段演示作为上下文"(2024+)，**"上下文预算"是新的自变量，其测量方法尚未建立**。

### A2 · Behavior Retrieval（检索进训练回路）
| 字段 | 内容 |
|---|---|
| 标题 | *Few-Shot Imitation Learning by **Querying Unlabeled Datasets***（⚠️ 我曾误记为 "by Prompting"，已更正） |
| 作者/机构 | Du、Nair、Sadigh、Finn（Stanford） |
| 版本 | arXiv:2304.08742v1，2023-04-18；venue 未获取 |
| 证据级 | B |

**做了什么**：从**无标注数据集**里检索**单个 (s,a) transition**（*"retrieve many relevant state-action tuples"*），再与目标专家数据**联合 BC 微调**（*"jointly fine-tune the policy on the expert and queried data"*）。**不免训练**——策略参数被更新。

**数字**：3 个仿真任务平均 **72±2%** vs GCBC 35±4% / GCBC+FT 36±2%（Table I，100 trials × 3 seeds）；真机 3 任务提升 >20%（Fig.10，40 次评估）。

**没做什么 / 局限**：嵌入只捕捉 *"general visual similarity"*；学新任务时须能访问先验数据集。

### A3 · FlowRetrieval（光流潜空间检索）
| 字段 | 内容 |
|---|---|
| 作者 | Lin、Sadigh 等（Stanford Sadigh 组） |
| 版本 | arXiv:2408.16944；年份 2024 |
| 证据级 | B |

**做了什么**：用 **GMFlow 算光流 → VAE 嵌入**，按"与目标 demo 的最小潜空间距离"取前 **δ%** 的**单帧运动**；检索数据与目标**共训**扩散策略（**非免训练**）。

**数字**：Square（10 demo / 400 库）、LIBERO-Can（10 / 900）、真机 Bridge、Franka Pen-in-Cup：平均比最好基线 **+14%**，比最好检索方法 **+27%**。

**扫过的轴**：δ%（**需手调**，自认局限）。**做过"检索数据的阶段分 bin 分布"（10 bin，有用 / 有害）**——属"检索构成归因"，不是失败归因。

**对我们的意义**：它证明"检索数据的**构成**"可以被分箱统计，这是我们阶段归因的近亲但不同物。

### A4 · STRAP（变长子轨迹 + 测试时重训）
| 字段 | 内容 |
|---|---|
| 作者/机构 | Memmel 等，UW + Bosch |
| 版本 | arXiv:2412.15182v2；ICLR 2025 |
| 证据级 | A（关键句主会话逐字复核） |

**做了什么**：把 demo 按**末端速度阈值**切块（*"transition states where the absolute velocity drops below a threshold: ‖ẋ‖ < ε"*，并把相邻段合并到 *"all are ≥ 20"*）；DINOv2 / CLIP **逐帧嵌入**；用 **S-DTW** 从大库检索**变长子段 top-K**；检索数据与 5 条目标 demo 合并，**部署时重训练**专家（约 35 分钟）。→ **检索免训练，策略非免训练**。

**数字**：LIBERO-10（库 = LIBERO-90 的 4500 条）平均 **58.1%**（BC 37.9 / 整轨迹检索 41.4）；真机 DROID-Kitchen **45.5~63.0** vs BC 10~14。

**扫过的轴**：**K 扫描 100~4000，最优值任务相关**；库规模（76k 轨迹检索约 300 s，扩库不掉点）；编码器（DINOv2 vs CLIP）。

**关键一句（直接改我们实验设计）**：*"We don't find any representation to significantly outperform the other with **DINOv2 separated from CLIP by only +0.7% across all 10 tasks**."* 表 1 注释：*"DINOv2 and CLIP features perform similarly, making STRAP flexible in the encoder choice."* → **编码器选择在动作片段检索上近乎零效应**，虽然 DINOv2 在图像实例检索上碾压 CLIP（§E6）。

**局限**：分段超参（ε、最小段长）对无停顿动作（搅拌、擦拭）完全失效，作者自评 *"This procedure can certainly be improved further"*。

### A5 · IWR（重要性权重替代最近邻）
| 字段 | 内容 |
|---|---|
| 标题 | 实际标题为 *"Data Retrieval with Importance Weights…"*（我曾简记为 IWR） |
| 作者/机构 | Xie 等，Stanford |
| 版本 | arXiv:2509.01657；CoRL 2025 |
| 证据级 | B |

**做了什么**：**理论上**证明"最近邻检索 = 目标分布高斯 KDE 的 h→0 极限"，因此改用 **KDE 重要性权重**打分检索；兼容 BR / FR / SR 三种潜空间；**共训**扩散策略。

**数字**：Square **84%**（BR 69）；LIBERO 5 任务均值 **54** vs SR 51 / FR 45 / BR 43；真机 Bridge 较 BR 平均 **+30%**。

**对我们的意义**：①**子任务 Partial Success 指标**（对阶段归因直接可用）；②KDE 权重可即插即用；③**检索时序分布图**（纠正"检索偏向前段"的偏置）——这是"检索构成"可测化的现成做法。

### A6 · ReMoBot（最接近我们的阶段归因先例）
| 字段 | 内容 |
|---|---|
| 标题 | *ReMoBot: Retrieval-Based Few-Shot Imitation Learning for Mobile Manipulation* |
| 作者/机构 | Yuying Zhang\*、Wenyan Yang\*、Francesco Verdoja、Ville Kyrki、Joni Pajarinen（Aalto） |
| 版本 | arXiv:2408.15919v4（2024-08 投，2026-06 改）；venue 未获取 |
| 证据级 | B |

**做了什么**：检索**截断后的专家子轨迹段**——state top-K → 回溯所属轨迹并截到 j → top-L → 按**动作历史 Hamming 距离**选一条 → 执行其末动作（Alg.1）。**比 VINN 高一阶**（单步 → 段）。**免训练**：*"selects appropriate control commands based on these retrieved demonstrations in a fully training-free manner"*，冻结 DINOv2。

**数字**：仿真 40 trials（Table II）Uncover / Cover / Curtain——Ours **36 / 31 / 32**，BAKU 38 / 33 / 13，BC 5 / 15 / 16，**VINN 0 / 0 / 0**。真机 20 trials：**70% / 80% / 45%**；**分阶段：Approach 20/20 全中，Grasp 15/17/16**（Table III）。泛化（尺寸/材质/位姿）Table IV 均无显著差异（p≥0.05）。

**扫过的轴**：库规模 1/5/10/15/20 demos（仅仿真）；**K∈{5,10} × L∈{3,5} 四格**（Table VI，最优 K=10、L=5）；**历史窗口未扫；三轴无交叉**。

**⚠️ 阶段级归因的关键先例（干预式，不是事后归类）**：*"we manually modified BC's output by replacing the second grasp action with an arm-up command, resulting in 33 successful trials out of 40"*（§IV-C）——**改一个动作看成功率变化**，比 MT3 的事后归类强得多。

**局限**：无碰撞规划致 Curtain 失败；*"the retrieval module may select semantically mismatched states due to the limited power of the visual backbone and the restricted diversity of the offline dataset"*；相似观测致局部最优；IK 失败。

**对我们的意义**：领域**并非无阶段归因**，而是**归因没有协议化**（没定义判据、没做双评估员、**没对基线对称施加**——它只对 BC 做了干预，没对自己做）。领先点③据此收窄。

### A7 · ReGIL（检索 → 在线 RL）
| 字段 | 内容 |
|---|---|
| 作者/机构 | Zhang、Verdoja、Yang、Kyrki（Aalto） |
| 版本 | arXiv:2606.09381，2026-06-08 |
| 证据级 | B |

**做了什么**：检索专家**子轨迹段**（top-k 视觉近邻定端点 + **S-DTW** 对最近 H 步历史做局部对齐）；检索结果三处用途：**早期探索的动作回放、成功缓冲、稠密奖励**；整体策略是在线 RL（TD3）**重训**。

**⚠️ 措辞陷阱**：它自称 *"training-free retrieval-guided exploration strategy"* **只指检索模块**（冻结 DINOv3），**整体不是免训练**。

**数字**：真机 3 任务，<1 h 在线训练 **80.0%**（随机目标）/ **96.7%**（固定目标）vs BC 40.0% / 63.3%（Table 2）。

**局限**：视觉歧义与光照致检索失败（Insert 任务 4 例）；非刚体失效；复杂环境中"仅靠回放"可能 bootstrap 不起来。

### A8 · RoboRouter（任务级检索 + 路由）
| 字段 | 内容 |
|---|---|
| 作者/机构 | Chen 等，SCUT / SWJTU / 厦大 / PolyU / ShanghaiTech / Zaragoza |
| 版本 | arXiv:2603.07892，2026-03-09 |
| 证据级 | B |

**做了什么**：**检索单位特殊——任务级"历史执行记录"**（视频摘要 + 元数据），**不是动作轨迹，也不是子轨迹**；LLM Router 从池中选一个策略**直接执行**，反馈写回库、不改权重。免训练：*"does not require further training on these data, i.e., a training-free scheme"*。

**数字**：RoboTwin 2.0 取 20 任务 × 100 trials，均值 **79.9%**；真机 5 任务 × 20 trials 平均 **47%** vs 最佳单体 34%（π0）；路由准确率 96.32% / 98.63%；延迟 ~4.8 s。换 VLM 掉到 76.55% / 76.60%（Gemini-1.5-Pro / GPT-4o-mini）。

**没做什么**：**正文无独立局限节**（未获取）。

### A9 · ReCAP（检索即上下文的起点）
| 字段 | 内容 |
|---|---|
| 标题 | *Retrieve, Don't Retrain* |
| 作者/机构 | NAVER AI Lab + 高丽大 |
| 版本 | arXiv:2606.15631 |
| 证据级 | B（附录 F Table 10 已读） |

**做了什么**：检索**池侧定长 state-action chunk，H=16 帧**，**每控制步重检索**（非变长、非 DTW）。两段式加权：Stage 1 用 ψ0（语言 + SAM3 物体位姿 + 初始本体感）取 **top-5 轨迹**；Stage 2 子帧打分权重 **proprio 1.0 / 本体感历史(8 步) 0.05 / DINO 图像 0.1 / action chunk 0.1 / delta-action 0.1 / time 0.0**，本体感 20-D、位置项再 ×4.0。动作参数化 **a_query = a_pool + Δa**（残差）。冻结 **Cosmos Policy（WAM）** 以 chunk 为条件。新任务零训练入池。

**数字**：PushT 未见角度 **34.9%** vs 无检索 6.0%（π0.5+检索 25.1%）；RoboTwin 2.0 五个未见任务 **31.5%** vs 基线 4.0；真机 held-out **10% → 80%**（每任务 10 条人手 demo）。**池增长曲线：11→35 任务，9.0→31.5 单调**。消融：未来帧目标 × 检索 27.4 → 34.9。

**自陈局限（这句是谱系空格的关键证据）**：*"residual formulation becomes less reliable when retrieved motions differ substantially in execution speed or temporal scale"* ——**这正是"没做时序对齐"的代价**。

**与 STRAP 的差别（原文）**：*"STRAP trains a task-specific specialist at deployment from DTW-matched sub-trajectories"*；总括 *"These methods still pay for each new task with training"*。

### A10 · MT3（锚点论文）
| 字段 | 内容 |
|---|---|
| 标题 | *Learning a Thousand Tasks in a Day* |
| 作者 | Dreczkowski、Vitiello、Vosylius、Johns（4 人，前两人共同一作） |
| 版本 | Sci. Robot. 10(108) eadv7594；arXiv:2511.10110v1，2025-11-13 |
| 证据级 | A（全文 + 代码库 tree 均抓） |

**做了什么**：轨迹分解为**对齐 + 交互**两阶段。输入仅两样：**目标物体分割点云**（首帧 Grounding DINO 分割 + XMem 传播）+ **语言描述**。两级检索**只执行一次**：①语言级——模板匹配从描述提取 micro skill 名，筛出同 skill 演示；②几何级——PointNet++ 编码点云、**余弦相似度选单条演示**。对齐：`T_WE^Test = T_δ · T_WE^Demo`，T_δ 由 **4-DOF 回归网络 + Open3D 广义 ICP** 精化，再 motion planning；交互：在工作空间**开环重放**演示的 30 Hz 末端 twist 序列（含夹爪）。**免训练**：新任务只需把演示追加进缓存。基线 Ret-BC / BC-Ret / BC-BC 共用 MT-ACT+ 主干（点云 + CLIP FiLM 调制、变分推断、动作历史、终止头）。

**实验协议**：Sawyer + Robotiq 2F-85 + 单个 D415 头部 RGB-D。受控实验 **3,450 rollouts、70 物体**；数据量轴 **1→50 演示/任务**（12 seen + 8 unseen，每任务 3 次）；多样性轴 150 条演示摊到 **10 / 30 / 50 任务**。千任务评估：**31 macro / 534 micro skills、402 物体**、单演示/任务，采集共 **17 小时**；**2,200 rollouts**（每任务 2 次，含 100 unseen；5–20 干扰物、光照变化、±45° 位置随机）。

**失败归因（已有，但口径粗）**：seen 任务、**单专家评估**——检索 **22.3%**、分割 **19.5%**、位姿估计 **23.9%**、其余 **29%**（主要抓握物体任务 20.2%）。

**自陈局限**：单次交互 / 单臂 / 演示与部署位姿需一致；未测干扰物阻挡；纯视觉无法感知可变形物体刚度；依赖准确分割；**开环无中途纠错**；位姿估计对小特征 / 对称破缺脆弱（壶嘴致 180° 错）；**检索不能在演示间插值**；双臂 / 多阶段需外挂机制。

**代码库（MIT，131 文件，推送 2025-11-17）**：五种方法实现齐全；`deployment/` 有 5 个**单场景推理示例**（**不是批量评测 harness**）；权重仅 `geometry_encoder.ckpt` + `pose_estimator.ckpt`（XMem.pth 单独下载），BC / MT-ACT+ 权重未发布；仅真机 Sawyer、Docker(Ubuntu 22.04)、**无仿真器**；论文称 2,200 rollouts 已开源为数据集但不在此仓库。→ **单任务流水线可复现，千任务评测不可直接复现。**

### B1 · RoboTTT（唯一占"训练侧上下文"单轴的工作）
| 字段 | 内容 |
|---|---|
| 标题 | *RoboTTT: Context Scaling for Robot Policies* |
| 作者 | Yunfan Jiang、Yevgen Chebotar、Ruijie Zheng、Fengyuan Hu、Yunhao Ge、Jimmy Wu、Tianyuan Dai、Scott Reed、Li Fei-Fei、Yuke Zhu、Linxi "Jim" Fan（11 人） |
| 机构 | NVIDIA / Stanford / UT Austin |
| 版本 | arXiv:2607.15275v1，2026-07-16，**仅 v1** |
| 证据级 | A（全文 + 主会话双页复核 62/63） |

**做了什么（机制，不是"把历史喂长"）**：
- 慢权重 = **GR00T N1.7** 主干（Eagle VLM + 16 层 DiT），**推理时冻结**。
- **fast weight = 每层 DiT 里插入的一个 TTT 层（两层 MLP + GeLU）的参数**，共 16 个、每个约 10 M；DiT 由 538 M 增至 690 M（§A.1）。
- 每 timestep：token = 16 个 register token + 本体 q_t + 加噪动作 Ã_t，先做步内自注意力并 cross-attend 到视觉 token Φ_t；沿时间维拼接后进 TTT 层——`W_t ← W_{t−1} − η∇_W ‖f_W(K_t) − V_t‖²`，再 `O_t = f_{W_t}(Q_t)`（Eq.1–2）。
- **梯度来源是自监督的 key→value 关联重建**，不是动作预测、不是图像重建。动作只出现在外层 flow-matching 损失里，外层梯度去学 QKV 投影与 W_0（**gradients of gradients**）。
- 输出经 `tanh(α)` 门控加回注意力输出，α 初始 0.001。**每 timestep 一次梯度步**；内层学习率可学，base lr 0.1。**TBPTT 段长论文未报告**（只说"序列切段、梯度仅在段内、fast weights 跨段传递、边界 detach"）→ **可复现性缺口**。

**"8K context"到底是什么（关键事实）**：**是预训练时单条训练序列的 timestep 数，不是推理窗口。** 原文 *"scale visuomotor context to 8K timesteps, three orders of magnitude beyond state-of-the-art policies, without growing inference latency"*；8K @30 Hz ≈ 4.5 分钟（*"about five minutes at 30 Hz control"*）。**下游 post-train 只用 1K 上下文**（§3.4）。

**实验协议**：3 个真机**双臂装配**任务（YAM，4× RealSense D405）：Pup Go Car / Circuit / Gear Bot；数据量 8 / 6 / 5 小时；平均 episode 2 / 1 / 5 分钟；**trial 数 20 / 20 / 10**。Circuit 约 80 种配置，训练 20、测试 60。评分 = **rubric 完成度**，不是 0/1。基线：GR00T N1.7（单步）/ GR00T N1.7 Hist.（1 帧历史）/ **GDN**（TTT 层换成 Gated DeltaNet，层位置/门控/参数量对齐）。上下文扫 **128 → 8K**，正文点名 128 / 1K / 8K，其余点仅在 Fig.8 曲线内。

**数字**：

|---|---|---|
| 79% vs 42% | 三任务平均 rubric 分，较单步 GR00T N1.7 **+87%**；较最好基线 GDN(56%) +41% | §4 |
| 71.5% vs 43.9% | 8K 预训练 vs 同模型 1K 预训练，§4 写 **+63%** | §4 |
| **62%** | **摘要写 +62%，正文写 +63%，同一篇自相矛盾** | abs vs §4 |
| 2/10 | Gear Bot（5 分钟十阶段）完全成功数；所有基线 0（Table 1 三列为 9/20、13/20、2/10） | Table 1 |

**compute-matched 争议（定案）**：**论文只对"主实验基线"做了算力对齐，对"上下文扫描"这一组没有。**
- 对齐声明原文（§4）：*"sequence models use a 1K-timestep context, and non-sequence models are trained to a **matched compute budget**"* —— 主语是基线。
- 已报告：预训练 16×GB200、30K steps；post-train 8 GPU、20K steps；**batch：≤4K 上下文时 per-device 4 / global 64，>4K 时 per-device 1 / global 16**（§A.2）；推理 RTX 5090 @30 Hz。

## 5. 族 D：地基（10 条）

> D1–D4 为全文级（B），D5–D10 为摘要级（C，来自 `classics.md`）。

### D1 · ACT / ALOHA
arXiv:2304.13705v1；Zhao、Kumar、Levine、Finn。**机制**：leader-follower 关节遥操（<$20k）+ **CVAE 吸收多模态** + Transformer **一次出 k 步**（有效时域降 k 倍）+ 推理时重叠 chunk **指数加权**。**数字**：6 真机 + 2 仿真；每任务 50 条（≈10 min）；Cup Open 84% / Slot Battery 96% / Slide Ziploc 88% / Thread Velcro 20%；去 CVAE 35.3% → **2%**。**把什么变成已解决**：低价硬件 + 50 条演示可做毫米级双臂；**action chunking 成为默认组件**。**局限**：**无泛化实验**；每任务从零训 5 h、80M 参数；失败归因 *"difficulty of perception and lack of data"*。

### D2 · Diffusion Policy
arXiv:2303.04137v5（RSS 2023 + 期刊扩展）。**机制**：策略 = 对动作序列的条件去噪 DDPM；视觉只条件一次、**receding horizon**、CNN-FiLM / 时序 Transformer 两套 backbone。**数字**：真机 Push-T **95%**（IBC 0% / LSTM-GMM 20%）；翻杯 90%；倒酱 IoU **0.74 vs 人类 0.79**；**12 任务（abs）/ 15 任务（正文 §5）**、4 个基准、平均提升 46.9%。**把什么变成已解决**：BC 的结构瓶颈（多模态、高维动作、训练稳定性）一并解决；**baseline 必须带 diffusion**。**局限**：**无 Limitations 章节**；数据效率只有相对曲线（*"outperforms LSTM-GMM at every training dataset size"*），**无绝对下限**。

### D3 · OpenVLA
arXiv:2406.09246v1。**机制**：Llama2-7B + DINOv2/SigLIP；动作按 **1–99 分位离散成 256 bins**，覆写词表末 256 token，next-token 预测；单图 + 指令 → 7 维动作，**无 chunking**。**数字**：970k 轨迹；29 任务比 RT-2-X（55B）**+16.5% 绝对**、参数少 7×；LoRA 1.4% 参数即匹配全量微调；64×A100×14 天 = **21,500 A100-hours**；4090 上 **6 Hz**。**把什么变成已解决**：开放权重 VLA 可复现、跨本体开箱可用、消费级 GPU 可微调。**局限**：只支持单图；**6 Hz 上不了 ALOHA 的 50 Hz**；*"typically achieving <90% success rate"*；DROID 混入后 *"action token accuracy on DROID remained low throughout training"*，**最后三分之一训练直接移除 DROID**。

### D4 · DROID
arXiv:2403.12945v2。**不是算法**——统一 Franka + 双 Zed + Quest2 栈、15 Hz 遥操、50 名采集者分布式采集；策略一律 DP + 50/50 混合训练。**数字**：76k 轨迹 / 350 小时 / 564 场景 / **52 栋楼** / 18 机器人 / 13 机构 / 1417 相机视角 / 12 个月；**abs 84 tasks vs 正文 86 tasks**（论文把 "tasks" 定义为"语言指令去重后的 unique verbs"）；另约 16k 条标 "not successful" 不计入规模；6 任务 × 4 地点、每任务每设定 **10 rollouts**；相对 OXE 同分布 **+22%**、OOD **+17% 绝对**。**把什么变成已解决**：**场景多样性（而非单纯数据量）是 OOD 泛化的驱动**——7k 条/20 场景 vs 7k 条/多样场景的对照。**局限**：无 Limitations 章节；**10 rollouts 无 CI**；开放问题 *"how can we train policies that perform tasks in new scenes without any in-domain data?"*。

### D5 · RT-1（C 级）
arXiv:2212.06817。论点：通用机器人模型的关键是**开放式、任务无关训练** + **能吸收全部多样数据的高容量架构**；提出 Robotics Transformer；研究泛化随**数据规模 / 模型规模 / 数据多样性**变化。→ "规模换泛化"叙事的源头。

### D6 · RT-2（C 级）
arXiv:2307.15818。把互联网规模预训练的 VLM **直接纳入端到端控制**；配方 = 机器人轨迹 + 互联网 VQA **共微调**，**动作表示为文本 token** → **VLA 命名与范式起点**。证据：**6k 评测试验**；涌现能力（新物体、训练数据中不存在的指令、初级推理）；加 CoT 可多阶段语义推理。

### D7 · OXE / RT-X（C 级）
arXiv:2310.08864v9。**22 种机器人、21 家机构、527 skills / 160,266 tasks、60 datasets**；RT-1-X / RT-2-X 是"跨本体正迁移"的首个大规模证据。**⚠️ 机构数口径**：论文写 21 institutions，官方页写 34 实验室 → **引用须标来源**。

### D8 · π0（C 级）
arXiv:2410.24164v4（RSS 2025）；Physical Intelligence，24 作者。预训练 VLM 之上做**流匹配动作生成**，跨本体（单臂/双臂/移动）训练。abs 页**无数据规模与成功率**（在正文，未读）。

### D9 · π0.5（C 级）
arXiv:2504.16054v1。**异质任务共训练**（多机器人 + 高层语义预测 + web 数据）；混合多模态样例：图像 + 语言 + **物体检测** + **语义子任务预测** + 低层动作；首次展示端到端系统在**全新家庭**做长程灵巧操作。→ 它是多篇工作的公共基线锚点（GAM 报 LIBERO-Pro 53% 即以它为基线）。

### D10 · Mobile ALOHA（C 级）
arXiv:2401.02117v1。**低成本全身遥操作 + 移动底盘**用于数据采集；用其数据做监督 BC，**与既有静态 ALOHA 数据集共训练**；**每任务 50 条演示**时共训练可把成功率提升至多 **90%**。

### D-合 · 四条地基共同留下的缺口
**共同确立的范式**：大规模人类演示 → 端到端 BC（chunk / diffusion / token 三种参数化）→ 单任务或跨本体少样本。四篇都把**数据规模与多样性**当泛化的唯一调节手段，把**策略结构**当性能瓶颈（DP 原话：policy structure 是 *"a significant performance bottleneck"*）。

**共同未解决（四条）**：
1. **评测不可比**：25 trials/1 seed（ACT）、10 rollouts（DROID）、29 任务但分本体（OpenVLA），无 held-out 场景协议。
2. **数据效率的绝对下限从未刻画**：ACT 50 条但每任务重训；OpenVLA 要 970k 预训练再 10–150 条微调；DP 只有相对曲线。**三篇都在说"相对更省"，没人回答"多少条才够"。**
3. **失败不可归因**：端到端黑箱，错了分不清是感知、覆盖不足还是表达力。
4. **演示质量天花板**：BC 原则上不能超出演示支撑集。

→ **检索式策略要填的是第 2 + 3 条。**

## 6. 族 E：机制层组件（7 条）

### E1 · Grounding DINO（开放词汇检测）
arXiv:2303.05499。**契约**：图像 + 文本 → **框 + 短语**，**不出 mask**——原文 *"cannot be used for segmentation tasks like GLIPv2"*。**局限**：900 query 上限；LVIS rare 上不如 GLIP。**⚠️ 实现陷阱**：所以"Grounding DINO + XMem"这条链**中间缺一环**（首帧 mask 从哪来），MT3 论文写"分割 + 传播"，这一环在实现里必须补。

### E2 · XMem（视频对象分割）
arXiv:2207.07115。**契约**：视频 + **首帧 mask** → 逐帧 mask；**半监督**，首帧必须人工或外接 SAM。**失效**：快动 / 模糊（唯一自陈失效）；**长时记忆是压缩原型 → 长遮挡后细节不可恢复**（不是"慢慢变差"，是"丢了就没了"）；**同类实例串例**（记忆按外观读，不按身份）。

### E3 · FoundationPose
arXiv:**2312.08344**（Wen 等，NVIDIA，CVPR 2024；⚠️ 我曾误记 2401.17857，那是 SAGD 3DGS 分割）。
**契约**：**RGB-D** + 2D 框 → 6D 位姿；硬先验 = **CAD 模型 或 ~16 张带位姿的参考图** + 内参。2D 检测是外部的，**分割错会原样传下去**。
**相对"回归 + ICP"改了什么（机制层）**：
1. **不回归，先造假设再判别**——对称/遮挡下位姿后验多峰，回归输出均值 = 一个不存在的朝向；FP 用 icosphere 采 Ns·Ni 个全局假设、各自精化，再用分层排序网络在 K 个假设间做 self-attention 打分，**选一个模式**。→ T-LESS 的 83.0 不是"回归更准"，是"不再取平均"。
2. **精化 = learned render-and-compare**：输入渲染 RGB-D 与观测 crop，输出相机系 Δt、ΔR（**解耦**），可迭代；crop 按假设位姿裁，等于把平移误差变成可学的视觉信号。作者明说**不需要 ICP**：*"without fine-tuning on the target dataset or ICP refinement"*。
3. **model-free 分支**：神经 SDF + 颜色场从约 16 张参考图合成任意视角 RGB-D，把"要 CAD"降级成"要几张**带位姿标注**的图"。
**精度**：YCB-V model-free ADD-S/ADD = **97.4 / 91.5**；LINEMOD ADD-0.1d = **99.9**；BOP 三集 AR **83.3**；T-LESS AR **83.0** vs MegaPose 54.3。
**算力**：**1.3 s/物体**（init 4 ms、refine 0.88 s、select 0.42 s），tracking **32 Hz**，RTX 3090。→ 单卡可，但估计**非实时**。

### E4 · AnyGrasp
arXiv:2212.08333。**契约**：单视角点云 → 7-DoF 抓取 + 置信分；需内参、夹爪宽度；**无需模型**。**直接排除透明 / 反光**物体。

### E5 · PointNet++
arXiv:1706.02413（C 级）。点云层次特征编码器，MT3 的几何分支用它。

### E6 · DINOv2
arXiv:2304.07193（C 级，但 STRAP 的对照结论为 A 级）。**图像实例检索**上碾压 CLIP（Hard 子集 Oxford/Paris：mAP **52.3 / 82.6** vs **19.7 / 60.2**）；但**动作片段检索**上只差 **+0.7%**（§A4）。**→ 检索质量的瓶颈不在表征，在度量与对齐。**

### E7 · S-DTW（子序列动态时间规整）
**复杂度**：距离矩阵 O(n·m·E)，DTW O(n·m)，全库 O(N·M)，*"scales linearly with the size of D_prior"*；DROID（76k）≈ **300 s** → **N 扫描成本线性、可承受**。
**四个失效点**：
1. 只 warp 时间**不 warp 幅值** → 慢而大的动作与快而小的动作代价不可比；
2. **退化匹配**：原文 *"To avoid degenerate matches, we limit the step size of the S-DTW backtracking to [1,2]"* ——放开步长则最优解塌缩为"一帧对多帧"、代价趋零（**极值偏置，参考越长越严重**）；
3. **累计代价随路径长度增长** → 跨 query 的 top-K **不可比**，系统性偏向短路径 / 长参考；
4. 只对齐时序**不对齐因果** → 推与拉在嵌入上相近即低代价。

### E8 · 度量族对照（表）

| 度量 | 适用 | 机制代价 | 失效 |
|---|---|---|---|
| **余弦** | 压成单向量后的语义相似 | 无点对点对应；时间被抹平 | 外观方差主导；整体近但局部错位仍判近 |
| **Chamfer** | 点云几何 | 双向最近点求和，**多对一** | 对密度与离群点敏感 |
| **EMD / OT** | 点云 + 轨迹对齐 | 质量守恒、一一对应，**线性规划级** | 计算贵 |
| **SWD** | 点云 | 投影到一维排序比分布，置换不变、近线性 | 投影方向数需调 |
| **S-DTW** | 变长子序列 | 时间 warp 吸收速度/时长差 | 见 E7 |

## 8. 从台账直接得出的判断（三条）

### 8.1 已成共识，可直接引用、不必再论证
1. **action chunking / receding horizon 是默认组件**（ACT、DP 各自独立确立）。
2. **"超不过演示质量"是整条模仿学习路线的共同上限**，不是检索式独有的原罪（DP 倒酱 0.74 vs 人类 0.79；OpenVLA 自陈 <90%）。
3. **场景多样性（而非单纯数据量）驱动 OOD 泛化**（DROID 的 7k/20 场景 vs 7k/多样场景对照）。
4. **上下文预算存在最优区间，非单调**（§7.3 三处独立证据）。
5. **编码器选择在动作片段检索上近乎零效应**（STRAP：+0.7%）。

### 8.2 空白（可判定，且已被"最好的工作"反向证明）
1. **N × K × L 三轴联合的等预算 (K,L) 等值线**：§7.1 无一行填满 → 空。
2. **等算力、等数据的上下文预算曲线**：唯一占单轴的 RoboTTT **未做**匹配（§B1）→ 空。
3. **带混杂控制的阶段级归因模型**：RoboArena / COLOSSEUM **都没报归因**，且 COLOSSEUM 的轴级降幅还混了位姿方差 → 空。可做法 = 在 `θ_p+τ_t+ν_t+ψ_{p,t}` 上加阶段项 `σ_{p,t,s}`。
4. **受控换算率协议**：唯一显式数字（Skild 380）是插值、无 CI、指标非 SR → 空，且**插值规则本身就该写进协议**。
5. **架构层空格**：「时序对齐的变长子轨迹」×「冻结条件化（免训练）」——有对齐的（STRAP/ReGIL）必须训练才能消化变长片段；免训练的（ReCAP）只能吃定长 chunk。**空白在架构层，不在想法层。**

### 8.3 威胁（必须先回答的反例，否则会被打穿）
1. **ACT 表 I：VINN 在两个真实任务终局成功率 ≈ 0** → 检索式"没有学习、超不过演示质量"有实证。**回答三层**：①VINN 输在单步检索无时域结构，而 chunk + temporal ensemble 正是 ACT 自己给的补丁；②该上限对 BC 同样成立；③检索的真正差异是**可归因 + 零训练 + 库可增量**。→ **立论写"可归因才让 scaling 可测量"，不写"更强"。**
2. **"更多上下文会变坏"**（§7.3）→ 朴素动机站不住，必须给"何时变坏"的判据。
3. **检索度量随 N 退化**（hubness / 极值偏置 / 容量上限）→ 与预算效应**同向**，会把等值线系统性压平，且无法区分"库没用"与"度量坏了"。**必须加"余弦 × N"独立对照臂。**
4. **三类错误互相伪装**（分割错伪装成位姿错；对称翻转伪装成分割错；检索到相似物伪装成位姿错；XMem 漂移伪装成检索错）→ **MT3 的"检索 22.3%"若是端到端单标签归类，不可信**；只能靠 oracle mask / oracle pose 反事实臂分离。
5. **LIBERO 底座对扰动极脆**（95%→<30%）→ 结论只在原始分布内成立。
