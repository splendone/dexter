# RH20T

- 级别:知识卡片(闲时菜单 B2)| 建档:2026-09-28 | 起草:Dexter | 状态:初版
- 官方页:https://rh20t.github.io/
- 论文:RH20T: A Comprehensive Robotic Dataset for Learning Diverse Skills
  in One-Shot(arXiv:2307.00595,ICRA 2024)
- 类型:多模态大规模真机数据集(首个主打"人类演示-机器人操作"配对的)
- 规模口径(官方页原文,2026-09-28 抓取):110,000+ 接触富集真机操作序列;
  数百万级"人类演示↔机器人操作"配对;任务 = RLBench 48 + MetaWorld 29
  + 自设 70;原始体量约 40TB(有 640×360 与 320×180 缩减版)
- 采集方式:触觉设备+脚踏板遥操作;每平台 = 机械臂 + 力/扭矩传感器 +
  夹爪 + 1-2 手内相机 + 8-10 全局 RGBD + 2 麦克风
- 模态(对②触觉透镜重要):RGB 720p@10Hz、深度、双目 IR、关节角/扭矩、
  夹爪位姿/开度、六维力/扭矩、音频 30Hz、**指尖触觉 2×16×3@200Hz
  (仅 7 号机器人构型)**
- 获取:Google Drive / 百度云公开下载(RGB、RGBD、LowDim、标定等分卷,
  7 种机器人构型);API:github.com/rh20t/rh20t_api
- 许可:**分卷双许可——RH20T-C(CC BY-SA 4.0)/ RH20T-NC(CC BY-NC 4.0,
  禁商用,训练的模型也受染)**——引用/使用前必须分清子集
- 透镜关系(这是判断):②触觉与多模态传感的关键语料(唯一同时带力/触觉/
  音频的多模态大库);"人类演示配对"结构对④(免遥操作的数据路线)有
  直接价值。
- 置信度与待核点:高(逐字来自官方页);NC 子集对模型许可的"传染"边界
  建议使用前法务级确认(宪法转介条款适用)。
