# AgiBot World(智元)

- 级别:知识卡片(闲时菜单 B2)| 建档:2026-09-28 | 起草:Dexter | 状态:初版
- 官方仓库:github.com/OpenDriveLab/AgiBot-World(3.2k stars);
  数据:HuggingFace agibot-world/AgiBotWorld-Alpha(与 Beta)
- 论文/技术报告:AgiBot World Colosseo(arXiv:2503.06669;IROS 2025
  最佳论文入围 & IEEE T-RO 2026,仓库自述)
- 类型:产业级大规模真机双臂操作数据集(宣称具身智能的"ImageNet 时刻")
- 规模口径(仓库 README 原文,2026-09-28 抓取):**Beta = 1,003,672 条
  轨迹(约 43.8TB)**;Alpha = 精选子集 92,214 条(约 8.5TB);100 台机器人;
  100+ 个 1:1 复刻真实场景,5 个目标域
- 论文口径补充(arXiv:2503.06669 abs 页,2026-09-28 复核):**>100 万条轨迹 /
  **217 任务** / 5 个部署场景**;配套通用策略 **GO-1** 较 OXE 预训练平均
  **+30%**(域内与域外);GO-1 用潜动作表示最大化数据利用,性能随数据量
  **可预测增长**——透镜①"数据规模红利"的正面证据。(README 未给任务数,
  217 为本轮从 abs 页补入)
- 采集方式:AgiBot 自家机器人真机采集,30Hz;特点 = 视觉触觉传感器 +
  **6 自由度灵巧手** + 移动双臂平台;任务覆盖接触富集操作、长程规划、
  多机协作
- 获取:HF / OpenDataLab;配套模型 GO-1 与 GO-1 Air(LeRobot 底座,
  微调约 70GB 显存,仅 Action Expert 约 24GB,推理约 7GB)
- 许可:**CC BY-NC-SA 4.0(仓库明示,数据与代码均同)**——禁商用 +
  相同方式共享,二创数据/模型都要注意传染
- 透镜关系(这是判断):④产业界真机数据的规模天花板(百万级轨迹);
  带灵巧手与触觉传感使其同时是②的重要候选;与产业哨直接交叉——
  智元的开源动态本身就是产业信号。
- 置信度与待核点:高(逐字来自官方仓库);Alpha/Beta 两版的任务分布
  差异、"1:1 复刻场景"的实际覆盖清单待核。
