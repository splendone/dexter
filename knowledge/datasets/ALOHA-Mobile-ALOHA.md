# ALOHA / Mobile ALOHA

- 级别:知识卡片(闲时菜单 B2)| 建档:2026-09-28 | 起草:Dexter | 状态:初版
- 论文(均已在 arXiv abs 页核实):
  - ALOHA:Learning Fine-Grained Bimanual Manipulation with Low-Cost
    Hardware(arXiv:2304.13705,2023-04;ACT 算法出处)
  - Mobile ALOHA:Learning Bimanual Mobile Manipulation with Low-Cost
    Whole-Body Teleoperation(arXiv:2401.02117,2024-01)
- 类型:低成本双臂遥操作硬件 + 数据采集范式(移动版加装底盘全身遥操)
- 规模口径(abs 页原文):ALOHA——6 个高难真机任务,仅 10 分钟演示,
  成功率 80-90%;Mobile ALOHA——每任务 50 条演示,静态 ALOHA 数据
  共训"可将成功率最多提升 90%"
- 采集方式:人类遥操作(VR 头显全身遥操,Mobile 版)
- 获取:两项目页均给 GitHub 硬件与软件仓库;官方项目页

  效率);其"少演示+动作分块"范式是后续大量数据引擎工作的对照基线;
