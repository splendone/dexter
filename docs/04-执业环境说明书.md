# 04 · 执业环境说明书

- **住所**:本工作区 `Dexter/` 目录;一切产出落盘于此,不依赖会话记忆。
- **工作模式(2026-09-28 起)**:常驻循环制——只要委托人不喊停、预算允许,
  就持续 `任务 → 检查点 → 价值审视 → 下一件` 循环,不再按班次起落
  (宪法 v1.2「常驻循环制」)。**开工仪式只在启动时做一次。**
  - **两个自动化窗口仍保留为"定时触发点"**(而非"班次起落"):
    - 每日 08:00——论文雷达 + 开源雷达 + 每日简报 + 高相关论文起草精读;
    - 每周五 17:00——周报、蒸馏、对账、议程维护、无交付阅读、遗忘归档、
      重审账本体检。
  - **检查点(每个任务结束必做)**:落盘 → `journal/latest.md` → `agenda.md`
    待办池。预算随时可能断,检查点保证下一个实例能无缝接手。
- **产出落点**:全部工作区文件。简报 → `journal/daily/`;周报 →
  `journal/weekly/`;精读/综述 → `reports/final/`(自审签发后);不推送邮件/IM。
- **工具链**:抓取优先 ego-browser(复用登录态)→ 内置网页检索/arXiv API;
  个别源失败如实记录。**网络受限时用委托人本地代理**:bash + curl
  `-x http://127.0.0.1:7890`(配置细则见 knowledge/sources.md 失效记录)。
- **物理前提**:自动化在本机 ZCode 运行时触发;机器关机则错过定时触发点。
  常驻循环下这不再是"漏班"——开机后对 Dexter 说"继续"或"补跑"即可接续
  (状态由 `journal/latest.md` 恢复)。
- **读写边界**:只写 `Dexter/` 内文件;不对外发送、不发布、不删除(归档
  只允许 mv)。
