## 0. TL;DR 与适用边界

**解决什么**:在**给定预算**内,搭一条**低成本桌面级操作数据生产线**——
真机遥操作采集 → 失败数据翻新 → 仿真合成增强 → 模仿学习策略训练 → 配比评测,
使一台低成本平台学会**一组桌面精细操作任务**并达到**可测成功率**。

**系统长什么样**(四段):

```
① 采集 rig            ② 数据仓                    ③ 策略训练            ④ 评测
主从遥操作臂/手持夹爪 → 真机轨迹 + 翻新数据 + 合成数据 → 模仿学习(DP / VLA)→ 固定任务集
(相机,可选触觉)        (统一格式:LeRobot / OXE)      (单卡~多卡)           (成功率 / 配比曲线)
```

**总预算量级**:**¥10000**(委托人 2026-10-09 明示)。BOM 核心档已定(§3.2,名义小计约 ¥7000;⚠️**最坏情形各项上限相加 ¥9643(臂按官方 ¥1343.16),最坏余量 ¥357**——见 §3.2 诚实标注)。

**不再受算力约束**;⚠️**免费试用到期转现金成本**(见 §3.2 云 GPU 行,须询价 + 升级门)。

## 1. 问题定义与验收目标

### 1.1 要达成的能力(可观测行为)

一台低成本**单臂 SO-101**(1 follower + 1 leader,unimanual;或手持夹爪)平台,在**给定预算**内,用**混合数据管线**学会
**一组桌面精细操作任务**(任务集在 §7.1 定义),并在**固定任务集 × 固定回合数**上
达到**可测的成功率**。

### 1.2 验收判据(可测量;**目标值待与委托人校准**)

| 指标 | 定义 | 目标(草案) | 测量方式 | 锚点出处 |
|---|---|---|---|---|
| **策略成功率** | K 个任务上的平均成功率(**单臂 SO-101 口径**) | **单臂可比目标,待实测标定**;⚠️**不引 ALOHA bimanual 80–90%/6 任务**(那是 4 臂双臂,不可迁移单臂——裁 A) | 固定任务集 × 每任务 **50 回合** | 单臂可比基线:同任务纯视觉 DP/Diffusion Policy(本平台实测标定,§1.3 底线) |
| **数据效率** | 达标所需真机演示数 | 每任务 **≤ 50 条**(对标 Mobile ALOHA,量级参考,须单臂复现) | 演示数-成功率曲线 | Mobile ALOHA(2401.02117) |
| **翻新增益** | "加 ε4P 翻新数据" vs "只用高质量真机数据"成功率差 | **取 ε4P「错配数据翻新」增益上限 +31.7pp**;⚠️**不取「等量替换」**(ε4P 摘要自陈:等量替换高质量数据 → 平均**降 4.2pp**)。故判据为「翻新增益为正(错配/低精度数据补量场景)」,**非**「等量替换不降」 | 消融对照(错配+低精度补量 vs 纯高质量) | ε4P(2609.26672,curl 实抓 abs 核对) |

| **采集节拍** | 每小时有效轨迹条数 | **待实测** | 计时 | — |

## 2. 系统构成与工作原理

### 2.1 子系统分解

| 子系统 | 内容 | 备注 |
|---|---|---|
| **机械** | 遥操作主从臂(**单臂 SO-101**,1 follower + 1 leader)或手持夹爪 + 末端执行器 | 候选范式见 §3.1;双臂 bimanual 见 §3.1 扩展档 |
| **传感** | 腕部 / 第三人称相机(必需);触觉(可选,变体 B) | 视觉为最低配置 |
| **驱动 / 控制** | 电机 / 舵机 + 实时控制回路 | 随所选平台 |
| **计算** | 训练工作站(GPU)+ 采集端(轻量) | **算力已解除(2026-09-30 委托人:无上限/免费试用),GPU 走云**;试用到期现金成本见 §3.2 云 GPU 行 |
| **供电** | 直流供电 + 急停 | 安全项见 §8.3 |

### 2.2 工作原理(为什么这样能达标)

- **模仿学习主干**:以动作分块(action chunking)/ 扩散策略学"一次预测一段动作"
  ——ALOHA·ACT 证明**低成本遥操作 + 动作分块**可在 **10 分钟演示**下达 **80–90%**(6 任务);
  ⚠️**此为 bimanual 双臂(4 臂)口径,不可迁移单臂 SO-101,仅作"少量演示即可学"的技术依据,非本平台验收锚点**(裁 A)。
  Diffusion Policy 是当代流/扩散策略的公共骨架。→ 这是"少量真机演示即可达标"的**技术依据**。
- **混合管线为什么划算**:①**真机**提供**接触物理**与**任务关键几何**(最贵、最少);
  ②**合成**(MimicGen 式:~200 条人演 → **50K+**;DexMimicGen 60 → **21K**)用引擎**扩增**;
  ③**翻新**(ε4P = arXiv:2609.26672「Imperfection for Precision」,curl 实抓 abs 核对):ε4P **不是**"失败轨迹→恢复数据",而是**把两类会被丢弃的「不完美数据」翻新利用——(a) 目标任务的低精度数据 +(b) 错配任务的高精度数据**(沿 flow-matching 轨迹分层注入:低精度目标数据用在高噪声段保任务上下文,高精度错配数据用在低噪声段迁移动作精度),**增益上限 +31.7 个百分点**;⚠️**代价:等量替换高质量任务数据 → 平均降 4.2pp**(裁 B,故只取错配/低精度补量增益,不取等量替换)。
  → 三者**互补**:真机锚定真实性,合成补量,翻新**回收低精度/错配的"不完美"数据**补覆盖。
  (注:失败轨迹→恢复数据是**另一条路线 Kintsugi 式**,与 ε4P 不同源,勿混——见 §6 P3。)
- **配比为什么是核心问题**:账本二分歧 1 / 透镜④开放问题 1 指出**同策略同预算的受控对比缺失**
  ——本规格的 §7.2 实验设计正是为**填这个缺口**,并**顺带产出可复跑曲线**(未来喂 G4)。

### 4.2 电气接口
- **供电电压**:**7.4V 档(follower STS3215 默认;leader 恒 7.4V,配 5V 电源)**;若选 **12V 版电机 → 须换 12V 5A+ 电源**(§3.2 STS3215 扭矩选型岔口);
- **⚠️ STS3215 扭矩档(选型岔口)**:**7.4V 堵转 16.5 kg·cm(≈1.62 N·m @6V)** vs **12V 版 30 kg·cm**,**差约 2 倍**;官方称 7.4V 对 SO-101 任务集**"sufficient"**,桌面精细任务默认 7.4V,负载不足才升 12V;
- **⚠️ 降额警告(官方 README 口径)**:上表 16.5 kg·cm 是 **@6V/7.4V 标称堵转扭矩**;实际 **5V 供电下扭矩略低于 16.5 kg·cm@6V**(电压降额),装配后**须实测校核**,不得以标称值冒充实测裕度;
- **末端负载 / 力矩裕度(可测判据,待实测标定)**:①**末端静态负载** = follower 臂全展姿态下末端可稳定持住的最大质量(kg),实测值须 **≥ 任务集最重道具质量 × 安全系数(建议 ≥2)**;②**关节力矩裕度** = (堵转扭矩 − 任务峰值所需扭矩)/ 任务峰值所需扭矩,**建议 ≥ 30%**;两项均在装配后逐轴实测记录(标"待实测");
- **"负载不足 → 升 12V"触发阈值**:若上述①末端静态负载实测 **< 任务需求** 或②力矩裕度 **< 30%** → 判定 7.4V 档负载不足,**升 12V 版电机 + 换 12V 5A+ 电源**(成本↑,须核预算并触发升级门);
- **通信总线**:**半双工 TTL 串口**(Feetech STS3215 舵机总线),经 Motor Control Board(Waveshare)转 USB 接采集端;
- 急停回路:**必须独立硬件回路**(安全项,§8.3)。

### 8.1 失败模式表
