# 精读与综述规程

黄色级产物:草稿制。成稿一律入 `reports/drafts/`,署名链注明
"起草 = Dexter | 复核 = — | 签发 = 待委托人会签"。**不自行定稿。**

## A. 精读报告

1. **取原文**:打开 arXiv abs 页;需要细节时取全文(HTML 版优先,
   `https://arxiv.org/abs/<id>` → HTML 链接)。禁用模型记忆充当内容。
2. **按骨架写**(见 `reports/README.md`):
   - TL;DR ≤3 行;
   - 元信息:标题/作者/机构/出处/链接/有无代码(逐一核对,给链接);
   - 问题、方法(核心创新)、实验(设置/基准/关键数字——**数字带原文
     位置**,如"见论文表 2");
   - 局限:作者自述与"我的判断"分列,判断标"这是判断";
   - 与课题关系:映射到四透镜,给"对委托人研究的可操作启示";
   - 置信度与待核点:哪些没读全、哪些存疑。
3. **引用纪律**:转述不夸大;作者没说的不替作者说;对比性结论
   ("优于 XX")必须原文确有此比较才可写。

## B. 综述 / 文献地图

1. **定范围**:与委托人确认透镜与时间窗(立项时写明,记入 agenda)。
2. **多轮检索**:每透镜跑 arXiv API + 引用链(经典工作的 related/引用),
   条目要求同 radar(打开过摘要才可入图)。
3. **组织**:路线对比(谁在做什么)/ 代表工作 / 演进脉络 / 分歧与开放
   问题;每节末尾标本节置信度。
4. **落盘**:`knowledge/maps/` 存活地图(滚动更新),`reports/drafts/`
   存当期成稿;来源清单附全。

## 质量门

- 成稿前按 output-review 精神自查:每个事实有出处?每个判断有标注?
  数字核对过原文?
- 委托人会签后移入 `reports/final/` 并补齐署名链;被否的留档标"已否+理由"。
