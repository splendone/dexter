## 改变研究计划的七条结论(供后续会话直接引用)

1. **"context"在领域里指三件不同的事**(训练序列长度 / 提示内演示条数 / 检索候选规模),无人分开 → 领先点① 改为「固定总预算 B=K·L 下的 (K,L) 等预算等值线」,RoboTTT 的 8K 属训练侧、排除族外。
2. **RoboTTT 的 compute-matched 只对基线做,上下文扫描没做**(§4 原句 + batch 64→16、步数同为 30K)→ "context 是新 scaling 轴"目前是相关性证据。
3. **Skild 的 380 是插值**(log-x 378.8 / 线性-x 431,差 14%),指标非 episode SR、无 CI → 只能当动机引用,不能当数值基线。
4. **LIBERO 标准协议(20×20×1)MDE≈9.4pp、对 5pp 功效仅 0.30**;我方 20×50×3 → 3.4pp / 0.98;敏感性 3.4–3.8pp 稳定。**配对同初态对功效只 +0.02~0.05**,必须做但理由写"排除混杂 + 使阶段归因可行"。
5. **视觉编码器选择几乎不重要**(STRAP:DINOv2 vs CLIP 差 +0.7%)→ 不做编码器消融,重心在**相似度度量**。
6. **检索度量随库规模 N 退化**(hubness / 极值偏置 / 容量上限),与预算效应同向 → 必须加"余弦 × N"对照臂量退化斜率,否则 N 轴结论不可解释。
7. **三类错误(检索/分割/位姿)会互相伪装**,只能靠 oracle mask / oracle pose 反事实臂分离 → **MT3 的"检索 22.3%"若为端到端单标签归类则不可信**。

## 立下的可证伪假设

- **H1'**:最优 K 是"该 N 下的检索精度"的函数,不是 N 的函数;因度量退化,**最优 K 可能随 N 增大而左移或提前饱和**(与直觉反向)。测法:每 N 测 top-1 精度,画"最优 K vs 精度"散点。
